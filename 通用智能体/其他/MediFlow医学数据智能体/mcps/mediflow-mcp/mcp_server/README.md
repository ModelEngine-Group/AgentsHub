# MCP 服务入口

`mcp_server/` 是 Nexent 调用 MediFlow 能力的入口。它把数据处理、知识图谱和数据分析封装为可发现、可调用的 MCP 工具，并返回结构化结果。

## 目录索引

| 目录或文件 | 作用 |
| --- | --- |
| `server.py` | 启动 MCP 服务并注册工具 |
| `config.py` | 读取服务地址、数据库路径和运行参数 |
| `tools/` | Nexent 直接调用的工具函数 |
| `task1/` | 数据集探查、文件整理、状态查询和质量证据 |
| `task2/` | 医学文本解析、实体关系抽取和报告组织 |
| `task3_nl2sql.py`、`task3_query.py` | 自然语言分析、图谱查询、来源查询和可选入口状态 |
| `task3_runtime.py` | 装配共享的数据分析服务和数据库路径 |
| `kg/` | 三元组入库、来源登记和分析库刷新 |
| `datamate/` | DataMate 数据集和 API 适配 |
| `shared/` | 外部入口状态、SQLite 和通用解析辅助模块 |

## 设计边界

- 工具层负责参数校验、调用服务层和返回结果；
- 业务流程由 `task1/`、`task2/`、`task3/` 和 `kg/` 中的服务模块完成；
- 数据库和外部平台访问通过适配模块完成；
- 查询结果必须来自真实数据库或接口；
- 数据分析自然语言入口统一使用 `task3.runtime`，分析数据库是统计结果的唯一来源，知识库检索用于补充文本背景和来源依据。
