# 知识图谱与分析数据库

`kg/` 保存离线数据库构建代码，用于把医学知识数据整理为知识图谱库，并派生出供自然语言分析使用的统计数据库。归档包已经提供预构建数据库；只有在数据源更新或需要重新生成时才需要运行这里的代码。

## 文件

| 文件 | 作用 | 输出 |
| --- | --- | --- |
| `build_kg_v2.py` | 构建知识图谱，保留来源、记录编号和质量标记 | `data/task2_medical_kg.db` |
| `build_analytics_v2.py` | 从知识图谱生成疾病统计、关系统计和分析表 | `data/task3_analytics.db` |

## 数据流

```text
医学知识数据或整理后的资料
  → 实体与关系规范化
  → 知识图谱数据库
  → 统计分析表
  → MCP 查询工具
```

日常使用直接展开 `knowledge_base/` 中的数据库即可。重新构建时请先备份现有数据库，并确认输入数据具有合法的来源和再分发权限。
