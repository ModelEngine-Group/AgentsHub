# 数据分析模块

`task3/` 实现自然语言分析规划、只读查询校验、证据绑定、图表数据生成和报告导出。它不负责页面布局，也不直接管理 Nexent；MCP 服务通过 `runtime.py` 装配统一分析服务。

## 处理流程

1. `planner.py` 识别疾病实体、查询意图、筛选条件和统计需求；
2. `sql_safety.py` 校验只读查询和执行范围；
3. `service.py` 读取分析数据库，并将结果、查询、来源、耗时和分析编号绑定；
4. `chart_policy.py` 根据字段和问题意图选择图表形式；
5. `report.py` 从同一份分析记录生成 HTML、CSV 和 JSON。

## 文件职责

| 文件 | 作用 |
| --- | --- |
| `contracts.py` | 分析计划和查询项的数据结构 |
| `semantic_layer.py` | 稳定的医学事实维度和查询模板 |
| `planner.py` | 稳定语义规划与开放式查询规划 |
| `sql_safety.py` | 只读查询校验、资源限制和结果序列化 |
| `chart_policy.py` | 字段类型与图表形式匹配 |
| `service.py` | 分析流程、证据绑定和运行指标 |
| `runtime.py` | MCP 与其他入口共用的服务装配 |
| `report.py` | HTML、CSV 和 JSON 结果导出 |

## 结果边界

分析数据库负责数量、排名、筛选和分组等结构化结果；Nexent 原生知识库可补充疾病定义、病因、症状和治疗背景。两类结果在返回内容中分别标明，不将文本检索结果当作统计值。
