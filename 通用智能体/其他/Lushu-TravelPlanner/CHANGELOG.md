# 更新日志

## 1.0.0 — 2026-11-02

首个版本，基于 Nexent v2.8.3 构建。

- 发布「旅游规划助手（路书 · Lushu Travel Planner）」智能体配置，主模型 `deepseek-chat`，温度 0.2，最大步数 20。
- 提示词确立「第一铁律：信息不全，只许提问，不许规划」——出发城市／日期／天数／人数构成／总预算五项任一缺失时，本轮仅输出不超过 60 字的提问，禁止输出行程、禁止调用工具、禁止使用"假设"类表述。
- 增加第二轮偏好确认（交通方式、住宿档次、必去/不想去、饮食忌口），用户回"都行"时须在首行声明所采用的默认值。
- 接入高德地图 MCP `amap-maps`，启用 12 个工具：地理编码、逆地理编码、周边搜索、关键字搜索、POI 详情、距离测量、驾车/公交/步行路线、天气。
- 接入 Tavily MCP `tavily-search`，使用 `tavily_search` 与 `tavily_extract` 查询门票价格、开放时间与官网原文。
- 增加工具调用纪律：一轮只调用一个工具；工具报错不重试同一个，换用下一个；连续两次失败即停止检索并标注"未查到实时数据"。
- 增加预算自洽规则与输出前自检（五项是否齐全、是否把未提供的信息当作已知、是否在解释假设）。
- 完成开发实例上的回归：单轮提问约束、地图检索、搜索检索、多轮偏好确认均按预期工作。
- 生成脱敏配置：`tenant_id` 置空，`mcp_info` 中两个 MCP URL 的密钥替换为占位符，导入者需自行配置。
