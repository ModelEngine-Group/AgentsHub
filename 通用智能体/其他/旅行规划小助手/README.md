# 【通用】旅行规划（travel_planner）

## 简介

一个面向个人用户的轻量级旅行规划智能体。用户给出目的地、出发地、旅行天数、预算、交通条件和个人偏好后，它输出结构清晰、可直接执行的逐日行程方案，包含行程概览、每日安排、交通/住宿/餐饮建议、分项预算估算、注意事项和备选方案。

与仓库内已有两个旅行规划智能体的区别：本版本**不依赖任何联网搜索工具**（无 MCP、无内置工具依赖），完全由大语言模型自身的知识完成规划。对车票、机票、酒店价格、门票库存、营业时间、天气等实时信息，明确标注"需出行前核实"，不编造数据。适合作为零依赖的最简模板使用——导入后只需选一个对话模型即可运行，无需申请任何第三方 API Key。

基于 Nexent v2.8.3 开发。

> **脱敏声明**：`agent.json` 来自 Nexent 平台导出并已脱敏，不含租户 UUID 和个人邮箱。`model_ids` / `model_names` 是导出机器的本地配置，**导入后必须重新选择模型**。

## 功能

- **需求澄清**：目的地、出发地、日期、天数、预算、交通条件等信息不足时，先提出必要的澄清问题，不自行假设后硬给方案。
- **逐日行程编排**：按天给出时间段、活动内容、地点、预计耗时、交通方式和用餐安排；同区域景点集中安排，预留休息和自由活动时间。
- **预算估算**：拆分交通、住宿、餐饮、门票和其他预计开支，以区间或估算值呈现并注明币种，说明估算可能随实时情况变化。
- **约束感知**：识别预算上限、行程节奏、老人或儿童同行、饮食禁忌、无障碍需求等限制条件。
- **风险与备选**：指出天气、预约、排队、交通延误等潜在风险，并提供可替换景点或活动。
- **边界明确**：不代用户完成实际预订、支付或出票；不假装具备实时联网查询能力，无实时依据时基于通用经验规划并提示核实。

## 运行环境与依赖

| 项目 | 配置 |
| --- | --- |
| 平台版本 | Nexent v2.8.3 |
| 智能体变量名 | `travel_planner` |
| 显示名 | 旅行规划 |
| 大语言模型 | 任意对话模型（开发与验收使用 `doubao-seed-evolving`，开启思考模式） |
| 内置工具 / MCP / Skill / 知识库 | 均未使用，零外部依赖 |
| `max_steps` | 15 |
| 输出预留 Token 数 | 建议 ≥ 8192（完整行程方案较长，推理型模型的思考过程也会占用输出 token） |

## 导入与配置

1. 在 Nexent 中导入 `agent.json`。
2. 打开智能体配置 →「模型与提示词」，**重新选择模型**（导出文件里的 `model_ids` 是原机器的本地 ID，在你的环境里不存在或指向别的模型）。
3. 无需配置任何 MCP 工具或 API Key。
4. 在调试窗口用下面的示例问题验证。

## 使用示例

- 帮我规划一份 3 天 2 晚的成都旅行方案，预算 3000 元
- 推荐适合亲子游的上海周末行程
- 去云南玩 5 天怎么安排路线比较合理？
- 预算 2000 元适合去哪里短途旅行？

## 能力边界

- 天气、车票余票、酒店实时价格、景区临时限流等信息无法联网核实，回答中会以"需出行前核实"标注，请以官方渠道为准。
- 需求相互冲突时（预算过低但要求过高、天数过少但景点过多），会主动说明冲突并给出优先级建议。
