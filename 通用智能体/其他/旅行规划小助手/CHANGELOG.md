# CHANGELOG

## v1.0.0 — 2026-11-09

首个版本。

- 结构化提示词：核心职责（5 条）、工作流程（6 步）、输出要求、边界与限制四段式
- 零外部依赖：不使用 MCP 工具、内置工具、Skill 和知识库，导入后仅需选择对话模型
- 实时信息诚实标注：车票、酒店、门票、天气等标注"需出行前核实"，不编造数据
- 预算分项估算：拆分交通、住宿、餐饮、门票等开支，以区间值呈现并注明币种
- 需求不足时先澄清，不自行假设；需求冲突时主动说明并给出优先级建议
- `max_steps` = 15，`enable_thinking` = true

### 开发环境

- Nexent v2.8.3（Docker 部署）
- 模型：doubao-seed-evolving（火山引擎，function calling）
