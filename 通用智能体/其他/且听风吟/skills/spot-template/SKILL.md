# 打卡构图与机位模板

## 功能说明
提供可直接执行的拍摄模板，降低"不知道拍什么"的压力。默认用户只有手机，不假设长焦、三脚架或补光设备。

## 前置判断
1. 场景：户外（公园/老街）或室内（商场/展馆）。
2. 时段与光线：上午 / 正午 / 黄昏 / 夜间。用户没说时按当前时间推断，并在回复里带一句"按现在这个光线…"。
3. 光线不足（夜间、室内暗区）：只给稳定可拍的机位，不要求高速抓拍或逆光效果。

## 工作流程
1. **一次只给 1 个机位**，问用户要不要下一个，不要一次罗列三个。
2. 每个机位必须包含四项：
   - 【机位描述】站在哪、看向哪，**必须带可核对的可见地标**（如"东门银杏南侧第三张长椅旁"），不能只写"道路中间"。
   - 【构图提示】画面里放什么（前景、对称、留白、引导线）。
   - 【光线建议】顺光/侧光/逆光，以及对应的时段。
   - 【画面意境】拍出来是什么感觉。
3. 用户反馈后，再给下一个机位，或针对这张照片给调整建议。

## 户外场景（公园/老街）模板参考
- 机位一（纵深）：站在步道中轴，用两侧树木或建筑形成引导线；侧光时纵深感最强。
- 机位二（前景）：透过一片树叶或花枝拍远处景物，前景虚化用手机人像模式即可。
- 机位三（细节）：蹲下拍落叶、光斑或石板纹理；正午硬光时纹理最清楚。

## 室内场景（商城）模板参考
- 机位一（线条）：利用扶梯、栏杆或天花板的几何线条仰拍，靠窗自然光一侧更干净。
- 机位二（倒影）：找光滑地面或玻璃橱窗拍反射，避开直射灯光造成的过曝。
- 机位三（色彩）：找一面纯色墙，人物靠边、大面积留白，手机开网格线对齐。

## 安全与隐私边界（必须遵守）
- 不进入封闭区域、施工区、护栏外或水域边缘等危险位置；不为机位攀爬栏杆、树木、雕塑。
- 不拍摄陌生人正脸；需要人物入镜时，提醒用户征得同意，或改用背影、剪影。
- 遵守场馆规定：博物馆、展馆、店铺明确禁止拍摄时，不给该场景模板。
- 夜间只建议照明良好、有人流的区域，不推荐偏僻地点或长时间停留。

## 输出示例（单个机位）
"先试这一个：走到东门那棵银杏南侧第三张长椅旁，面朝主路。
构图：让两排树在画面两侧收拢成引导线，手机开网格线，把主体放在下三分之一。
光线：现在这个时段是侧光，树影最有层次。
感觉：一张很安静的纵深街景。
拍完告诉我效果，我再给下一个机位。"
