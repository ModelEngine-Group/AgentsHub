# 且听风吟

> 不赶路，只感受。

一个治愈系的个人探索向导「小稚」。不推荐热门景区，而是把公园、街区、商城甚至楼下的长椅，重新变成值得感受的场所。

## 一、基本信息

| 项目 | 内容 |
|---|---|
| 智能体名称 | 且听风吟 |
| 内部标识 | `wind_listener` |
| 推荐模型 | DeepSeek-V4.1-Flash（需支持工具调用，可替换） |
| 最大步数 | 15 |
| 技能数量 | 3 个 |
| 外部依赖 | 高德地图 MCP（`amap`）、可选知识库 |

## 二、解决什么问题

多数旅行智能体的目标是「把行程排满」，但真实场景里更常见的需求是：一个人想出门，又不想做攻略，只想随便走走、有点小惊喜。

这个智能体面向的就是这类需求，核心是把日常空间变成可体验的场所，输出轻量、可执行、不施压的小任务。

## 三、三层决策模型

| 层级 | 用户状态 | 处理方式 |
|---|---|---|
| 发现层 | 不知道去哪 | 调用高德 MCP 搜索真实 POI，结合天气筛选，给 1-2 个近距离选项 |
| 脚本层 | 知道去哪，不知道干什么 | 激活对应技能，一次只给一个阶段或一个机位 |
| 意义层 | 希望这次出门「有点说法」 | 优先检索知识库讲诗词渊源；无可靠命中时诚实回退 |

用户已经给出地点和明确诉求时，跳过提问直接进入对应层。

## 四、包含的技能

| 技能 | 触发场景 | 输出 |
|---|---|---|
| [color-walk](skills/color-walk/SKILL.md) | 「想随便走走」「不想动脑」「给我个小任务」 | 分阶段颜色观察任务，一次只给一个阶段 |
| [place-lore](skills/place-lore/SKILL.md) | 「这里有什么故事」「这地方有说法吗」 | 带出处的地点典故；查不到时给 2-3 个实地发现角度 |
| [spot-template](skills/spot-template/SKILL.md) | 「怎么拍」「给我个机位/模板」 | 手机可直接执行的机位、构图、光线提示，含安全与隐私边界 |

技能之间为串行关系：多个同时命中时，先完成前一个技能的一个步骤，再进入下一个，不并行输出两套内容。

## 六、导入与配置

1. 在 Nexent 平台「智能体开发」页面选择**导入**，上传本目录下的 `agent.json`。
2. 导入后重新绑定模型（原文件中的模型为 DeepSeek-V4.1-Flash，可按环境替换）。
3. 将 `skills/` 下的三个目录分别打包为 zip 上传，或直接按平台支持的方式导入技能。技能名称需与 `skill_names` 中的 `color-walk`、`place-lore`、`spot-template` 保持一致。
4. 绑定高德地图 MCP（`amap`），并确认以下三个工具可用：`maps_weather`、`maps_text_search`、`maps_around_search`。
5. 可选：为 `place-lore` 挂载与地点历史、诗词相关的知识库，未挂载时技能会自动走诚实回退。

> 注意：仓库内的 `agent.json` 保留了原作者的高德 MCP 接入地址，导入后建议替换为你自己的 MCP 服务，避免共用配额。

## 七、测试样例

| 用例 | 用户输入 | 期望表现 |
|---|---|---|
| 1 | 我在成都春熙路附近，今天天气怎么样？适合出门的话给我一个「颜色漫游」的轻任务 | 先查天气；给出主题色的两个候选；只输出第一阶段任务，不提前给第二、三阶段 |
| 2 | 我一个人在商场里随便逛逛，有什么适合在室内完成的打卡任务吗？ | 识别为室内场景，使用室内模板，不套用户外自然观察逻辑 |
| 3 | 下午想去西湖边走走，那里有什么不太为人所知的诗词渊源吗？ | 先检索知识库；有可靠出处时给出诗词名、作者、朝代；无命中时明确说明并给发现角度 |
| 4 | 心情有点闷，想在家附近找个能吹风的地方，你能推荐一个吗？ | 需先获取位置；位置缺失时温和询问地标，不编造坐标与 POI |
| 5 | 给我一个拍照机位 | 一次只给 1 个机位，且必须带可核对的可见地标；附带安全与隐私提醒 |

## 八、本地验证

验证环境：

- 平台：Nexent 在线环境
- 模型：DeepSeek-V4.1-Flash
- 高德 MCP：`amap`（`maps_weather`、`maps_text_search`、`maps_around_search`）

| 用例 | 结果 | 实测表现 |
|---|---|---|
| 用例 1（户外 + 天气前置） | 通过 | 先返回成都多云、白天 17℃ / 夜间 11℃，再给任务；给出砖红、灰蓝两个候选；只输出第一阶段并标注建议 10 分钟；说明找不到 3 种材质也可完成 |
| 用例 2（室内场景转换） | 通过 | 识别商场室内场景，改用橱窗、标牌、灯光的寻找任务，未套用户外自然观察逻辑 |
| 用例 3（知识库命中 / 回退） | 通过 | 未检索到可靠出处时明确说明「暂时没查到可靠的出处」，未编造诗词；改为推荐西泠印社碑廊等真实地点，并给出可自行发现的观察角度；附带雨天防滑与拍摄前征询提醒 |
| 用例 4（坐标缺失时不编造） | 通过 | 主动索要城市、地标或坐标，未生成虚构 POI，也未编造坐标；说明拿到位置后会先查天气再推荐 |
| 用例 5（单机位输出与安全提醒） | 通过 | 仅输出 1 个机位（纵深银杏道），给出网格线构图、蹲低视角与压半档曝光的可执行建议；提示不站到栏杆外或水边。待优化：机位缺少「东门左手边」这类可核对地标；「拍背影不用征得同意」的措辞与拍摄礼仪边界不一致 |

## 九、使用边界

- **不编造地点**：所有 POI 必须来自高德 MCP 的实际返回，没有返回就说明「附近信息暂时拿不到」。
- **不编造典故**：诗词引用必须给出诗名、作者、朝代；三者不全则标注待核实或不引用。
- **不做危险推荐**：夜间不推荐偏僻地点，不为拍照建议攀爬或进入封闭区域。
- **尊重隐私**：不引导拍摄陌生人正脸，不复述用户的精确坐标。
- **不做承诺**：不提供门票预订、价格或余位的确定性承诺，涉及实时信息统一提示以现场为准。

## 十、与同类智能体的区别

| 维度 | 常规行程规划智能体 | 且听风吟 |
|---|---|---|
| 目标 | 覆盖更多景点 | 感受少量场所 |
| 输出 | 按天完整行程表 | 单步小任务，完成再继续 |
| 空间范围 | 跨城旅行 | 公园、街区、商城等日常空间 |
| 交互节奏 | 一次性给全量信息 | 一次只推进一步 |
| 失败处理 | 常用「据说」「相传」填充 | 明确说明查不到，并给实地发现角度 |
