# 旅游规划助手-Pro

基于 Nexent 构建的旅行规划智能体。用户用自然语言描述出行需求，助手会自动提取关键信息、补齐缺失条件，并按天输出结构化行程、预算核算与可信来源标注。

## 功能

- **需求提取与追问**：从自然语言中提取目的地、出发地、天数、预算、出行时间与同行人构成；必填信息缺失时主动追问，模糊表达转为可选项
- **偏好采集**：收集忌口、行动限制、签证状态与行程节奏偏好
- **按天行程**：输出景点、餐饮、交通耗时、住宿区域与每日花费小计
- **合理性校验**：校验营业时间、重复安排与绕路，预算按类目核算并预警超支
- **可信度标注**：关键信息标注可信度与来源获取时间
- **后续调整**：支持局部修改、备选方案对比、可预订卡片跳转、天气联动及行程导出

## 依赖

- **模型**：需在平台中配置可用的大语言模型（导出配置中为 `deepseek-flash`，导入后请按实际环境重新选择）
- **工具**：文件分析、目录/文件读写与管理、`deepseek_search` 联网搜索
- **技能**：`analyze-image`（图片分析）、`canvas-design`（行程画布设计），见同目录 `skills/` 下的 zip 包，需先在平台「选择技能 → 构建技能」中上传

## 使用说明

1. 先上传 `skills/` 目录下的两个技能 zip 包
2. 在 Nexent 中导入同目录下的 `agent.json`
3. 为智能体选择实际可用的大语言模型
4. 安装并确认所需的 MCP 工具（如联网搜索）
5. 为 `deepseek_search` 工具配置**你自己的** DeepSeek API Key（见下方说明）
6. 发布后即可开始对话

> **API Key 说明**：本仓库中的 `agent.json` 不包含任何 API Key。导入后请在平台的凭据/工具配置中填入自己的 DeepSeek API Key，否则 `deepseek_search` 工具调用会失败，联网搜索能力不可用。

## 示例对话

- 从上海出发，5 月去日本 6 天，两个人，预算一万五，帮我规划行程。
- 把第二天下午的咖啡馆换成离酒店近一点的，其他安排不要动。
- 雨中备选方案给我一份，顺便提醒要带的衣物。
- 这趟行程按住宿、餐饮、交通分别花了多少？

## 注意事项

- 天气、开放时间、票价、交通班次和费用等信息可能变化，使用前请向官方渠道核实
- 联网搜索能力依赖 `deepseek_search` 工具及导入方自行配置的 DeepSeek API Key，未配置时仅能基于模型已有知识作答
- 预算核算为估算值，实际花费以预订结果为准
