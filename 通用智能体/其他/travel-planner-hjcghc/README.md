# 旅游规划助手

旅游规划助手是基于 **Nexent** 构建的中文智能体，面向自由行、短途出游和家庭旅行等场景。它通过多轮对话了解旅行条件，结合城市知识库生成每日行程、分项预算和出行提醒，并根据用户反馈调整安排。

当前配套资料以杭州为例，覆盖西湖、浙江省博物馆、良渚文化参访，以及轻松游规则、雨天替换建议和预算计算示例。其他城市可按相同方式补充资料并绑定知识库。

## 主要功能

| 功能         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 旅行需求收集 | 确认出发地、目的地、日期或天数、人数、预算及其包含范围、兴趣偏好和行动限制；信息不足时先追问。 |
| 每日行程规划 | 按天安排活动、交通、用餐与休息，并考虑用户的出行节奏。       |
| 个性化调整   | 根据自然风景、历史文化、美食等偏好，以及老人、儿童等同行情况调整活动强度。 |
| 预算估算     | 分别列出住宿、餐饮、市内交通、门票等费用，统一每人或全体口径，核对分项与合计。 |
| 城市资料检索 | 通过 `knowledge_base_search` 检索已绑定的城市知识库，参考相关条目并注明资料来源。 |
| 行程修改     | 根据雨天、体力或预算变化修改受影响的安排，保留其他已确认条件。 |

智能体的基本工作流程为：**收集需求 → 检索城市资料 → 生成行程与预算 → 根据反馈调整**。

## 文件说明

提交到 AgentsHub 时，建议将配置与资料放在同一个智能体目录下：

```text
旅游规划助手目录/
├── agent.json                  # Nexent 平台导出的智能体配置
├── README.md                   # 功能介绍与知识库绑定教程
├── CHANGELOG.md                # 版本记录
├── knowledge/
│   └── 杭州旅游知识库.txt        # 用于创建知识库的原始资料
└── screenshots/                # 可选：实际运行截图
```

`agent.json` 用于导入智能体配置，`knowledge/` 中的文件用于在目标环境重建知识库。知识库的索引和访问权限需要在目标 Nexent 环境中配置。

## 导入智能体

1. 登录 Nexent，进入 **智能体开发 → 智能体配置**。
2. 点击 **导入**，选择本目录中的 `agent.json`。
3. 打开导入后的“旅游规划助手”，检查并选择当前环境可用的大语言模型。
4. 按下方教程创建、上传并绑定城市知识库。
5. 完成调试后发布，在正式问答入口使用。

如果已经在平台中创建了这个智能体，可以直接进行知识库绑定。

## 城市知识库内容

配套文件 `杭州旅游知识库.txt` 包含以下内容：

| 内容                 | 用途                                                 |
| -------------------- | ---------------------------------------------------- |
| 杭州轻松游规则       | 为每日活动数量、午间休息和行程节奏提供项目默认建议。 |
| 西湖文化景观         | 为自然风景与文化主题规划提供基础资料。               |
| 浙江省博物馆         | 提醒规划时区分馆区，并核查对应参观规则。             |
| 良渚博物院与遗址公园 | 帮助区分参访地点，预留转换地点的时间。               |
| 雨天替换建议         | 提供室内活动候选及调整思路。                         |
| 三天两人游预算示例   | 展示住宿分摊、分项求和与剩余预算的计算方法。         |

文件中分别标明官方事实摘要、项目规划建议和假设预算，保留来源链接及整理日期。示例费用用于说明计算方法，实际规划时应根据用户选择和查询结果更新。

## 知识库创建与绑定教程

以下以知识库名称 **杭州旅游资料** 为例。如果使用其他名称，请在工具设置和相关提示词中使用实际名称。

### 第一步：准备模型

在 **智能体开发 → 模型配置** 中确认两类模型可用：

| 模型类型              | 用途                                     |
| --------------------- | ---------------------------------------- |
| 大语言模型（LLM）     | 理解用户需求、调用工具并生成旅行方案。   |
| 向量模型（Embedding） | 将城市资料转换为可供知识检索使用的表示。 |

创建知识库时，选择平台中已配置的向量模型。若下拉列表为空，先完成向量模型配置。

### 第二步：创建知识库并上传资料

1. 进入 **智能体开发 → 知识库配置**，点击 **创建知识库**。
2. 名称填写 **杭州旅游资料**，选择可用的向量模型。
3. 建议开启 **保留源文件**；若界面提供用户组或权限选项，确保使用智能体的账号具有检索权限。
4. 上传 `knowledge/杭州旅游知识库.txt`，等待处理状态变为 **已就绪**。

文件处理成功后才可正常检索。操作入口与状态说明可参考 [Nexent 知识库配置文档](https://modelengine-group.github.io/nexent/zh/user-guide/agent-development/knowledge-configuration.html)。

### 第三步：为智能体绑定检索工具

1. 返回 **智能体配置**，选择“旅游规划助手”。
2. 展开 **工具与技能**，点击 **选择工具**。
3. 找到并启用 **知识库检索 `knowledge_base_search`**；列表未更新时可先点击“刷新工具”。
4. 点击工具的设置按钮，在知识库列表中选中 **杭州旅游资料**。如果界面显示 `index_names`，在这里确认目标知识库范围。
5. 按界面提示完成必填参数，保存设置，并确认该工具已出现在智能体的已选工具列表中。

模型兼容性和工具配置方式可参考 [Nexent 智能体配置文档](https://modelengine-group.github.io/nexent/zh/user-guide/agent-development/agent-configuration.html)。

### 第四步：明确知识库使用规则

在智能体的 **使用要求** 中加入或检查以下内容：

> 处理杭州旅游请求时，先使用知识库检索工具查询“杭州旅游资料”，再结合用户需求生成方案。引用相关资料时注明资料名称和来源链接。区分官方事实、项目建议与假设预算；实时票价、开放时间、预约情况及天气需要另行核实，无法核实时明确说明。

### 第五步：验证绑定效果

点击 **调试**，发送：

> 请检索“杭州旅游资料”，告诉我资料中的“杭州轻松游”每天最多安排几个主要活动，午间至少预留多久？请注明资料名称。

配套资料中的预期答案为：**每天最多2个主要活动，午间至少预留1小时用于用餐和休息**。这属于本项目的默认规划建议，可根据用户要求调整。

同时检查调试运行记录：应能看到 `knowledge_base_search` 的实际调用，以及包含相关内容的返回片段。答案正确且有实际检索记录，才能确认绑定有效。

验证完成后保存并发布。如果更换了知识库或修改了工具绑定，请重新调试，并在发布后导出最新配置。

## 对话示例

### 生成旅行计划

> 我从上海出发，去杭州玩三天，两名成年人，人均预算1500元，不包含上海到杭州的往返交通，包含两晚住宿、餐饮、市内交通和门票。日期暂未确定，偏好自然风景和美食，希望节奏轻松。请先按公共交通和经济型住宿生成草案，明确假设，并给出每日行程、预算汇总、预约提醒和雨天备选方案。

### 调整已有行程

> 假设第二天下雨，请将第二天改为以室内活动为主，减少步行。其他条件保持不变，并重新核算受影响的费用。

完整方案按 **需求摘要、每日行程表、预算汇总、出行提醒、雨天备选** 的顺序组织。无法核实的费用或规则应标注为估算或待核实。

## 常见问题

| 问题                           | 排查方向                                                     |
| ------------------------------ | ------------------------------------------------------------ |
| 创建知识库时没有向量模型可选   | 到“模型配置”检查是否已配置可用的 Embedding 模型。            |
| 上传后显示解析失败或入库失败   | 查看状态图标的错误提示，按原因检查文件内容、模型服务或平台处理服务。 |
| 助手回答了问题，但没有检索记录 | 检查工具是否启用、知识库范围是否选中，以及使用要求是否明确要求检索。 |
| 检索不到已上传的资料           | 检查文件是否已就绪、当前账号是否有权限，以及知识库和检索所用向量模型是否兼容。 |
| 导入其他环境后无法查询原知识库 | 在目标环境上传原始资料，重新创建或选择可访问的知识库，再绑定检索工具。 |

## 扩展与使用范围

扩展其他城市时，可按“景点或场馆名称、地点、主题、事实摘要、规划建议、来源链接、整理日期”的格式补充资料，再上传到对应知识库并更新检索范围。

当前城市资料用于辅助规划。天气、票价、开放时间、预约余量和住宿价格具有时效性，需按出行日期核实。智能体提供旅行建议，实际订票、付款和酒店预订需要通过相应服务完成。
