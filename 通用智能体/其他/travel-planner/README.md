# 旅游规划助手

基于 Nexent 的旅行规划智能体，根据目的地、时间、人数、预算及偏好生成分日行程和预算参考；配置可用的 DeepSeek 搜索工具后，可以检索天气、景点与交通等信息，并提示用户核实来源。

## 前置条件

- 可使用的 Nexent 实例及有智能体开发权限的账号。
- 已配置并通过连通性测试的大语言模型。导出文件按展示名称 `deepseek-flash` 查找模型；导入前应先配置同名模型。
- 如需联网搜索，在 Nexent 中配置并测试 `deepseek_search` 工具及其服务授权。密钥应在运行环境中单独配置，不要写进仓库文件。

## 导入和使用

1. 在 Nexent 中进入智能体开发或 Agent 仓库的导入入口，选择本目录中的 `agent.json`。
2. 按导入提示检查模型、搜索工具及其他依赖；根据本地环境重新绑定可用模型并配置搜索工具。仓库中的搜索密钥为空，必须在目标环境中自行填写。搜索工具保持启用但密钥为空时，部分 Nexent 版本可能在启动智能体时失败；如暂时不需要搜索，请取消选择该工具并保存。
3. 输入目的地、天数、人数、预算口径和兴趣偏好，例如：

   > 从上海出发，两个人周末去杭州玩两天，不含往返大交通预算共 2000 元，喜欢自然风景和当地美食，不想太赶。

4. 对于天气、票价、预约规则和开放时间，打开引用来源核对日期和内容；重要出行信息以相关官方渠道最新公布为准。

未配置搜索工具时，智能体只能提供基于已有知识和用户输入的建议，无法保证信息实时。

## 功能与限制

- 信息不足时追问目的地、时长、预算等关键条件。
- 生成分日行程、交通建议和分类预算，并标注估算与待核实事项。
- 对明显紧张的预算提示冲突，提供调整方案。
- 对实时或变化较快的信息，搜索结果仅作线索，仍需核实引用与官方信息。
- 不负责订票、支付或确认酒店库存。

## 测试记录

在本地 Nexent 环境中进行过以下人工调试：

| 场景 | 输入或条件 | 已观察到的结果 |
| --- | --- | --- |
| 常规规划 | 上海出发，两人杭州两天，预算 2000 元，不含往返大交通 | 输出分日行程和分类预算；示例预算合计计算正确。交通时间与地点安排未逐项验证。 |
| 信息不足 | “帮我规划一次旅行” | 用自然语言询问目的地、出发地、时长、人数、预算和偏好。 |
| 预算冲突 | 四人北京往返三亚五天，预算 1000 元含交通和住宿 | 提示预算冲突，询问预算口径并给出调整方向；具体费用需按日期核实。 |
| 搜索 | 查询杭州次日天气及灵隐寺门票 | 输出带来源标记的回答；运行日志记录两次搜索请求返回 HTTP 200。尚未逐条核实引用页面与事实。 |
| 脱敏配置导入 | 在同一租户导入本目录的 `agent.json` | 成功导入；同名提示需要更名。搜索工具密钥留空，测试副本尚未完成重新配置密钥后的对话验证。 |

联网结果依赖模型、工具和数据来源，不同配置或测试时间可能得到不同结果。导入后的可用性需要在目标环境重新验证。

提交版配置去除了原环境的租户 ID、模型 ID、模型参数覆盖和搜索密钥。原导出包包含已在智能体中关闭的 `docx` 技能；该技能及其引用未纳入本目录。
