# CHANGELOG

## V1 — 2026-11-02

首个版本，基于 Nexent v2.8.3 构建。

- 新增「行程管家·旅游规划助手」智能体定义（`agent.json`），由平台导出后脱敏。
- 需求抽取覆盖出发地、目的地、日期/天数、人数、预算、偏好与特殊需求；关键信息缺失时一次性追问。
- 行程编排以可执行为目标：逐日时间轴、点对点交通与耗时、就近聚类、首尾日扣除抵离时间。
- 强化节奏控制：每日高强度点位不超过 2 个，同行有老人或儿童时进一步放缓。
- 预算按六科目估算并要求三处对账（行程条目 / 每日小计之和 / 明细表合计），备用金单列不摊入每日小计；超预算时输出住宿降档、交通替代、门票取舍三档降本方案及组合方案。
- 接入 `deepseek_search`：实时票价、开放时间、天气类问题必须检索并标注来源与查询日期，检索失败标为「待核实」。
- 支持多轮增量修订，仅输出变更项并重新核算预算。
- 已在 Nexent v2.8.3 + DeepSeek 模型上完成实测：行程预算用例产出可对账的 1610 元预算表与四选一降本方案；实时信息用例触发工具调用并标注官方来源与查询日期。
- 导出文件已脱敏：`deepseek_api_key` 置空，`tenant_id` 与作者信息已清理；同时移除仅运行时有效的工具参数 `language`，确保文件可被再次导入（平台原始导出无法往返导入）。
