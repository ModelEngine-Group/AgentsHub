# 【通用】旅游规划助手（travel_planner）

## 简介

一个**零外部依赖**的行程规划智能体：用户给出目的地、天数、预算和同行人信息后，输出可直接照着走的逐日行程表、分项预算估算、实用贴士和备选方案。

只靠提示词驱动，**不需要联网搜索、不需要知识库、不需要配置任何 API Key**，导入后选个模型即可使用，适合作为入门模板或教学示例。

> **与仓库内已有旅游类智能体的区别**：`BudgetTravelPlanner-Agent`、`Lushu-TravelPlanner` 等版本依赖 `tavily_search` 等工具做实时核实，导入后必须填自己的搜索 Key；本版刻意做成**零依赖**——不查实时数据，只做结构化规划，涉及票价/开放时间一律要求标注「约 / 以官方为准」，因此开箱即可跑通，适合作为基础模板二次开发。

## 功能

- **信息不足先追问**：目的地、天数、预算、同行人缺失时，一次性最多追问 3 个问题，不自行假设后硬给方案。
- **结构化输出**：固定为「行程概览 → 每日表格 → 预算汇总 → 实用贴士 → 备选方案」五段，每日安排用表格呈现（时间段 / 安排 / 交通方式 / 预估费用 / 备注）。
- **预算可核对**：交通、住宿、餐饮、门票、其他分项给出区间和合计，超出预算时明确说明缺口并给压缩方案。
- **人群适配**：带老人或小孩时自动放慢节奏、减少单日景点数量。
- **不编造精确数字**：不确定的票价、开放时间统一标注「约」或「以官方为准」，需要假设时显式标注为假设。

## 导入与配置

1. 在 Nexent 的「智能体配置」页面点击 **导入**，选择本目录的 `agent.json`。
2. 打开智能体 →「模型与提示词」→ **重新选择模型**（导出文件中的 `model_ids` 是原机器的本地 ID，在你的环境里不存在，必须重选；建议选支持中文长输出的模型，输出预留 Token 不低于 8192）。
3. 确认「开场白与示例问题」已带入（共 4 条示例），保存后即可在调试窗口试跑。
4. 满意后点击 **发布**，即可在「智能体对话」中使用或生成体验链接。

## 使用示例与预期输出

### 示例 1：信息完整

输入：

```
成都 3 天 2 晚，两个人，预算 2000，重点是美食
```

预期：先给一句整体思路（如"按人均 1000 控制，住春熙路周边，主打小吃+一顿火锅"），随后输出三天表格行程、分项预算（交通/住宿/餐饮/门票/其他）、3~5 条贴士和一条"若预算吃紧"的备选方案。

### 示例 2：信息缺失

输入：

```
我想出去玩
```

预期：不直接给方案，一次性追问 3 个问题（去哪 / 几天 / 预算与同行人），并说明信息齐了之后会怎么做。

### 示例 3：需求冲突

输入：

```
北京 5 天，人均预算 500
```

预期：指出预算与天数不匹配（住宿+门票就会超），给出压缩方案（如改为 2 天、住五环外、只保留免费景点），不硬凑一个"看起来合理"的总价。

## 已知边界

- 不联网，无法给出实时票价、天气、班次、预约余量；需要实时数据时请配合 `tavily_search` 等搜索工具做二次开发。
- 预算中的餐饮、市内交通属于经验估算，已在输出中标注，请以实际消费为准。
