# 旅游规划助手｜预算与备选行程

根据同行人数、旅行节奏和总预算安排行程。支持低步行强度路线、按房或按人核算费用，以及遇到下雨或临时闭馆时切换同区域活动。

## 导入

1. 在 Nexent 智能体仓库导入本目录的 `agent.json`。
2. 在模型管理中选择一个可用的中文对话模型。本地开发使用 Qwen3 4B，模型显示名为 `qwen3-local`。导入时可映射到本机已有模型。
3. 在智能体配置中预览并发布。

## 示例

- 「想带家人出去玩，预算有限。」
- 「从上海到苏州玩两天，日期待定，住一晚。三人同行，其中一位老人。预算 1800 元含往返，想看园林和博物馆，请安排低步行路线和一项雨天备选。」
- 「两人去杭州三天，合住一间房两晚，300 元/间/晚，往返交通每人 200 元，总预算 900 元。」

门票余量、开放时间、天气与票价由用户在出发前向官方渠道核实。行程内的费用属于规划估算。
