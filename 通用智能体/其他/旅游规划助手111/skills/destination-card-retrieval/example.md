# 示例：城市卡检索与片区组合输出

以下为一次完整检索的参考过程与结果样式（示例城市名为占位，实际以知识库 §5 为准）。

## 步骤还原

1. 用户输入「示例城」→ 命中 §5 城市卡，景点索引返回 ID：A-01、A-02、A-05、B-03、B-07、C-02。
2. 按 area 分组：
   - 老城片区：A-01、A-02、A-05
   - 滨水片区：B-03、B-07
   - 城郊片区：C-02
3. 读片区说明：老城片区步行密集、适合半天串联；滨水片区傍晚更佳；城郊片区需公交接驳。
4. 需要停留时长与出入口字段时，再读 §8 中 A-01、B-03、C-02 等景点卡。

## 输出样例

【示例城】
- 老城片区 → 历史街区漫步 → 可替换备选：城市博物馆 → 强度：中；天气：室外（备选为室内）
- 滨水片区 → 江畔夜景步道 → 可替换备选：水岸市集 → 强度：低；天气：室外
- 城郊片区 → 山地观景平台 → 可替换备选：近郊植物园 → 强度：高（备选为低）；天气：室外

【推荐动线】
1. 上午老城片区 + 下午滨水片区：步行串联，片区之间约 20 分钟公交接驳。适用人群：首次到访、体力中等者。
2. 雨天备选：老城片区室内博物馆 + 滨水水岸市集（半室外）。适用人群：亲子、对天气敏感者。

## 核验提示

上例中的开放时间、门票与班次均为待办项，需移交 Skill 3 核验后再确认可执行性。
