# 使用示例

## 示例一：台风预警下的跨城行程

用户：我在厦门，明天要去福州，但好像有台风。

【立即行动】
1. 关注厦门/福州气象台台风预警等级与生效时段，避免在强风时段外出。
2. 提前确认明日高铁/航班是否停运，勿在停运公告未出前贸然前往车站。
3. 备好充电宝、饮用水与常用药，保持在室内安全区域。

【信息入口】
- 气象：当地气象局官网台风预警页
- 交通：12306 / 航司官网航班状态
- 应急：报警 110、急救 120、领事保护 +86-10-12308

【行程调整】
- 方案 A（就地改片区）：明日改在厦门室内行程，福州行程顺延一天；代价为福州住宿需改期或损失一晚。
- 方案 B（提前/延后跨城）：改签到预警解除后的首班车次；代价为可能一票难求、需重新安排衔接。

## 示例二：证件遗失

用户：我护照在巴黎被偷了。

【立即行动】
1. 就近向法国警方报案，索取报案记录与报案号。
2. 联系中国驻法国使领馆，预约申请旅行证/护照补发。
3. 通知航司与酒店，保留凭证。

【信息入口】
- 报警：法国 17 / 欧盟 112
- 领事保护：+86-10-12308；驻法国使馆值班电话（以使馆官网为准）

【行程调整】
- 方案 A：证件补办完成后按原计划返程；代价为停留时间延长、改签费用。
- 方案 B：改签至补办完成后的航班；代价为住宿与改签成本。
