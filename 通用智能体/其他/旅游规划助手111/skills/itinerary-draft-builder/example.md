# 示例：行程初稿一次完整产出

## 输入（用户提供）
- 同行者：2 人，均成人，少行李
- 到达：D1 10:20 高铁抵达城市 A 站
- 离开：D3 16:30 城市 A 站发车
- 住宿：A 市老城区酒店，D1–D3 不换住
- 必去点：A 市博物馆、老城街区、滨江观景带

## 第一步：锚点与可用时长
| 锚点 | 当地日期时间 | 说明 |
| --- | --- | --- |
| 到达 | D1 10:20 | 高铁站 |
| 离开 | D3 16:30 | 需 14:30 前到站 |

- D1 可用时长：10:20 到站 + 出站取行李 20 分钟 + 到酒店寄存 30 分钟 ≈ 11:10 起可用，至 20:00 约 8.5 小时（含午晚餐）。
- D3 可用时长：D3 09:00 起至 14:30 需到站 ≈ 5.5 小时（含午餐），**不安排定时门票**。
