# 旅游规划助手

## 简介

根据用户提供的出发地、目的地、天数、同行人数等信息，规划涵盖**行程安排、交通、住宿、餐饮、预算和景点游览**的完整旅行方案，并提示签证、安全和饮食（如素食）等注意事项。旅行风格和具体约束会在规划前向用户确认，最终以清单形式输出旅行方案。

核心差异：不靠一个巨型 Prompt 硬生成，而是把规划拆成 **5 个可独立复用、可单独迭代的技能**，由主智能体按顺序编排。

## 功能特性

### 五段式规划流水线

| 顺序 | 技能 | 作用 |
|---|---|---|
| ① | `travel-need-clarifier` | **需求澄清**：把「想去某地玩」这类模糊需求问清、归一化日期、标注日期风险、判断签证入境条件 |
| ② | `destination-card-retrieval` | **目的地检索**：按城市名/别名定位知识库中的城市卡，提取景点并按片区归组，输出候选景点、体力强度、天气敏感度标签与推荐动线 |
| ③ | `itinerary-draft-builder` | **行程编排**：产出时间可行、片区合理、可替换调整的行程初稿，核算转场与可用时长，生成备选方案 |
| ④ | `itinerary-fact-check` | **事实核验**：把开放时间、门票价格、交通班次、天气预警、签证入境、路线估时等易变字段，标成四种可追溯的证据状态，**不臆造结论** |
| ⑤ | `travel-safety-emergency` | **安全应急**：遇到气象预警、交通停运、突发中断、健康就医、证件遗失或治安事件时，给出应急指引与行程调整方案 |

### 证据状态机制

`itinerary-fact-check` 把每条事实归入四类之一：

- **已核实** —— 有明确来源
- **常规规则可用于初稿** —— 稳定常识（如多数博物馆周一闭馆）
- **估算** —— 路线时长等推算值
- **待核验** —— 必须出行前确认

输出里会明确标注，而不是把估算值混在事实里一起说。

## 技术架构

### 模型

`agent.json` 未写死模型，导入后按平台提示绑定当前环境可用的大模型即可。

### 工具

| 工具 | 类型 | 说明 |
|---|---|---|
| `tavily_search` | 平台内置 | 联网搜索，用于实时信息（开放时间、票价、天气） |
| `knowledge_base_search` | 平台内置 | 知识库检索，`top_k=3`、`hybrid` 混合检索，用于目的地城市卡 |

### 协作方式

单个主智能体 + 5 个技能（无子智能体、无自定义 MCP）。

## 使用示例

用户输入：

```
两个人从上海出发去杭州玩两天，预算总共 2000 元，偏好慢节奏。
```

智能体流程：

1. `travel-need-clarifier` —— 确认日期、同行人构成、特殊需求
2. `destination-card-retrieval` —— 检索杭州城市卡，按片区归组景点
3. `itinerary-draft-builder` —— 排两日行程、核算转场与预算
4. `itinerary-fact-check` —— 标注开放时间、票价、班次的证据状态
5. `travel-safety-emergency` —— 遇到天气预警时给备选方案

输出：分项预算表、总额与人均、每日行程表、雨天备选、待核验清单。

## 导入方式

按下面顺序做，**顺序不能换**（技能要先装，否则导入时找不到）：

1. **绑定模型**：导入过程中平台会让你选模型，选当前环境已开通的大模型。
2. **先装技能**：智能体开发 → 选择技能 → **构建技能**，上传 `skills/` 下的 5 个 `.zip` 各一次。
3. **再配知识库**：`agent.json` 里的 `knowledge_base_search` 绑的是原环境的索引，导入后需要**重新指向你自己的知识库**；没有知识库时，用 `destination-card-retrieval` 的技能说明手工建一个城市卡库，或先只靠联网搜索运行。
4. **填搜索 Key**：见下方「安全处理说明」。
5. **导入智能体**：智能体开发 → 导入 → 选 `agent.json`。

## 安全处理说明

本目录的 `agent.json` 相对平台导出原件做了两处处理，均为**公开发布必要**：

1. **移除了真实 Tavily API Key**，替换为占位符 `YOUR_TAVILY_API_KEY_HERE`。
   使用前请到 [tavily.com](https://tavily.com) 申请自己的 Key，把它填回 `tavily_search` 工具的 `params.tavily_api_key`。
   不填的话，联网搜索工具会调用失败，其余技能仍可运行（但「待核验」项会变多）。
2. **知识库索引名保留原值**（`knowledge_base_search.params.index_names`），仅作结构参考，导入后必须重新绑定，否则检索为空。

除此之外，`agent.json` 的结构、提示词、技能绑定关系与平台导出原件一致。

## 边界与免责

- 价格、开放时间、班次、天气、签证政策均为**易变信息**，助手只能标注证据状态，**出行前请以官方渠道复核**。
- 预算为估算值，不含临时涨价、汇兑波动与个人消费差异。
- 签证与入境结论仅为条件判断，**不构成法律或移民建议**，以使领馆与官方公告为准。
- 安全应急内容不替代当地报警、急救与领事保护渠道。
- 助手不会代用户预订、支付或出具票据。
