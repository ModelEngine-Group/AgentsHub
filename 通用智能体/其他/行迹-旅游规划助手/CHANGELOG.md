# CHANGELOG

## v1.0 — 2026-11-09

首个版本。

- 基于 Nexent v2.8.3 构建，模型 `deepseek-ai/DeepSeek-V3`
- 七段式系统提示词：角色 / 工作流程 / 输出模板 / 准确性约束 / 工具规则 / 风格 / 多轮修改
- 绑定内置文件工具：`create_file`、`read_file`、`list_directory`，支持行程导出为 Markdown
- 预算表强制对账：合计 = 各行小计之和，并输出与用户预算的差额
- 澄清策略：关键要素缺失时最多追问 3 个问题，信息足够直接出方案
- 附带迎宾语与 6 个示例问题，覆盖国内外、亲子、自驾、导出、短途等场景
