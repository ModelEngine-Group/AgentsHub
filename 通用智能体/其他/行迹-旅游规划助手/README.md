# 行迹 · 旅游规划助手

> 输入「去哪、几天、多少预算」，输出一份能直接照着走的行程单：逐日行程表、逐项预算对账、行前清单，还能一键导出 Markdown 文件。

- **分类**：通用智能体 / 其他
- **适用场景**：国内城市深度游、自然风光线路、亲子与长辈同行、自驾环线、出境自由行
- **推荐模型**：`deepseek-ai/DeepSeek-V3`（指令跟随强、长表格输出稳定）
- **版本**：v1.0

---

## 能做什么

| 能力 | 说明 |
|---|---|
| 需求澄清 | 从一句话里提取「目的地 / 天数 / 时间 / 人数 / 预算 / 偏好」六要素，只在关键信息缺失时提问，一次最多 3 个问题并给默认值 |
| 逐日行程 | 每天按时段（上午 / 午餐 / 下午 / 晚餐 / 夜间）输出表格，含交通方式与人均花费 |
| 预算对账 | 分类明细 → 合计 → 人均，并与用户预算对比差额；合计必须等于各行小计之和 |
| 行前清单 | 证件与票据 / 衣物与装备 / 药品与个护 / 需提前预订 四组待办 |
| 备选方案 | 雨天替代、太赶时的删减建议、按同行人群（带娃 / 长辈 / 情侣 / 独行）调整 |
| 导出文件 | 说「导出 / 保存 / 发我一份」，把完整行程写成 `itinerary_<目的地>_<N>天.md` |
| 多轮修订 | 「太赶了」「预算降一点」「换成亲子版」时只改受影响段落，并重新给出对账后的预算 |

## 快速开始

1. 登录你的 Nexent 平台，进入 **智能体开发 → 导入**
2. 上传本目录下的 `agent.json`
3. 导入向导中把模型映射到你环境里已有的对话模型（推荐 DeepSeek-V3 或同级别指令跟随模型）
4. 确认工具 `create_file` / `read_file` / `list_directory` 可用（平台内置，无需额外配置）
5. 保存 → **发布** → 在「智能体对话」里选择「行迹 · 旅游规划助手」即可使用

> 本智能体不依赖自定义 Skill 与 MCP，导入后即可运行；不需要任何 API Key。

## 使用示例

**示例一：完整规划**

```
帮我规划成都 4 天 3 晚，两个人，人均 3000 元，想吃地道美食，节奏不要太赶
```

输出结构：行程概览表 → Day1–Day4 时段表 → 预算明细（合计 / 人均 / 与预算差额）→ 行前清单 → 备选与调整 → 需要确认的问题。实测结果：合计 ¥5508、人均 ¥2754，相比 ¥3000 预算结余 ¥246。

**示例二：信息不足**

```
我想出去玩
```

预期：一次问 2–3 个关键问题（去哪 / 几天 / 预算），并给出建议默认值，而不是抛回一串问卷。

**示例三：多轮修订**

```
太赶了，把第三天下午的行程去掉，预算降到人均 2500
```

预期：只调整第三天相关段落，开头一句话说明改了什么，末尾重新给出对账后的合计。

**示例四：导出**

```
把刚才那份行程导出成文件，我要发给同行的朋友
```

预期：调用 `create_file` 写入 `itinerary_成都_4天.md`，并告知文件名与结构。

## 配置说明

| 项 | 值 | 说明 |
|---|---|---|
| 智能体变量名 | `travel_planner` | 仅字母/数字/下划线 |
| 最大运行步数 | 8 | 规划任务通常 5–8 步，过小会被截断 |
| 输出预留 | 4096 tokens | 行程表格较长，给少了会被截断 |
| 提供运行摘要 | 开启 | 便于排查它调用了哪些工具 |
| 自验证 | 关闭 | 开启会显著增加耗时，本场景收益有限 |
| 绑定工具 | `create_file`、`read_file`、`list_directory` | 文件读写，用于导出与回看历史行程 |
| 依赖 Skill / MCP | 无 | 导入即用 |

## 提示词设计要点

提示词采用「角色 → 工作流程 → 输出模板 → 准确性约束 → 工具规则 → 风格 → 多轮修改」七段式，其中四处是效果关键：

1. **写死输出模板**：标题层级、表格列名全部指定，输出结构才稳定，而不是每次换格式。
2. **写死对账规则**：「合计 = 各行小计之和（先算再写）」。不加这句，模型经常凭感觉给合计，预算表就是废的。
3. **写死不准编造**：价格一律标「约 XX 元（以官方为准）」，不确定店名时只写品类与商圈（如「春熙路附近的川菜馆」），免费景点标免费。
4. **写死工具调用条件**：只有用户说「导出 / 保存 / 生成文件」时才建文件，避免每轮都去写文件。

## 已知限制

- **价格与开放时间是估算值**，不联网，不查询实时票价与天气；出行前请以景区 / 官方渠道为准。
- **不做真实预订**：不订票、不订房、不支付，也不会声称已经订好。
- **小模型效果有限**：在 7B 级别模型上多步工具调用协议易失败（表现为把 Markdown 塞进代码块、反复试探），建议使用 DeepSeek-V3 或同级别模型。
- **模型容量需配好**：若导入环境中模型的「上下文窗口 / 最大输出」为空，Nexent 可能按 `max_tokens=1` 调用，表现为只回几个字。请在模型配置中补全（DeepSeek-V3：上下文 164000、最大输出 8192）。
