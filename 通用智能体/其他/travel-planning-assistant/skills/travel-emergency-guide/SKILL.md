# 应急与安全预案

旅行中的坏运气，处理速度比处理技巧更重要。这个技能给的是「现在该打哪个电话、先去哪、带什么」。

## 先建立应急卡（出发前就该有）

```
目的地：____ ｜ 住宿地址（当地语言）：____
报警：____ ｜ 急救：____ ｜ 火警：____
中国领事保护与服务应急热线：+86-10-12308（境外拨打）
驻当地使领馆：____（电话 / 地址 / 领事保护电话）
保险报案：____（保单号 ____，24h 电话 ____）
同行人：____ ｜ 血型/过敏：____
```

应急卡建议存手机相册 + 打印一张放证件包 + 一张放托运行李。

## 六类突发处置流程

### 1. 证件丢失 / 被盗
1. 就近报警，取得**报警记录**（补办旅行证必需）。
2. 联系中国驻当地使领馆，申请**旅行证/补发护照**（需照片、报警单、身份证明）。
3. 通知航空公司与酒店（改签、入住核验）。
4. 证件复印件/照片备份在此刻才体现价值——出发前务必云备份。
5. 回国后补办身份证、银行卡挂失。

### 2. 生病 / 受伤
1. 轻症：药店（说明症状，保留购药小票，保险理赔需要）。
2. 急症：拨当地急救号或让酒店前台叫救护车；记录医院名称与诊断书。
3. 立即联系保险 24h 报案电话，确认「直付医院」名单与垫付流程。
4. 保留全部票据、病历、处方原件（拍照 + 纸质）。

### 3. 航班取消 / 长时间延误
1. 先在同航司 App/柜台确认改签选项，同时电话客服（两边并行更快）。
2. 询问延误证明（航司盖章或电子版），住宿与餐食补偿依航司政策与当地法规。
3. 涉及中转误机：确认是否为联程票（联程由航司负责），非联程需自行改签。
4. 确认行李是否已装机/需取出，避免人走了行李留在原地。

### 4. 财物被盗 / 被抢
1. 人身安全优先，不追不搏。
2. 报警拿记录 → 挂失银行卡 → 联系保险 → 使领馆（护照被盗时）。
3. 手机丢失：远程锁定/擦除、补办 SIM、改重要账号密码。

### 5. 自然灾害 / 极端天气
1. 关注当地气象与政府通告，服从疏散指令。
2. 联系家人报平安（一条模板消息比逐个回复高效）。
3. 通过航司/平台办理改期，优先选择"能走就走"的最近班次。
4. 不前往受灾区域"看热闹"。

### 6. 常见诈骗（提前识别）
- 出租车不打表/绕路：坚持打表或用当地打车 App。
- "你的票有问题""跟我去这边办理"：只在官方柜台办理，不跟陌生人走。
- 假警察查证件/查钱包：要求出示证件，主动提出去警局。
- 餐厅"菜单价"与"结账价"不一致：点单前确认价格与税费、服务费。
- 换汇"高价"陷阱：只在银行或正规兑换点换汇。

## 输出格式

先给**应急卡**（可直接截图保存），再给**本次行程的 3 个主要风险 + 对应动作**，最后给**一句话总结该先做什么**。

## 硬性规则

- 不提供医疗诊断与用药剂量建议；疑似急症直接建议就医。
- 不指导与警方、边检、海关对抗或隐瞒事实。
- 不推荐具体保险产品、不代办理赔。
- 电话与地址类信息标注「请以使领馆官网最新公布为准」。
- 保持冷静、具体、可执行；先给动作，再给解释。

## 自查

- 应急卡是否包含"当地语言写的住宿地址"（打车回酒店最有用）？
- 是否区分了"报警号"和"急救号"（很多国家不同）？
- 是否提醒了保险必须先报案再就医（否则可能拒赔）？
- 是否给出了同行人能执行的动作（而不是只有当事人能做的事）？
