# 行李清单

好清单的标准不是"带得全"，而是「该带的都在、不该带的没占重量、过安检不被扣」。

## 生成前确认 5 件事

1. 出行天数与洗衣条件（酒店洗衣/自助洗衣房/手洗）
2. 气候区间：最高温、最低温、降水概率、紫外线强度
3. 活动类型：城市观光 / 徒步 / 海岛 / 滑雪 / 商务 / 婚礼
4. 行李额：手提件数与重量、托运件数与重量（廉航尤其要确认）
5. 特殊需求：处方药、婴幼儿、宗教场所着装、拍摄器材

## 清单按「六层」组织

**第一层 证件与钱**
护照（及复印件/照片备份）、签证、身份证、驾照及翻译件、保险单、机票行程单、2 张证件照、信用卡 2 张（分开放）、少量当地现金、紧急联系人卡。

**第二层 电子设备**
手机、充电器、充电宝（随身，不可托运）、转换插头、数据线、耳机、相机与存储卡、eSIM 或随身 WiFi。

**第三层 衣物（按天数算，不按"以防万一"算）**
上装 = 天数 ÷ 洗衣间隔 + 1；下装 = 上装 × 0.6；内衣袜子按天数；外套按温差 1 件；鞋 2 双（一双走路、一双正式或凉鞋）。原则：同色系互搭，一件多穿。

**第四层 洗护与日用**
旅行装洗漱、防晒、润唇、保湿、纸巾湿巾、折叠伞、洗衣袋、密封袋、眼罩耳塞、水杯。

**第五层 健康与药品**
常用药（感冒、退烧、止泻、抗过敏、创可贴、消毒棉片）、个人处方药（原包装 + 处方或说明）、防蚊、晕车药、口罩。

**第六层 场景加项**
海岛：防水袋、浮潜装备、速干衣、防晒衣。
徒步：登山杖、头灯、雨衣、能量棒、水袋。
滑雪：雪镜、面罩、保暖内衣、护具（大件可当地租）。
商务：正装（用挂烫或送洗代替带熨斗）、名片、转换头。
亲子：奶瓶消毒、儿童退烧药、安抚物、备用衣物 ×2。

## 安检与承运规则（必须核对，不凭记忆）

- **液体**：随身携带单瓶容器 ≤100ml，总量装 1L 透明袋；超过则托运。
- **锂电池/充电宝**：必须随身，禁止托运；容量 ≤100Wh 通常可直接带，100–160Wh 需航司批准，>160Wh 一般禁止。
- **药品**：固体常用药一般可带；含麻醉/精神类成分的必须带处方与说明，部分国家需提前申报。
- **锐器**：刀具、剪刀（刀刃 >6cm）、登山杖多数需托运。
- **食品**：肉类、蛋类、种子、水果多数国家禁止入境，不要"带点特产"。
- **免税额度与申报**：酒、烟、现金超限需申报。

以上为通用框架，**具体以承运航司与目的地海关最新规定为准**。

## 输出格式

按「随身 / 托运」两栏输出，每项后标注数量：

```
随身（≤__kg）：证件包 / 充电宝 / 药品 / 电子设备 / 一日换洗
托运（≤__kg）：衣物 __ 件 / 鞋 __ 双 / 洗护 / 其他
```

表后补三条：

1. **可以不带**：列出用户容易多带但当地易买/酒店提供的物品。
2. **必须随身**：证件、药、充电宝、贵重物品、一日应急衣物（防行李延误）。
3. **出发前 24 小时检查**：证件有效期、行李额、液体分装、充电宝容量标识。

## 硬性规则

- 不给出"如何把超量液体带上飞机"之类规避安检的方法。
- 不推荐携带可能违反目的地法律的物品（含某些药品、无人机、对讲机）。
- 药品只给通用类别，不推荐具体处方药、不调整剂量。
- 所有安检数值标注「以承运方规定为准」。

## 自查

- 清单是否与天数匹配（7 天带 12 件上衣是浪费行李额）？
- 是否考虑了「行李延误 1 天」的应急包？
- 充电宝是否有清晰容量标识（无标识常被拒）？
- 是否把处方药放进了托运箱（应随身）？
