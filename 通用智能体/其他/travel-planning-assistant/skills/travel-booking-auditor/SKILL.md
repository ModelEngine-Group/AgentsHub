# 预订核对与行前检查

绝大多数"到了机场才发现"的问题，都能在出发前 7 天用一张核对表解决。

## 四个时间节点

### T−30 天：资格与证件
- [ ] 护照有效期 ≥ 出行结束日 + 6 个月（部分国家要求空白页 ≥2 页）
- [ ] 签证类型与目的匹配（旅游/商务/探亲），停留期覆盖全程，入境次数足够（多国行程要确认单次/多次）
- [ ] 转机国是否需要过境签；行李是否直挂
- [ ] 保险已购，覆盖医疗、航班延误、行李丢失，保额满足签证要求
- [ ] 目的地是否有疫苗/健康申报要求

### T−14 天：订单一致性
- [ ] 机票姓名与护照完全一致（拼音顺序、空格、有无中间名）
- [ ] 航班日期跨时区换算正确（+1 天 / −1 天最容易错）
- [ ] 酒店入住/退房日期与航班匹配，含"跨日到达是否多订一晚"
- [ ] 酒店政策：入住时间、是否可免费取消、是否收城市税、是否需押金
- [ ] 接送机/租车已确认取还时间与证件要求
- [ ] 需要预约的项目已抢到（门票、餐厅、热门展馆）

### T−7 天：落地可用性
- [ ] 值机开放时间与方式（部分廉航必须线上值机，否则收柜台费）
- [ ] 行李额：件数、重量、尺寸；超重单价
- [ ] 座位与特殊餐食已选（特殊餐一般需提前 24–48 小时）
- [ ] 目的地通信方案已就绪（eSIM 已安装但未激活 / 漫游包已开）
- [ ] 现金与卡：至少两种支付方式，通知银行境外用卡
- [ ] 下载离线地图、翻译包、当地打车 App

### T−1 天：出门清单
- [ ] 证件包：护照、签证、身份证、保险单、行程单（纸质 + 手机各一份）
- [ ] 充电宝随身、液体分装、药品随身
- [ ] 家中：水电燃气、快递、宠物、贵重物品
- [ ] 航班状态复查（延误/取消/航站楼变更）
- [ ] 紧急联系人卡写好（含保险报案电话、当地急救号）

## 核对表输出格式

```
出行：____ → ____ ｜ 出发：____ ｜ 返回：____
风险等级：低 / 中 / 高（依据：签证时效、转机次数、旺季、带娃/老人）
```

| 检查项 | 现状 | 结论 | 需做什么 | 截止时间 |
|--------|------|------|----------|----------|

按「必须马上处理 / 出发前处理 / 可忽略」三组排序，每组不超过 5 条。

## 高风险场景的额外核查

- **转机 <2 小时（国际）**：确认是否同一航站楼、行李是否直挂、误机后改签规则。
- **分开购票的两段行程**：前段延误后段不保，建议留 ≥4 小时缓冲或买联程。
- **廉航**：随身行李尺寸严格，登机口托运费用常高于提前购买 2–3 倍。
- **落地即跨城**：末班车时间、夜间打车安全、酒店前台是否 24 小时。
- **带儿童/老人**：婴儿车托运规则、轮椅申请（一般需提前 48 小时）、儿童证件。
- **自驾**：国际驾照许可（IDP）是否被承认、信用卡是否支持预授权、保险自付额。

## 硬性规则

- 不代替用户下单、不索要或保存证件号码、卡号、密码等敏感信息。
- 不承诺"一定能入境/一定能退改"，所有结论附「以承运方与边检现场判断为准」。
- 发现证件或签证存在硬伤时，直接指出并建议改期或改签，不提供变通方案。
- 核对表只列事实与动作，不做过度安慰性表述。

## 自查

- 是否把"免签"错当成"无需任何手续"？
- 航班跨日/跨时区是否换算正确？
- 酒店是否按"落地当天"而非"出发当天"计算？
- 返程日是否预留了足够时间办理退税与还车？
