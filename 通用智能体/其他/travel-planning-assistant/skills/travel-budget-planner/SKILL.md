# 旅行预算测算

预算不是报一个总数，而是让用户知道「钱花在哪、哪一档可以砍、哪里会超」。

## 九个分项（不漏项）

| 分项 | 单人或按人均 | 常见占比 | 备注 |
|------|--------------|----------|------|
| 往返大交通 | 人均 | 25–40% | 机票/高铁，含行李费 |
| 城际交通 | 人均 | 5–15% | 多城行程才有 |
| 住宿 | 按间夜摊人均 | 20–30% | 双人同行按半间房计 |
| 餐饮 | 人均/天 | 10–20% | 分「日常餐」与「体验餐」 |
| 门票与活动 | 人均 | 8–15% | 含乐园、演出、一日游 |
| 市内交通 | 人均/天 | 3–8% | 地铁/打车/租车油费 |
| 签证与证件 | 人均 | 2–5% | 签证费、加急、照片 |
| 保险 | 人均 | 1–3% | 按天计价 |
| 购物与杂费 | 人均 | 5–20% | 单独列，不混入必需开销 |

另加 **不可预见费 = 上述合计 × 10%**（汇率波动、临时改签、突发打车）。

## 测算顺序

1. 先锁**大交通**：给出价格区间与「提前多久订更便宜」的经验窗口，而不是单一数字。
2. 再锁**住宿**：按城市分档给出每晚区间（青旅床位/经济连锁/四星/精品），乘间夜数。
3. 餐饮用「日均 × 天数」，但把 1–2 顿特色餐单独加价。
4. 门票按「必去项目实价 + 可选项目打包估」。
5. 汇总后给三档：**省（−25%）、舒适（基准）、品质（+40%）**，并说明每档砍/加的是什么。

## 三档的差异点（不是简单打折）

- **省**：位置换到地铁末端或青旅、砍掉 1/3 付费项目、多用超市与本地小馆、避开周末入住。
- **舒适**：市中心三星/四星、每天 1 个付费主项目、正常打车频率。
- **品质**：景观房或套房、私导/包车、米其林或特色餐厅、优先通道与快速票。

## 省钱杠杆（按效果排序）

1. **改日期**：避开当地假期、周末、大型展会，住宿差价常达 30–50%。
2. **提前订大交通**：国际线提前 1.5–3 个月，国内线提前 3–6 周；廉航注意行李费可能抵消差价。
3. **住宿位置换价格**：离核心区 3–5 站地铁，价格常降 20–35%，用交通卡抵消。
4. **城市通票/交通日票**：单日移动 ≥3 次才划算，先算次数再买。
5. **午餐吃正餐**：很多餐厅午市套餐比晚餐便宜 30–50%，菜品相近。
6. **免费日与折扣时段**：博物馆免费开放日、夜间折扣场。
7. **退税**：确认起退金额与退税比例，别为退税凑单。

## 输出格式

```
预算结论：人均 ¥____（不含购物）｜ 区间 ¥____ – ¥____
人均每日：¥____ ｜ 大交通占比：__%
```

|------|----|------|------|------|
| 往返大交通 | | | | |
| 住宿 | | | | |
| … | | | | |
| 不可预见费(10%) | | | | |
| **合计** | | | | |

再补三段：

1. **最容易被低估的三项**（通常是市内交通、门票、餐饮加价）。
2. **三个省钱动作**（具体到「改到哪个时间段」「住哪个片区」）。
3. **汇率与支付提示**（换汇比例建议、境外取现手续费、刷卡货币选择）。

## 硬性规则

- 金额一律写区间，不写"精确到个位"的假精确数字。
- 明确计价口径：人均还是总价、含不含国际机票、含不含购物。
- 涉及票价的必须标注「价格为经验区间，以实际查询为准」。
- 不推荐任何具体理财、换汇、代购、分期产品。
- 不做"零元游""逃票""低价团"类建议。

## 自查

- 是否按人数摊算了房费，而不是把整间房价当人均？
- 是否把往返在途日的住宿算进去了（红眼航班到当天是否要订房）？
- 是否漏了行李托运费、选座费、城市税/度假村费？
- 是否把购物混进"必需开销"导致预算虚高？
