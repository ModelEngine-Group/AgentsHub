# 旅游规划助手（Travel Planning Assistant）

基于 [Nexent](https://github.com/ModelEngine-Project/nexent) 平台构建的旅行规划智能体。围绕"出发前把事情查清楚"设计，覆盖行程规划、目的地情报核查、预算测算、行李清单、行前核对与应急安全六个环节，并配套一个可导入的旅行知识库。

## 功能

| 能力 | 说明 |
|------|------|
| 逐日行程规划 | 按片区分组排布动线、估算单日有效游玩时长、首尾日特殊处理、每片区配雨天 Plan B |
| 目的地情报核查 | 签证入境、节庆闭馆、治安、支付、通信、插头电压等 12 项必查清单，输出情报卡 |
| 预算测算 | 9 分项预算 + 三档（省/舒适/品质）方案与省钱杠杆 |
| 行李清单 | 按气候/天数/活动/行李额生成六层清单，含液体、锂电池、药品安检规则 |
| 行前核对 | T−30/14/7/1 天节点核对表：护照有效期、机票姓名、转机、酒店政策 |
| 应急预案 | 应急卡模板 + 证件丢失、就医、航班取消、财物被盗等处置流程 |

内置硬性规则：不编造票价、营业时间与政策条文；签证、票价、时刻等时效信息一律标注"以官方最新公告为准"。

## 目录结构

```
travel-planning-assistant/
├── agent.json      # 智能体定义（Nexent 平台导出，已去除租户 ID、模型绑定等环境信息）
├── README.md
├── skills/         # 6 个自定义技能（SKILL.md）
└── knowledge/      # 旅行知识库种子文档（8 篇 Markdown）
```

## 前置条件

- 可访问的 Nexent 平台实例，且具备智能体开发权限
- 已配置并通过连通性测试的大语言模型（开发环境使用本地 Qwen3-8B，兼容任意 OpenAI 协议模型；建议使用能力较强的模型以获得更好的技能遵循度）
- 嵌入模型：`bge-m3`（1024 维），用于旅行知识库向量化

## 导入步骤

1. **导入智能体**：在 Nexent 智能体开发 → 导入，上传本目录的 `agent.json`；按提示重新绑定目标环境可用的模型。
2. **安装自定义技能**：本目录 `skills/` 下的 6 个技能在导入智能体时如提示缺失，可在智能体开发 → 选择技能 → 构建技能，逐一上传对应的 `SKILL.md`。
   - `analyze-image`、`search-knowledge-base` 为 Nexent 平台内置官方技能，通常无需单独安装。
3. **搭建旅行知识库**（推荐）：
   - 在平台知识库页面新建名为 `旅行知识库` 的知识库，嵌入模型选择 bge-m3（1024 维）；
   - 将 `knowledge/` 下的 8 篇 Markdown 文档上传并向量化；
   - 在智能体的 `search-knowledge-base` 技能配置中，将 `index_names` 指向该知识库。
4. **开始使用**，示例输入：
   > 我下个月去日本东京玩 3 天，帮我安排行程，并告诉我日本用什么插座、紧急电话是多少。

## 功能与限制

- 知识库内容为方法论与稳定常识（时差、插座、紧急电话等）；签证政策、票价、时刻表等易变信息需以官方渠道复核。
- 智能体不负责订票、支付或酒店库存确认。
- 小参数量本地模型可能将技能误当作函数调用；如遇回答中断，建议更换更强的模型。
