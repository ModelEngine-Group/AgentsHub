# 安全应急与领事协助

本文件提供旅途突发情况的处置流程、应急联系方式与防骗要点。联系电话与政策以使领馆官网最新公布为准。

## 一、应急卡必备字段

- 目的地、住宿地址（当地语言书写）
- 当地报警、急救、火警电话
- 中国领事保护与服务应急热线：+86-10-12308（境外拨打）
- 中国驻当地使领馆地址、领事保护电话
- 保险 24 小时报案电话与保单号
- 同行人联系方式、血型与过敏史

## 三、证件丢失处置

1. 就近报警，取得书面报警记录（补办旅行证必需）。
2. 联系中国驻当地使领馆，申请补发护照或旅行证；材料通常包括报警单、照片、身份证明、原护照复印件。
3. 通知航空公司改签（旅行证可用于回国）。
4. 证件复印件、云端备份在此刻发挥作用。
5. 回国后补办身份证、银行卡与相关证件。

## 四、生病与就医

1. 轻症：药店购药，保留小票（理赔凭证）。
2. 急症：拨当地急救号或由酒店代叫救护车，记录医院名称、诊断书与费用明细。
3. 第一时间联系保险报案，确认直付医院与垫付流程。
4. 保留全部票据、病历、处方原件并拍照备份。
5. 需要转运回国时，联系保险与国际救援机构。

## 五、航班取消与延误

1. 同时通过 App/柜台与客服电话处理，两条线并行。
2. 索取延误/取消证明。
3. 联程票由航司负责改签与住宿；非联程需自行处理。
4. 确认行李状态，避免人与行李分离。
5. 保留因延误产生的额外支出凭证，用于保险理赔。

## 六、财物被盗与被抢

1. 人身安全优先，不追逐、不搏斗。
2. 报警取得记录。
3. 立即挂失银行卡、冻结支付账户。
4. 联系保险理赔（部分保险要求 24 小时内报案）。
5. 护照被盗按证件丢失流程处理。

## 七、自然灾害与极端天气

1. 关注当地气象部门与政府通告。
2. 服从疏散与避险指令。
3. 向家人报平安（统一模板消息，避免逐个回复）。
4. 通过航司或平台办理改期，优先最近可成行班次。
5. 不前往受灾区域。

## 八、常见诈骗手法

- **出租车不打表/绕路**：坚持打表，或使用当地合规打车应用。
- **假工作人员"帮忙办理"**：只在官方柜台办理，不跟随陌生人。
- **假警察查验钱包**：要求出示证件，主动提出前往警局。
- **餐厅双菜单**：点单前确认价格、税费与服务费。
- **换汇高价**：只在银行或正规兑换点换汇，拒绝街头兑换。
- **"免费"赠品与签名**：拒绝接受，快速离开。
- **退税代办收取高额手续费**：自行在机场办理。

## 九、领事协助能做什么与不能做什么

**可以提供**：补发旅行证件、提供当地律师/翻译/医院名单、通知国内家属、在拘留或事故时探视、协助联系航空公司。

**不能提供**：支付医疗费、律师费、机票费；干预当地司法；代为办理签证；提供住宿与现金。

## 十、出行前安全准备

- 购买覆盖医疗、延误、行李与个人责任的旅行保险。
- 将行程与联系方式告知家人，约定每日报平安时间。
- 保存使领馆与保险电话到手机与纸质卡。
- 了解目的地高风险区域与常见骗局。
- 避免深夜独自前往偏僻区域。
