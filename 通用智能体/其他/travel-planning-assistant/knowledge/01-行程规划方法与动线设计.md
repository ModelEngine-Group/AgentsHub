# 行程规划方法与动线设计

本文件用于旅行需求理解、行程排布、时间估算与动线优化；适用于自由行、亲子游、长辈同行与多城联游。

## 一、行程规划的标准流程

1. 明确约束：出发地、目的地、日期、天数、人数构成、预算、节奏偏好、硬性必去点。
2. 划分片区：把目的地地图切成 3–5 个片区，每个片区聚 2–4 个相近点位。
3. 排布日程：每天一个主片区，跨区移动放在早晨或傍晚。
4. 估算时长：白昼时长 − 通勤 − 用餐 − 排队缓冲 = 有效游玩时长。
5. 设定缓冲：行程总量只填到有效时长的 85%。
6. 配备选：每个户外主项目配一个室内替代。
7. 输出表格：日期、片区、上午、午餐、下午、晚餐、住宿、备注（预约/闭馆/交通）。

## 二、动线设计原则

- 同一天内的移动应是"环形"或"直线"，避免 A→B→A 折返。
- 上午安排需要排队或体力最好的项目，下午安排室内或轻松项目。
- 长途移动后不安排需要预约的硬性项目。
- 同一片区内的点位按"开门时间"排序，而不是按地图距离排序。
- 每天设置一个"锚点"（必去项），其余项目可弹性增减。

## 三、时间估算经验值

| 环节 | 建议估算 |
|------|----------|
| 市内两点移动 | 30–45 分钟 |
| 博物馆/美术馆 | 2.5–4 小时 + 30 分钟入场 |
| 主题乐园 | 全天（6–9 小时） |
| 正餐 | 60–90 分钟 |
| 网红餐厅排队 | 30–60 分钟 |
| 机场至市区 | 45–90 分钟 |
| 跨城高铁 | 2–4 小时 + 两端接驳各 40 分钟 |
| 酒店入住 | 20–30 分钟 |

## 四、按人群调整

- **亲子（6 岁以下）**：单日硬性项目 ≤2 个，午睡时段留 1.5 小时，每 2 小时安排一次洗手间/补给。
- **长辈（65 岁以上）**：单日步行上限 8000 步，避免连续爬坡与台阶多的老城，优先有电梯的博物馆。
- **情侣/朋友**：可加入 1–2 个"体验型"项目（烹饪课、夜游、演出）作为记忆点。
- **独行**：夜间活动选择人流密集区域，住宿优先前台 24 小时。

## 五、多城联游规则

- 3 城以内、单城停留 ≥2 晚为宜；连续 1 晚换城会导致"全程在搬家"。
- 城际移动安排在上午，抵达后当天只安排轻活动。
- 尽量单向推进（A→B→C），避免回到起点城市的往返。
- 跨国行程要预留边境通关时间（陆路边境 1–2 小时）。

## 六、首尾两天的处理

- 到达日：入住 + 周边 1 小时步行圈 + 晚餐，不排预约项目。
- 离开日：按"国际航班提前 3 小时、国内航班提前 2 小时"倒推，最后一项安排可随时放弃的轻活动。
- 红眼航班落地当天，建议多订半日酒店或安排温泉/休息，不排硬行程。

## 七、行程自检清单

- [ ] 单日景点数是否 ≤4（带娃/带老人 ≤3）？
- [ ] 是否存在两小时以上车程被塞进半天？
- [ ] 是否考虑了周一闭馆、午休、宗教礼拜时间？
- [ ] 是否每 3 天安排一次半天休整？
- [ ] 是否每天留了一顿自由餐？
- [ ] 是否标注了必须提前预约的项目？
- [ ] 退税/还车是否留足时间？

## 八、常见规划错误

1. 只看地图直线距离，忽略山、河、单行线导致的绕行。
2. 把"打卡数量"当目标，导致每天都在赶路。
3. 忽略当地假期与大型展会，住宿涨价且景点爆满。
4. 把所有购物压到最后一天，退税时间不足。
5. 连续高强度步行三天，第四天体力崩盘。
