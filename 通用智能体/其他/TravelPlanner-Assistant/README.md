# 旅游规划助手（TravelPlanner-Assistant）

> 作者：牛子铭　学号：20252402
> 基于 [Nexent](https://modelengine-group.github.io/nexent/zh/getting-started/overview.html) 平台构建

## 一、简介

面向"想自己安排行程"的个人和小团队的旅行规划智能体。输入目的地、天数、预算、同行人和偏好，
输出可执行的每日行程、预算估算与行前提醒；回答前会先检索旅行知识库，并注明资料依据。

**核心特点**

- **有依据**：回答优先来自「旅游知识库」，引用具体文档，不凭空编造
- **会追问**：信息不足时最多追问 3 个关键问题（目的地/天数/预算/同行人），其余按假设处理并说明
- **结构化输出**：行程概览 → 每日安排 → 预算估算 → 行前提醒
- **诚实边界**：知识库没有的内容会明确说"资料里没有"，再给通用建议

## 二、依赖

| 依赖 | 说明 |
| --- | --- |
| 模型 | `DeepSeek-V4-Pro`（或任意 OpenAI 兼容模型，如 `deepseek-chat`、`qwen-plus`） |
| 工具 | `KnowledgeBaseSearchTool`（`knowledge_base_search`，平台内置） |
| 知识库 | 需自建，本文档 `knowledge/` 目录提供 7 份源文档 |
| 向量模型 | 建议 `BGE-Small-ZH`（512 维）或 `BAAI/bge-m3`，注意：**换模型需重建知识库** |
| Skill / MCP | 无 |

## 三、导入步骤

### 1. 建知识库

1. Nexent →「知识库」→ 新建
2. 名称：`旅游知识库`（与其他名称不同也可，导入后重新绑定即可）
3. 向量模型：选择已配置的 embedding 模型（如 `BGE-Small-ZH`）
4. 上传 `knowledge/` 下 7 个 Markdown 文件
5. 等待状态变为「已就绪」

### 2. 导入智能体

1. 「智能体开发」→「导入」
2. 选择本目录的 `agent.json`
3. 若提示模型缺失，先在「模型配置」中添加 `DeepSeek-V4-Pro` 或改用已有模型

### 3. 重新绑定知识库（重要）

`agent.json` 中的知识库引用指向作者本地实例的索引，导入后需要重新指定：

1. 打开导入后的智能体 → 配置页
2. 找到「知识库检索」工具 → 重新选择你在第 1 步创建的知识库
3. 保存

### 4. 发布

选择可见用户组（如 Default Group）→ 发布 → 在「开始问答」中使用。

## 四、提示词要点

智能体提示词（`agent.json` 中 `prompt` 字段，约 1000 字）包含：

- **角色设定**：资深旅行规划师
- **工作流**：需求澄清 → 知识库检索 → 结构化输出
- **追问上限**：最多 3 个问题，避免过度打扰
- **输出结构**：① 行程概览 ② 每日安排（时间-地点-交通-用餐）③ 预算估算（分项）④ 行前提醒
- **硬约束**：禁止编造票价/开放时间/预约规则；价格用区间并提示以官方为准；知识库无内容时明确说明
- **节奏约束**：一天不超过 2 个主景点

## 五、示例问题与预期

| 提问 | 预期表现 |
| --- | --- |
| 大理三天怎么安排？ | 基于《01-云南旅行指南》给出每日行程，注明依据 |
| 带 5 岁小孩去成都 4 天怎么玩？ | 结合成都指南与亲子节奏（每天 1–2 个主景点、保留午休） |
| 去哈尔滨怎么玩？ | 明确回答"资料里没有这部分"，再给通用建议，不编造 |

## 六、知识库内容

`knowledge/` 下 7 份文档，均为七段式结构（概览/必去/路线/交通/住宿/预算/避坑），便于切块检索：

| 文件 | 内容 |
| --- | --- |
| 01-云南旅行指南.md | 昆明、大理、丽江 |
| 02-成都旅行指南.md | 成都市区、都江堰、青城山、美食 |
| 03-西安旅行指南.md | 西安市区、兵马俑、华山 |
| 04-行程模板与排期方法.md | 3/5/7/10 天骨架、按人群节奏 |
| 05-交通与住宿选择指南.md | 城际交通选择、住宿选址、订房清单 |
| 06-旅行预算测算参考.md | 预算构成、人均基准、速算公式 |
| 07-行前准备与安全须知.md | 行前清单、证件安全、高原专题 |

## 七、测试记录

在 Nexent v2.8.3 + DeepSeek-V4-Pro + 本地 BGE-Small-ZH（512 维）环境下验证：

- 知识库检索命中正常（"大理三天怎么安排" → 命中云南指南，相似度 1.00）
- 行程输出包含每日安排与预算分项
- 超出知识库范围的问题可正确拒答并说明

## 八、已知限制

- 知识库仅覆盖云南、成都、西安三地，其他目的地会提示"资料里没有"
- 票价、开放时间、预约规则为参考值，出行前需以官方渠道为准
- 不含签证、境外目的地等跨境信息
