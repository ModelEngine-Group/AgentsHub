# 行程模板与排期方法

> 文档类型：方法论知识库　标签：行程、排期、模板、节奏、亲子、老人
> 适用问题：行程怎么排、每天安排几个景点、带老人小孩怎么安排

## 一、排期的四条基本原则

1. **一天不超过 2 个主景点**：加上交通与用餐，3 个以上会变成赶场。
2. **"远—近—远"交叉**：把需要长途移动的景点分开，避免连续两天奔波。
3. **抵达日与离开日留白**：抵达当天只安排轻松项目；离开当天提前 3 小时到机场/车站。
4. **同类景点不重复**：连续看三个古镇会审美疲劳，穿插自然景观或美食体验。

## 二、按人群的节奏建议

| 人群 | 每日主景点 | 说明 |
| --- | --- | --- |
| 情侣 / 朋友 | 2 个 | 可安排夜景、咖啡、拍照点 |
| 亲子（3–10 岁） | 1–2 个 | 午休必须保留，行程围绕孩子的兴趣点 |
| 带老人 | 1 个 | 减少爬坡，优先索道/观光车，中午回酒店休息 |
| 摄影爱好者 | 1–2 个 | 按日出日落排点，留出等待光线的时间 |
| 特种兵 | 3–4 个 | 只适合体力好、追求打卡的年轻人 |

## 三、通用日模板

### 标准日（城市游）
- 08:30 早餐
- 09:00–12:00 主景点 A
- 12:00–13:30 午餐 + 休息
- 14:00–17:00 主景点 B 或博物馆
- 17:30–19:00 回酒店休整
- 19:00–21:00 晚餐 + 夜景/步行街

### 自然景区日
- 07:00 出发（越早越好，避开人流与高温）
- 08:30–12:00 核心景区
- 12:00–13:00 景区内简餐
- 13:00–15:30 次核心区或返程
- 16:00 回城，晚上自由活动

### 移动日（城市间转移）
- 上午退房 → 高铁/航班 → 下午抵达 → 入住 → 附近轻量游览
- 移动日不安排需要预约的景点

## 四、按天数的骨架模板

### 3 天（单城市）
- D1 抵达 + 市中心地标 + 夜景
- D2 核心景点（最想去的一个）+ 博物馆
- D3 近郊半日 + 返程

### 5 天（单城市 + 周边）
- D1 抵达 + 市区
- D2 核心景区一日
- D3 周边一日（古镇/山/湖）
- D4 博物馆 + 美食 + 购物
- D5 休闲 + 返程

### 7 天（双城）
- D1–D2 城市 A 核心
- D3 转移到城市 B，下午轻松游
- D4–D5 城市 B 核心 + 周边
- D6 自由活动/购物
- D7 返程

### 10 天以上（多城环线）
- 每 3 天安排 1 个"缓冲日"（睡到自然醒、洗衣、发呆）
- 长途移动不超过 4 小时/次
- 提前确定 2–3 个必须完成的"高光体验"，其余弹性

## 五、时间估算参考

| 场景 | 预留时间 |
| --- | --- |
| 市内景点间打车 | 20–40 分钟 |
| 地铁跨区 | 30–50 分钟 |
| 机场到市区 | 45–90 分钟 |
| 高铁站安检进站 | 30–45 分钟 |
| 热门景区排队入园 | 20–60 分钟（旺季更长） |
| 博物馆参观 | 2–3 小时 |
| 大型主题乐园 | 1 天 |

## 六、行程自检清单

- [ ] 是否有连续两天长途移动？
- [ ] 需要预约的景点是否都已预约？
- [ ] 抵达日和离开日是否留了缓冲？
- [ ] 是否有一天的行程是"可以随时取消"的弹性安排？
- [ ] 老人小孩的体力是否匹配？
