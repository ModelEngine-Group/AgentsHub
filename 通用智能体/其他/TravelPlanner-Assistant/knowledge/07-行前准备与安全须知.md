# 行前准备与安全须知

> 文档类型：通用知识库　标签：行前、安全、证件、保险、急救、高原、天气
> 适用问题：出发前要准备什么、需要注意什么、安全吗、证件怎么办

## 一、出发前 30 天

- [ ] 确认目的地天气与季节特征（雨季/台风季/高温/严寒）
- [ ] 预订大交通与住宿（旺季更早）
- [ ] 检查证件有效期（护照需 6 个月以上有效期）
- [ ] 需要签证的，确认办理时长与材料
- [ ] 预约热门景点/博物馆门票
- [ ] 购买旅游意外险

## 二、出发前 7 天

- [ ] 打印/保存行程单、酒店地址（含当地语言）
- [ ] 手机下载离线地图、翻译 App
- [ ] 兑换少量现金（部分小店只收现金）
- [ ] 检查银行卡境外可用性与手续费
- [ ] 告知家人行程与联系方式
- [ ] 常用药备齐（处方药带说明）

## 三、出发前 1 天

- [ ] 值机/选座，确认行李额
- [ ] 充电宝、充电器、转换头
- [ ] 行李称重
- [ ] 家里水电燃气检查
- [ ] 提前叫车/查好去机场路线

## 四、证件与财物安全

| 风险 | 应对 |
| --- | --- |
| 证件丢失 | 身份证/护照复印或拍照存云端，与原件分开存放 |
| 财物被盗 | 分散存放现金与卡；人多处背包前背 |
| 信用卡盗刷 | 开启交易提醒，回国后核对账单 |
| 手机丢失 | 提前备份通讯录，开启查找设备功能 |

## 五、常见安全风险

1. **交通**：不坐无牌黑车；夜间尽量用正规网约车；租车检查车况与保险。
2. **水上活动**：只在有救生员区域游泳；浮潜/潜水选有资质商家。
3. **高风险项目**：蹦极、滑翔、越野等确认保险覆盖范围。
4. **饮食**：避免生食、路边摊凉菜；高原地区少饮酒。
5. **夜间**：避免独自走偏僻路段；酒吧街注意饮品离开视线后不再饮用。
6. **诈骗**：低价团、免费接送、"内部票"多为陷阱。

## 六、高原旅行专题

- 海拔 3000 米以上属于高原，常见反应：头痛、失眠、恶心、气短。
- 抵达当天：不剧烈运动、不洗热水澡过久、不饮酒。
- 备葡萄糖、氧气瓶；症状加重立即下撤就医。
- 有严重心肺疾病、高血压未控制、孕妇不建议上高原。
- 高原紫外线强，SPF50+ 防晒、墨镜、唇膏必备。

## 七、天气与自然灾害

| 情形 | 应对 |
| --- | --- |
| 台风 | 关注预警，避免海岛/沿海行程，航班可能取消 |
| 暴雨 | 山区易发泥石流，避开峡谷徒步 |
| 高温 | 正午减少户外，补水补盐 |
| 严寒 | 分层穿衣，注意手脚保暖 |
| 地震 | 室内躲桌下/承重墙角，室外远离建筑 |

## 八、健康与急救

- 随身药包：退烧药、止泻药、抗过敏药、创可贴、碘伏、晕车药。
- 记住当地急救电话：中国大陆 120，报警 110，火警 119。
- 出境记住：欧盟 112，美国 911，日本 119。
- 有慢性病者携带病历摘要（英文/当地语言更佳）。

## 九、文明与合规

- 尊重当地风俗与宗教场所规定（着装、拍照限制）。
- 景区禁止区域不进入，不投喂野生动物。
- 无人机飞行需遵守当地法规与景区规定。
- 垃圾随身带走，不破坏自然与文物。
