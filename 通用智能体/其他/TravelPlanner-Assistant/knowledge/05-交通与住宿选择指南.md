# 交通与住宿选择指南

> 文档类型：方法论知识库　标签：交通、机票、高铁、住宿、酒店选址
> 适用问题：怎么选交通方式、住哪里方便、酒店怎么挑

## 一、城际交通怎么选

| 距离 | 推荐 | 说明 |
| --- | --- | --- |
| < 500 公里 | 高铁 | 总耗时（含往返车站）通常优于飞机 |
| 500–1200 公里 | 高铁 / 飞机 | 看班次时间与价格，夜车卧铺也可考虑 |
| > 1200 公里 | 飞机 | 提前 3–6 周订票价格更优 |

**判断公式**：总耗时 = 到站时间 + 候车/候机 + 车程/航程 + 出站到酒店。
高铁一般按"车程 + 1.5 小时"估算，飞机按"航程 + 3 小时"估算。

### 订票时机
- 国内机票：提前 3–6 周较稳；节假日提前 2 个月。
- 高铁：提前 15 天开售，热门线路（如京沪、成渝、昆明—大理）建议开售即订。
- 廉航：注意行李额与退改规则，别只看票价。

## 二、市内交通

| 方式 | 适合 | 提示 |
| --- | --- | --- |
| 地铁 | 通勤、跨区 | 避开早晚高峰；提前下载当地地铁 App |
| 打车/网约车 | 3–4 人、带行李 | 景区门口高峰期难打车，可提前叫 |
| 公交 | 预算敏感 | 班次间隔大，适合本地生活体验 |
| 共享单车 | 3 公里内 | 注意是否在运营区内 |
| 包车 | 环线、多人、带老人 | 约 300–800 元/天，按车型与里程 |

## 三、住宿选址三原则

1. **靠近地铁站**：步行 5–10 分钟内，效率提升明显。
2. **靠近"第二天要去的方向"**：比如第二天去兵马俑，就住城东或高铁站附近。
3. **避开纯景区核心的"高溢价区"**：往外 1–2 站地铁，价格可能低 30%。

### 不同场景的选择

| 场景 | 推荐区域 |
| --- | --- |
| 首次到访城市 | 市中心地铁枢纽，方便打卡 |
| 亲子 | 有早餐、有洗衣、房间大；远离酒吧街 |
| 带老人 | 电梯房、离景点近、安静 |
| 自驾 | 有停车场，城市边缘上高速方便 |
| 中转赶早班机 | 机场附近有接驳车的酒店 |

## 四、房型与设施核对清单

订房前确认：

- [ ] 是否有独立卫浴、热水稳定
- [ ] 是否有空调/暖气（南方冬季湿冷）
- [ ] 是否含早餐（亲子、老人很实用）
- [ ] 是否可免费取消（行程有变数时必选）
- [ ] 是否有电梯（老城区客栈常见无电梯）
- [ ] 隔音情况（看评论关键词"吵""酒吧""临街"）
- [ ] 是否可寄存行李（退房后还要玩的情况）

## 五、常见坑

- 平台"距景点 500 米"可能指直线距离，实际绕路 1 公里以上。
- 海景房/山景房要确认"无遮挡"，低楼层可能被树挡住。
- 民宿图片常为广角拍摄，实际房间偏小。
- 旺季临时涨价、到店无房的情况存在，优先选可确认订单的平台。
- 高原地区酒店供氧、供暖能力差异大，提前问清。

## 六、行李与随身

- 证件：身份证、护照/签证（出境）、驾照（自驾）
- 电子：充电宝（≤100Wh 可随身）、转换插头、数据线
- 药品：常用药、晕车药、肠胃药、创可贴
- 衣物：按温差准备外套；高原带防晒与墨镜
- 其他：折叠伞、便携水杯、湿巾
