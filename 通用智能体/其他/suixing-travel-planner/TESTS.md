# 测试与验证

日期：2026-11-10；环境：Nexent v2.8.4 官方 Docker 镜像、DeepSeek Flash、Docker 沙箱。模型通过服务商支持的 `deepseek-v4-flash` 别名调用，关闭额外深度思考以降低交互等待。

## 预算技能测试

在与平台一致的沙箱镜像中运行 Python 标准库 `unittest`，**6 项测试通过**：

1. 一间房住两晚与两人往返交通：600 + 400 = 1000，900 元预算余额 -100。
2. 家庭行程回归：成人与儿童交通分别计算，全部费用合计 2466，余额 534。
3. Decimal 舍入：0.335 × 3 按分四舍五入为 1.01。
4. 免费项目与零预算。
5. 拒绝负数、NaN、Infinity、布尔值、空值和非法金额。
6. 拒绝空条目列表与超出上限的条目数量。

在技能源码目录运行：

```bash
python -m unittest discover -s tests -v
```

## 结果解释与边界

预算技能验证算术，不证明模型选择的单价、票种、数量说明或场馆政策一定正确。真实出行前仍需用户核对输入口径、官方公告和可订价格。演示稿明确注明了一处餐饮备注的人工计费单位校对，金额未改动；不把人工校对稿冒充完全未经编辑的模型输出。

模型可能先给草稿再修正。运行验证启用了 Nexent 内置回答协议修复；记录和示例采用最终被提交的答复，丢弃已撤回的中间草稿。此处验证的是所列场景，没有声称覆盖所有目的地、政策或极端情况。
