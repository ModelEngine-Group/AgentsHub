# 随行·旅游规划助手

作者：**20241311**　版本：**1.0.0**

基于 Nexent 构建的中文旅游规划智能体。把出发地、人数、日期和总预算变成每日路线、精确预算表、预约清单及雨天备选。

## 功能

- 条件不足时集中询问最多 5 个关键问题。
- 区分全体/每人预算、房间数/人数、旅行天数/住宿晚数。
- 通过 Nexent 内置 `deepseek_search` 检索景区和场馆公开信息，优先官方来源，保留平台来源引用。
- 安排亲子或低步行强度路线、休息时间、同区域雨天备选；核对闭馆日。
- 使用自带 `travel-budget-checker` 技能核算每行乘法、总计和余额，直接输出脚本生成的预算表。
- 预算冲突时说明缺口并给调整方向；未来天气、房价和余票没有实时凭证时明确标注待确认或估算。

## 导入与配置

已在 Nexent **v2.8.4 官方镜像**环境完成实际运行验证。

1. 在模型配置中添加可用的中文对话模型。验证环境使用 DeepSeek Flash；当前 Nexent 模型目录识别 `deepseek-v4-flash`，DeepSeek 官方仍接受该别名并映射到当前 Flash 服务，详见[官方调用说明](https://api-docs.deepseek.com/)。
2. 在技能页面上传 `skills/travel-budget-checker.zip`。源码同时位于 `skills/travel-budget-checker/`，便于审查、运行与修改。
3. 进入“智能体开发 → 导入”，上传本目录的 `agent.json`，把导出模型映射到本机已配置的模型。
4. 如果导入界面提示技能依赖，将其映射到刚上传的 `travel-budget-checker`。
5. 在智能体工具配置中找到 `deepseek_search`，填写**自己的** `deepseek_api_key`。本仓库中的密钥字段为空。建议参数：`max_results=3`、`need_content=false`、`timeout_seconds=25`、`max_retries=1`。
6. 在预览中试运行下方问题，然后发布到自己所在的用户组。

对话和搜索使用服务商 API，按服务商规则计费。预算技能只依赖 Python 标准库，在 Nexent 的 Docker 沙箱执行。无需额外地图 Key、数据库或嵌入模型。

## 示例问题

**先澄清需求**

> 帮我计划一次旅行。

**检查预算冲突**

> 两人去杭州玩三天，住两晚，只订一间房，300 元每间每晚，往返交通 200 元每人，总预算 900 元。不要联网，只判断预算是否足够，并给调整方向。

预期：住宿 600 元 + 交通 400 元 = 1000 元，已经超支 100 元，且尚未计入餐饮等费用。

**完整亲子行程**

> 上海出发，2026 年 12 月 5 日至 7 日去杭州玩 3 天，2 大 1 小，孩子 8 岁，住一间房两晚，全体预算 3000 元含往返高铁和住宿。不自驾，想去西湖和一处博物馆，每天有休息。请核对开放与预约信息，列预算和雨天备选。

完整测试输入见 `test-cases.json`，真实运行示例见 `examples/`。

## 数据与时效边界

- 搜索结果可能是摘要或历史公告；开放时间和预约规则以场馆当期官方公告为准。来源冲突时明确列出冲突和核实事项。
- 未接铁路售票、酒店库存或实时导航 API。票价、房价和路程耗时按清楚标注的估算处理。
- 预算技能保证输入数据的算术一致性；输入的单价、人数和项目选择仍需使用者确认。
- 技能不联网、不读取凭据。智能体不执行预订和付款。
- 来源标记如 `[[o1]]` 在 Nexent 内关联真实来源卡；不可根据标记或标题猜造 URL。
