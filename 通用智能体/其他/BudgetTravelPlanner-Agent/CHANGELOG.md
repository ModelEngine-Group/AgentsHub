# CHANGELOG

## v1.0.0 — 2026-11-01

首个版本。

- 三段式提示词：职责（5 步工作流）、约束（12 条）、示例（5 个任务）
- 工具：`tavily_search`，用于核实门票价格、开放时间、预约政策
- 能力边界：天气、交通班次、实时路况不调用搜索，引导用户查询 12306 / 气象服务
- 预算输出要求逐项列算式，禁止只给合计数
- 同一问题搜索次数上限 2 次，避免多来源价格混用
- `max_steps` = 15

### 开发环境

- Nexent v2.7.0
- LLM：`deepseek-v4-flash-0731`
- 未使用知识库、Skill、MCP
