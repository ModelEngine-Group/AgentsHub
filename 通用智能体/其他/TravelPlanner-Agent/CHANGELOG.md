# 更新日志

## 1.1.0 — 2026-11-03

- 增加老人、儿童、轮椅或婴儿车等同行条件的行程适配规则，要求标明未核实的无障碍信息。
- 明确预算总额/人均口径，并按人数、房间数和住宿晚数展示核算依据、合计与余额。
- 增加老人同行场景的回归用例和无障碍信息核实说明。

## 1.0.0 — 2026-10-30

- 使用 Nexent v2.8.0 配置并发布「智能旅游规划助手」。
- 实现旅游需求分析、按天行程规划、预算估算及多轮调整提示词。
- 接入 Nexent 本地 `deepseek_search` 工具，用于获取可引用的公开网页信息。
- 完成开发实例中的景点介绍、预算规划及联网工具调用检查。
- 生成面向开源贡献的脱敏配置；导入者需重新设置模型与搜索工具 API Key。
