# 智能旅游规划助手（TravelPlanner-Agent）

基于 **Nexent v2.8.0** 构建的中文旅游规划智能体。输入目的地、旅行时间、出发地、人数、预算和兴趣偏好，即可获得每日行程、景点与美食建议、交通安排及费用估算。对于涉及实时变化的信息，智能体可通过 `deepseek_search` 检索公开网页，并提醒用户以官方渠道核实。

> 本目录中的 `agent.json` 来自 Nexent 平台导出，并在发布前进行了脱敏；不包含原开发者的租户标识、邮箱或 API Key。导入后需要自行配置模型与搜索工具密钥。

## 功能

- **需求分析**：提取出发地、目的地、日期、天数、人数、预算和偏好，缺少必要条件时询问。
- **行程规划**：按天和时段组织景点、餐饮、交通、游览时间，尽量减少折返。
- **预算估算**：分别计算往返交通、住宿、餐饮、门票、市内交通、备用金，并检查合计。
- **交互调整**：支持在同一会话中调整预算、天数和景点偏好（建议导入后进行多轮回归测试）。
- **联网检索**：在可用时通过 `deepseek_search` 查询景点票务、营业时间等公开信息，优先引用官方来源。

## 运行环境与依赖

| 项目 | 配置 |

## 导入与配置

1. 在目标环境部署或登录 Nexent，并获得智能体开发权限。
2. 进入 **智能体开发 → 导入**，选择本目录中的 `agent.json`。
3. 在模型管理中配置可调用的 DeepSeek 大语言模型；导入后根据模型映射提示选择目标环境中可用的模型。
4. 打开导入的智能体，进入 **工具管理 → `deepseek_search` → 配置**，输入**自己申请**的有效 API Key。导出文件中的 `deepseek_api_key` 已置空，不能直接用于联网搜索。
5. 测试工具连通性、智能体简单问答与联网搜索，确认无误后发布。

**安全提醒：** 不要把 API Key、租户密码、登录令牌等信息提交到仓库。若重新导出已配置的智能体，请再次检查所有工具参数中的密钥。

## 使用示例与预期输出

**示例 1：景点推荐**

输入：`请用三句话介绍成都适合旅游的三个景点，不需要调用工具。`

预期：简洁介绍有代表性的景点，并避免把参考信息表述为实时票价或开放公告。

**示例 2：预算与行程**

输入：`两个人从重庆出发去成都旅游两天一晚，总预算1500元，请给出简洁行程和预算表，控制在800字以内。`

预期：输出两天一晚的路线、交通与住宿建议，以及计算一致的预算表，注明费用为估算。

**示例 3：联网搜索**

输入：`请使用 deepseek_search 查询成都大熊猫繁育研究基地的开放时间、门票价格和官方购票渠道，并提供来源链接。`

预期：执行工具调用，返回检索得到的信息及可核实来源；对于搜索结果冲突，优先使用官方公告。

**示例 4：多轮调整（建议回归测试）**

在示例 2 的同一会话中输入：`总预算改成1200元，其他条件不变，请重新规划并说明变化。`

预期：保留目的地、出发地、人数和天数，调整住宿、餐饮或景点安排并复核合计。

## 已完成的开发侧检查

在原始开发实例中，景点简答、两天一晚预算规划均成功返回；联网测试的执行记录中出现了 `deepseek_search` 工具调用。**这些是原始实例上的测试结果，不等于已完成对本脱敏文件在新租户中的再次导入验证**。发布者和使用者应在目标 Nexent 环境重新执行上述用例。

## 局限与说明

- 本版本未接入地图路线、实时交通票务预订或天气专用 API；无法保证交通耗时、营业时间及报价实时准确。
- 搜索结果可能包含不准确或过期的第三方资料，使用前请核对景区或交通官方渠道。
- 不执行购买、酒店预订、付款等真实交易。
- 网页搜索需要可用的服务配置及相应额度，可能产生 API 成本。
