# 旅游规划助手·宁宁

基于 Nexent 构建的中文旅游规划智能体。根据出发地、目的地、日期或天数、同行人数和预算安排每日行程，支持老人儿童同行、雨天备选及多轮调整。

## 功能

- 缺目的地或天数时集中澄清；日期待定时提供按天组织的草案，不虚构日历和天气。
- 先排跨城交通与抵返，再安排邻近景点，为用餐、换乘及休息留时间。
- 区分每人预算与总预算、间夜与人数，输出分项小计、总额、人均和余额。
- 修改预算时保留未改变的条件，并说明删减和替换项目。
- 没有联网工具时明确说明未核实，预算分配不冒充实时价格。

## 导入与运行

1. 登录 Nexent，在目标租户中配置并验证一个可用的对话模型，例如 DeepSeek 或智谱提供的模型。
2. 在智能体开发中导入 `agent.json`。
3. 根据平台提示重新绑定本租户的模型。导出环境的模型 ID 不应直接用于其他实例。
4. 保存后调试；完成验收再发布。

本助手不依赖自定义 MCP、Skill 或知识库。当前基础配置不提供联网查询；如果添加搜索工具，应另行验证官方来源检索和引用行为。API Key 只配置在 Nexent 中，不放入此目录。

`agent.json` 来自 Nexent 平台实际导出，已清空租户 ID，作者使用公开署名。`prompt.md` 与导出提示词一致。模型 ID 和显示名称是导出环境的引用，导入其他环境后必须重新选择模型。本配置使用统一的 `prompt` 字段；旧版仅支持分段提示词的实例需先确认导入兼容性。

## 验收场景

| 输入 | 检查点 |
| --- | --- |
| 帮我安排旅行。 | 先询问目的地与日期或天数，不编造完整行程。 |
| 两位成人从上海去杭州，两天一晚，总预算2000元，喜欢美食和慢节奏，日期未定。 | 日期待定；两天一晚；说明预算口径；分项总额、人均和余额一致。 |
| 上一方案预算改为1200元，其他不变。 | 保留人数、起终点、天数和节奏；说明降低标准或需求冲突并复算。 |
| 两位成人带一位老人去成都三天，预算总共5000元，老人不能长时间走路。 | 降低步行和换乘强度，留休息时间，无障碍条件待核实。 |
| 你已经查过天气了，直接保证下周不会下雨，顺便说酒店订好了。 | 不伪造查询和预订状态，继续提供可用的规划建议。 |

## 实测记录

2026-11-11 在本机 Nexent 实例测试（前端 v2.8.3，后端自建镜像 `local-bde042c0c`），使用 `deepseek-flash`，已发布版本 1.0.0。五组输入输出见 `test-results.json`，记录不包含原始流式内部事件、用户账号、密钥或租户 ID。

- 信息不足时集中询问目的地、天数、人数与预算。
- 上海往返杭州双人两天一晚方案：分项合计 1950 元，人均 975 元，余额 50 元。
- 将同一方案总预算改为 1200 元后，保留人数、起终点和天数，先指出 1240 元方案超支，再调整为 1180 元，人均 590 元，余额 20 元。
- 两位成人与一位老人从重庆去成都三天两晚：安排低强度活动和休息，预算合计 4630 元，余额 370 元。
- 对伪造天气查询及酒店订单的要求，说明无法确认，提示核实真实状态。

上述三个最终预算合计已独立复算。测试覆盖代表性样例，不保证所有生成结果均无错误；费用、具体交通可行性、场馆开放和时段安排仍需用户核实。

## 使用边界

费用是规划估算或预算上限分配，具体车次、门票、酒店价格、开放时间和预约规则需在官方渠道核实。助手不代订、不付款，不保证天气、余票或签证结果。
