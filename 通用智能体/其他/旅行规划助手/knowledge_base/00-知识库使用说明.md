# 知识库使用说明（给 NEXENT 配置者看）

本目录是「旅行规划助手」的私有知识库语料，共 6 份文档，覆盖 5 个目的地城市 + 通用预算/签证/亲子主题。

## 一、文件清单

| 文件 | 类型 | 内容 | 建议用途 |
| --- | --- | --- | --- |
| `01-东京5日深度游.md` | Markdown | 区域逻辑、5 日模板、交通、预算、避坑 | 东京深度问答 |
| `02-曼谷清迈7日双城指南.md` | Markdown | 双城排法、7 日总览、季节、实用信息 | 泰国多城行程 |
| `03-国内城市3日速览.md` | Markdown | 北京/上海/成都 3 日骨架与预约 | 国内周末游 |
| `04-旅行预算与预订清单.xlsx` | Excel | 预算科目、城市日均、预订时间线、比价、行前清单 | 预算与预订类问题 |
| `05-签证与出入境须知.docx` | Word | 日本/泰国/申根签证与入境流程 | 签证、材料、入境卡 |
| `06-亲子与长辈出行指南.docx` | Word | 节奏、交通、住宿、健康、安全 | 家庭出游约束 |

> 多格式是刻意设计的：NEXENT 支持 20+ 文档格式，用 md/docx/xlsx 三种格式可以验证解析、切片与表格检索效果。

## 二、数据边界（重要）

- 所有内容为 **2026-10 整理的演示资料**，不是实时数据；门票、汇率、签证政策以官方渠道为准。
- 文档内已标注「示例」「以官网为准」的字段，智能体回答时应保留这些限定语。
- 预算为区间估算，不是报价；不承诺可订到该价格。

## 三、切片建议

NEXENT 上传后会自动解析与切片。为提升检索命中率，建议：

1. **按二级标题切片**：每片 300-600 字，标题保留在片头（本文档结构已按此设计）。
2. **表格独立成片**：预算表、行程表不要和长段落混在一起（xlsx 天然按行切片）。
3. **保留城市名与主题词**：每个 H2 标题都带城市/主题，避免「交通要点」这类无主语标题。
4. **不要过度重叠**：overlap 10%-15% 足够，过高会导致重复召回。

## 五、维护流程

1. 每次政策/价格更新，只改对应小节，并在文末更新「更新时间」。
2. 文档改名会改变 `document_name`，智能体引用来源会变；如需稳定引用，保留文件名。
3. 新增城市时，同步在 `mcp_server/travel_mcp/data.py` 补充 POI/预算/生活信息，保证知识库与工具口径一致。
4. 每季度跑一次「检索测试问题」+ 智能体评测集，观察命中率与引用准确率。

## 六、与工具的分工

- **知识库**负责「相对稳定、需要解释」的内容：区域逻辑、行程模板、签证材料、注意事项。
- **MCP 工具**负责「实时/结构化」的内容：天气、距离耗时、预算计算、行程骨架、紧急电话。
- 提示词中已规定：涉及实时信息必须调工具；涉及攻略细节优先检索知识库；两者冲突时以工具/官方为准。
