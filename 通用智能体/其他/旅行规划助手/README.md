# 旅行规划助手（旅小伴）

## 简介

「旅小伴」是一个基于 **NEXENT** 的旅行规划智能体。用户用一句自然语言描述出行需求（目的地、天数、人数、预算、同行人），它输出一份可执行、可预算、可溯源的行程方案。

它不是一个只会聊天的旅行顾问，而是把「规划」拆成可验证的步骤：补约束 → 调工具 → 生成行程骨架 → 校验 → 算预算 → 检索攻略 → 六段式输出。

## 功能特性

- **完整行程**：行程概览、每日安排、预算估算、预订清单、风险备选、信息来源，固定六段式。
- **实时工具**：天气（Open-Meteo）、景点检索、路线耗时（OSRM）、预算估算、行程编排、目的地生活信息。
- **知识库**：东京、曼谷 + 清迈、北京/上海/成都，以及预算、签证、亲子与长辈主题。
- **可信标签**：【已核实·工具】【知识库】【估算】【需确认】，明确区分事实与推测。
- **多轮调整**：支持「把第二天改成亲子」「预算压到 1.2 万」这类局部修改。
- **安全边界**：不代订、不编造价格、不索取证件号；对签证与价格给官方链接与复核提示。

## 技术架构

```
用户 → NEXENT 智能体（旅小伴）
        ├── 职责/约束/示例提示词
        ├── 知识库检索（6 份语料）
        └── MCP 工具（travel-planner-mcp，6 个工具）
                ├── get_weather      天气（Open-Meteo）
                ├── search_poi       景点/片区/门票
                ├── plan_route       距离与耗时（OSRM）
                ├── estimate_budget  分项预算 + 机票区间
                ├── build_itinerary  按片区生成行程骨架
                └── get_local_essentials 货币/插头/紧急电话
```

- 模型：`deepseek-flash`（也可用 `deepseek-v4-pro`、`qwen-max`）
- 向量模型：`BAAI/bge-m3`
- 最大步数：15
- 智能体变量名：`travel_planner`

## 工具清单

| 工具 | 作用 | 数据来源 |
| --- | --- | --- |
| `get_weather` | 未来 1-14 天天气、降雨、风力 | Open-Meteo，无需 Key |
| `search_poi` | 景点/街区/美食检索 | 本地精选库 + OpenStreetMap 兜底 |
| `plan_route` | 两点距离与预计耗时 | OSRM 路网 + 速度折算 |
| `estimate_budget` | 住宿/餐饮/交通/门票分项预算 | 规则模型，可按人数天数计算 |
| `build_itinerary` | 按片区聚类生成逐日行程骨架 | 本地算法，避开周一闭馆 |
| `get_local_essentials` | 货币、插头、饮水、紧急电话、交通卡 | 本地知识库 |

## 知识库

`knowledge_base/` 内含 6 份语料：

| 文件 | 内容 |
| --- | --- |
| `01-东京5日深度游.md` | 区域逻辑、5 日模板、交通、预算、避坑 |
| `02-曼谷清迈7日双城指南.md` | 双城分配、季节、寺庙礼仪、实用信息 |

| `04-旅行预算与预订清单.xlsx` | 预算科目、城市日均、预订时间线、行前清单 |

## 导入步骤

### 1. 准备模型

在 NEXENT「模型配置」中添加：

- LLM：`deepseek-flash`（`https://api.deepseek.com/v1`）
- Embedding：`BAAI/bge-m3`（`https://api.siliconflow.cn/v1/embeddings`）

### 2. 启动 MCP 工具

```bash
cd mcps/travel-planner-mcp
python -m travel_mcp --transport http --port 8765
# 或
docker compose up -d --build
```

健康检查：

```bash
curl http://127.0.0.1:8765/health
# {"ok": true, "server": "travel-planner-mcp", "version": "1.0.0", "tools": 6}
```

在 NEXENT「MCP 仓库 → 我的 MCP」添加远程服务：

- 名称：`travel-planner-mcp`
- URL：`http://host.docker.internal:8765/mcp`（Linux 用宿主机 IP）
- 认证：无

点击连通性校验，保存并启用。

### 3. 建知识库

「知识库配置」→ 新建 `旅行规划知识库` → Embedding 选 `BAAI/bge-m3` → 上传 `knowledge_base/01-06` 六份文件 → 等待「已就绪」。

### 4. 导入智能体

「智能体配置」→「导入」→ 选择 `agent.json` → 选择模型 → 绑定上一步的知识库 → 保存。

> `agent.json` 里记录的知识库索引是导出环境中的 ID，导入后需要重新绑定当前环境的「旅行规划知识库」；MCP URL 如与本机不同，也需要在「MCP 配置」中改成你的地址。

### 5. 调试与发布

先问一句「东京明天天气怎么样？」确认工具调用正常，再点「发布」。

## 使用示例

> 11 月 2 日从上海出发，去东京玩 5 天，两个人，预算一万五，想看经典景点也想吃好一点。

期望输出：行程概览 → 每日行程 → 预算估算 → 预订与准备 → 风险与备选 → 信息来源，并标注哪些来自工具、哪些是估算。

> 带 60 岁父母和 5 岁孩子去北京 3 天，怎么安排不累？

期望输出：每天不超过 2 个核心景点、提示预约与体力、给午休与备选。

> 帮我订五一东京的酒店，顺便把签证也办了。

期望输出：明确说明不能代订，给筛选条件、比价渠道与签证材料清单。
