# CHANGELOG

## v1.0.0 — 2026-11-11

首个版本。

- 结构化提示词：职责与工作流（5 步）→ 约束 → 输出格式（五段式）→ 示例
- 工具依赖：仅 `tavily_search`（联网检索），用于查景点、交通、季节等公开信息；未配置时降级为通用经验 + "需出行前核实"提示
- 预算分项估算：交通 / 住宿 / 餐饮 / 门票 / 杂项，区间值 + 币种，超支给降本替代方案
- 诚实标注：实时价格、营业时间、库存类信息统一标注"建议出行前核实"，不编造数据
- 信息不足时先澄清最关键的一到三项，不反复追问；需求冲突时说明并给优先级建议
- 零额外依赖：不使用知识库、不依赖平台内置技能包，导入后选择模型 + 填 Tavily API Key 即可

### 导出说明

- `agent.json` 由 Nexent v2.8.3 平台导出，已做如下清理：
  - 移除环境相关字段（`tenant_id` 等），避免把部署环境信息带进公共仓库
  - `tools` 仅保留提示词实际使用的 `tavily_search`，并清空 `tavily_api_key`（请填入自己的 Key）
  - 清空 `skill_names` / `model_ids` / `model_names`：不绑定平台内置技能包与特定模型，导入后自行选择
- 导入步骤：智能体开发 → 导入 → 选择 `agent.json` → 选择对话模型 → 填写 Tavily API Key → 发布
