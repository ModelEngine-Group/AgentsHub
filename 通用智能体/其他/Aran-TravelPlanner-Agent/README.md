# Aran 旅游规划助手

基于 Nexent v2.8.3 配置的中文旅游规划智能体，根据目的地、出行日期和旅行时长，整理逐日行程、景点路线、交通建议、美食推荐及季节穿搭建议。

## 文件

- `agent.json`：智能体导出配置，已清空搜索 API Key 和租户标识，作者邮箱替换为 Aran。
- `skills/`：随 Nexent 导出的技能包，保留各技能中的原始说明及许可信息。

## 导入和配置

1. 在 Nexent 的智能体管理页面导入配置；若使用 ZIP 导入，将本目录的 `agent.json` 与 `skills` 一起压缩，确保两者位于压缩包根目录。
2. 在模型配置中添加自己的模型服务并检测连通性。原配置使用 `deepseek-ai/DeepSeek-V4.1-Flash`；导出文件中的 `model_ids` 是原环境本地 ID，导入后必须在智能体的“模型与提示词”中重新选择模型。
3. 在工具管理中检查 `deepseek_search`，填写该工具所需的有效 `deepseek_api_key`，并单独测试搜索。模型可对话不代表搜索服务也可用；不同服务商的密钥不保证通用。
4. 确认已导入需要的技能，并检查沙箱、文件工作区和模型输出容量配置。
5. 如需邮件发送，另行配置 `send_email` 的 SMTP 服务；当前导出中的邮件参数未配置。不需要时可移除该工具。
6. 进入智能体调试，验证回答后再发布。

## 使用示例

> 我计划 2026 年 11 月 14 日到南京旅游，玩三天，两人同行，从上海出发，预算总计 3000 元。请规划每日景点、交通、住宿区域、美食及穿搭建议。

> 我想去杭州，但还没决定日期和天数，请先帮我确认需要补充的信息。

## 验证建议

以下为建议测试，未附运行记录，不代表已全部验证：

- 检查三天行程是否完整、路线是否减少折返，是否给出交通和美食建议。
- 检查日期、预算等信息不足时是否追问或明确说明假设。
- 核实搜索工具确实执行成功，实时信息附来源与查询日期。
- 如展示文件产物，检查 DOCX/PDF 等文件能够下载并打开。

## 能力边界

- 提示词包含天气、网络攻略及穿搭需求；当前导出仅包含通用网页搜索，没有独立的天气、地图或小红书接口，不能据此保证实时天气、最短路径或特定平台内容可获取。
- 未成功检索的信息应明确标为估算或待核实；票价、营业时间、班次和天气以官方信息为准。
- 模型与搜索服务需要使用者自行配置，费用和额度以服务商规定为准。
- 本配置包含文件读写、删除及邮件等工具权限；导入者应按自己的使用需要检查和保留。
