# 零售订单字段与净销售额口径

数据为模拟零售订单，每个订单号仅有一条记录。金额单位为人民币元，保留两位小数。按 `order_date` 的自然月份归属，退款也归于该记录的订单月份。

| 字段 | 含义 |
| --- | --- |
| `order_id` | 唯一订单号 |
| `order_date` | 订单日期，格式为 YYYY-MM-DD |
| `category` | 品类名称，按全名匹配 |
| `amount_cny` | 非负订单金额。退款行存储正数退款金额 |
| `status` | `completed` 已完成，`refunded` 已退款，`cancelled` 已取消 |

净销售额 = 已完成订单金额合计 − 已退款订单金额合计。已取消订单不参与金额与排名。只有取消订单的品类不列入排名。存在有效订单且收支相抵时，仍展示净额 0.00。只有退款的品类可出现负净额。

各品类按净销售额降序排列。净额相同共享名次，后续名次按竞赛排名递进，例如 1、1、3。若并列第一，应列出所有并列品类。没有已完成或已退款记录时，提示无可统计数据。
