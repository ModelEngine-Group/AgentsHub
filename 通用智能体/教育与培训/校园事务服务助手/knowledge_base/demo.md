# 校园事务演示知识库

文档 ID：campus-demo-001
版本：0.1.0
来源：本项目原创虚构场景
适用学校：仅示例校园，无真实学校适用性
有效性：只供功能演示，不能作为真实办事依据

## 在读证明
示例流程为：完成校内身份认证，说明证明用途，向示例教务服务中心申请。是否收费、办理时限、领取方式未配置，必须核实，不能自行推断。

## 宿舍报修
示例材料为楼栋、房间及故障描述。助手可以整理报修草稿，不能宣称已提交。遇到火灾、漏电等即时危险，应先远离危险并联系校园应急部门，不等待普通报修流程。

## 校园卡补办
示例流程要求先通过校内身份认证，再由校园卡中心核实办理条件。费用、挂失入口与补办地点未配置，不得编造。不要在对话中索取密码、验证码或完整证件号码。

上线前：由学校负责部门提供正式文件，替换本文并补充来源链接、校区、适用人群、生效和失效日期；演示与正式知识库分开绑定。
