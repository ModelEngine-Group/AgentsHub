# 重庆大学校园事务服务助手

基于 Nexent 平台构建的校园事务问答智能体，面向重庆大学本科生，提供教务学业、校园卡、校园活动、办事指南、宿舍生活等事务的办理流程指引。

## 功能简介

| 服务范围 | 说明 |
|---------|------|
| 教务学业 | 缓考申请、选课、转专业、考试安排等流程指引 |
| 校园卡 | 校园卡挂失、补办、充值等操作指南 |
| 校园活动 | 第二课堂、讲座报名等活动的报名入口与流程 |
| 办事指南 | 各类校内事务的办理步骤、所需材料与注意事项 |
| 宿舍生活 | 宿舍申请、调换、退宿等手续办理 |

智能体回答严格基于知识库与文件分析结果，不凭空编造事实、时间、地点或金额。

## 导入步骤

### 1. 上传技能（Skill）

1. 登录 Nexent 平台，进入「智能体开发」。
2. 选择「技能」→「构建技能」。
3. 上传 `skills/analyze-image.zip`，完成技能创建。

### 2. 导入知识库

`knowledge_base/` 目录包含 16 个分类、642 篇整理好的校园事务文档（纯文本，UTF-8 编码）。按以下方式导入：

1. 在 Nexent 中创建一个知识库索引。
2. 将 `knowledge_base/` 下的各分类 `txt` 文件上传到该索引并完成解析（建议使用 `by_title` 切分策略，各文档以 `# 标题` 分隔）。
3. 记录该索引的 ID，后续配置到智能体中。

> 提示：如果追求最简流程，也可直接上传 `knowledge_base/_合集_全部事务知识.txt`（单文件合集）进行解析。

### 3. 导入智能体

1. 进入「智能体开发」→「导入」。
2. 上传 `agent.json`。
3. 在智能体工具配置中，将 `knowledge_base_search` 工具的 `index_names` 参数填写为你上一步创建的知识库索引 ID。
4. 选择大语言模型，完成安装。

### 4. 发布

配置完成后发布智能体，即可在问答中使用。

## 注意事项

- `agent.json` 中 `knowledge_base_search` 工具的 `index_names` 默认为空，**导入后需自行填写**本地知识库索引 ID。
- 知识库内容整理自重庆大学官网公开信息与学生经验分享，信息等级字段（A=官方发布、B=学生经验）已标注在每篇文档头部。
- 涉及金额、电话、时间等时效性信息，建议以重庆大学官网最新发布为准。
