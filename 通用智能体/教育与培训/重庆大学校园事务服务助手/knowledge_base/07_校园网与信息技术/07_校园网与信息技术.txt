## 0. 前言
虽然网上有很多15分钟就能让你下单电脑的视频或者文章，但是我认为还是要稍微懂一点电脑基础知识，这样才能在购买的时候认清商家的话术，选到最适合自己的，本期干货较多，可能会比较长。还有本期还有一个极简版本发布在蓝盟（https://cqu-openlib.cn/%E7%A4%BE%E5%9B%A2/%E7%A7%91%E5%AD%A6%E6%8A%80%E6%9C%AF%E5%8D%8F%E4%BC%9A/%E8%93%9D%E7%9B%9F/）的微信公众号 重大蓝盟NEW。
接下来进入正片，我认为一个相对科学的选购流程是
1. 了解电脑基础知识。
2. 明确自己的需求，使用场景。
3. 了解不同电脑形态的区别与特色。
4. 选定适合自己的电脑形态。如果一个满足不了，那为什么不试试多个？
5. 了解同一类型电脑下不同型号的区别。
6. 选定型号，配置。
此外，不同平台购买也有区别。购买之后也不是开箱即用。要检验一下电脑功能是否正常。还有一些推荐的初始化设置，让你的电脑更加好用，我会之后单独出一期文章。好了，接下来进入正片。

## 1. 电脑基础知识
第1步，先了解一下电脑基础知识，电脑都是由哪些部件组成的。
### 1.1 核心的部件
CPU，GPU（又称显卡），硬盘和内存，其他还有一些主板，电源，散热。
#### 1.1.1 CPU
CPU是电脑的大脑，负责处理电脑几乎全部的数据。你在电脑上的所以操作都要用到CPU， CPU也是你电脑卡不卡的决定性因素。
#### 1.1.2 内存
内存是电脑的草稿纸，应用和数据需要从硬盘写入内存才能正常使用，内存越大你能同时开的应用和网页就越多。
#### 1.1.3 GPU（又称显卡）
显卡是电脑的图形处理中心，主要的使用场景是在一些复杂的3D游戏中渲染画面，此外还能跑AI，大模型之类的。
#### 1.1.4硬盘
硬盘是电脑的仓库，下载的应用视频文档都需要放在硬盘内。
### 1.2 其他
#### 1.2.1 散热
其他重要的就是散热了，电子产品自然是需要消耗电才能工作的，消耗的电能也绝大部分转化为了热量。
电脑上有两个发热大户，CPU和GPU，谁在正常工作温度区间内能释放更多的热量，消耗更多的电能，谁就能获得更强的性能。
#### 1.2.2 主板
主板，是电脑的工作平台，连通并安装各个硬件，集成了许多设备。
#### 1.2.3电源
电源，电脑各个配件需要的都是低压直流电，而电源适配器，可以将220伏的交流电转化为电脑工作所需要的低压直流电。
#### 1.2.4 网卡
网卡，顾名思义，是无线上网时，负责处理数据的硬件。部分台式电脑可能没有。
#### 1.2.5 其他
笔记本上还有键盘，触控板，屏幕，摄像头。这些就不一一细讲了。

## 2. 明确电脑的需求和使用场景
### 2.1 需求
需求，即你要用电脑干什么，我一般分为三方面，专业需求，游戏娱乐需求，兴趣爱好需求。
我推荐等专业录取之后问一下所在学校的学长学姐，看一下自己的培养方案，课程可能会用到哪些软件。比如说我们学校的博雅学院就需要学微积分，某些医学生也要学编程。具体情况具体分析，前面的也只是一种概述。
#### 2.1.1 专业需求
##### 2.1.1.1 文科
日常办公，WORD，PPT，浏览网页文献，对电脑性能需求较低。
##### 2.1.1.2 理工科类
理工科。很多专业需要用到仿真建模之类的软件，对电脑性能有一定要求。大部分都是需要强力CPU，但还有小部分需要用到独立显卡。
还有计算机类的，编程早期学习阶段本身不怎么需要电脑性能，但是搞到后面一些深度学习之类的会吃显卡。提一嘴编程的环境，这也是一些人使用Linux或者Mac OS的原因。
##### 2.1.1.3 艺术类
摄影绘画相关会对色彩有额外要求。
#### 2.1.2 游戏需求
不同游戏的性能需求天上地下，游戏类型相似，画面相似的游戏也可能因为优化不同，对性能的要求截然不同，而且不同人对分辨率，画质和帧率的要求截然不同，所以游戏不能一概而论。
但为了便于理解，我还是分了3类，该分类图一乐。
一类是各种2D游戏，这种几乎不吃性能的。
还有就是原神星铁，还有各种手游模拟器，无畏契约之类的，对于性能要求不高，好一点的核显，也能低画质流畅游玩了。
最后就是大型3A，需要一定性能的独立显卡。
总而言之，想要畅玩3D游戏就需要独立显卡。
### 2.2 使用场景
使用场景上，主要是宿舍，图书馆，教室实验室，还有携带电脑出行。
#### 2.2.1 宿舍
宿舍，平时使用电脑的需求多而全，什么办公做作业，打游戏，跑渲染等等，那主要考虑以下几点：

- 是否会断电
- 是否会限制最大用电功率，即限电
- 是否会断网
- 有没有空间放下显示器

如果有一项的话，那都不推荐买台式。
虽然但是限电这一项不是特别严谨，中端配置台式机和游戏本的功耗并不会相差特别大
#### 2.2.2 图书馆
图书馆，那就是看网课，查文献，做ppt word之类的。那就要考虑

- 有无插座，电脑是否要长时间离电使用
- 电脑的噪音
#### 2.2.3 教室实验室
教室实验室类似于图书馆，那就要考虑：

- 有无插座，电脑是否要长时间离电使用
- 电脑的噪音
#### 2.2.4 出行
简而言之就是电脑的便携性，还有移动办公的体验怎么样。

- 是否要在出行途中使用电脑？
- 假期的话电脑将如何安置？
- 是否需要带回家？

问了以上这些问题，你应该对你的需求使用场景有一个大概的认识。
需要注意的是这个需求不是静态的，大二和大四对于同一个软件的使用可能是截然不同的。可能学习前期跑的数据量比较少，轻薄本也能从容应对，到了后期数据量就会指数级增长，要上台式机了。

## 3. 了解电脑形态与分类
### 3.1 系统
首先，根据系统不同，电脑分为Windows电脑和Mac电脑，这两个电脑的软件是不互通的。
很多老师可能会给你发学习版的Windows软件，这在Mac上是不能正常使用的，平时在windows上面玩的游戏啊，很多也没有适配Mac。
简单讲一下MacBook的特点，剪视频，修图很强，续航很强，内存和硬盘很贵，能打的游戏非常有限。
具体请看苹果电脑MacOS入门
简单评价一下，如果你不确定你是否适合MacBook，那么就不要把Macbook作为唯一一台电脑。如果你对10小时以上的续航是刚需，那就只有Macbook可选。半年后，Windows阵营可能会有续航改观。
### 3.2 产品类型
Windows阵营主要有笔记本和台式机，其他还有迷你主机，笔记本平板2合1电脑。
#### 3.2.1 笔记本平板2合1电脑
先讲其他吧，首先就是这个笔记本平板二合一电脑。

- 特点：
	- 搭载windows系统
	- 可以兼容windows上绝大部分软件的
	- 支持触控和手写
	- 大小类似于平板，常见11寸与13寸
- 优点：
	- 记笔记流畅
	- 能使用Windows生态，兼容性好
	- 轻便，不带键盘，普遍能做到1千克以下
- 缺点：
	- Windows本身就不是对触控做优化的，触控操作逻辑很烂
	- 对续航也没有优化，续航也很烂
	- 体积小，散热也没法做大
	- 性能弱鸡
	- 随便用用就发热严重
- 评价
	- 现在连更新这个品类的厂商都很少了，也就Surface在出新产品，可见这个品类多小众。
#### 3.2.2 迷你主机
然后就是迷你主机了

- 特点：
	- 体积较小，和机顶盒差不多大
	- 没有独立显卡
	- 散热水平和轻薄本类似
	- 大部分型号需要外接电源使用
- 评价：
	- 有一说一，这东西应该不是给学生党用的，适合那种办公党，因为他没有自带屏幕和键鼠，需要外接电源，显示器之类的。适合那种需要在固定场景办公，但是需要将电脑移动，并且没有什么性能要求的人。
#### 3.2.3 高性能笔记本
然后就是基本上所有人都会选购的笔记本和饱受争议的台式机
过去可能会有全能本这个品类，但是现在笔记本之间的配置更加泾渭分明了。所以我将有独立显卡的称为高性能笔记本，又称游戏本，没有独立显卡的称为轻薄本。
当然，笔记本的形态还有很多，但是万元以下主要就分为这两类，特殊的设计要额外的价格支撑。这两者的核心区别在于有没有独立显卡啊。有独立显卡，那独立显卡需要大量功耗，那游戏本相较于轻薄本就需要更大的散热，也就意味着更大的厚度，质量，体积，体积大了，也能做出更多的接口，扩展性更强。为了满足游戏需求，普遍也会配上高刷新率的屏幕。当然因为功率大，充电器也会更大，满负载的时候噪音也会大。
至于轻薄本，优缺点就反过来了。
总结一下

- 特点：
	- 搭载独立显卡
	- 性能释放在160瓦以上
	- 机身重量在2千克以上
- 优点：
	- 性能释放好，可以从事部分中部生产的需要
	- 4060配置的游戏本就可以满足基本的游戏需求
	- 屏幕普遍刷新率高，响应时间快
	- 可以满足入门级的AI需求
	- 接口大多丰富，基本可以加装或更换内存硬盘
- 缺点：
	- 高负载运行时噪声大
	- 普遍尺寸较大，重量重
	- 部分机型续航不行，重量较重
	- 原装适配器大。不过现在部分机型支持pd充电，可以更换更小的充电器
- 评价：
	- 2千克出头的轻薄游戏本应该是最适合大部分爱打游戏的大学生了，至于显卡上个4060就够了，4070提升不大，差价不大的话可以升级。个人不太推荐，价位在9000以上的，性价比不高。
#### 3.2.4 轻薄本
- 特点：
	- 没有独立显卡
	- 性能释放普遍在30瓦到70瓦之间
	- 机身重量普遍在1千克至1.5千克之间
- 优点：
	- 相对轻薄
	- 大部分支持pd充电，自身电源适配器也小巧
	- 续航轻薄本一般会大于游戏本，但是还是要具体型号具体分析，看实测数据
- 缺点：
	- 没有独立显卡，基本上不能玩大型3D游戏
	- 接口较少，普遍缺少网线接口
	- 内部扩展性差，部分型号不能加装内存或硬盘
	- 没有快速响应的高刷新率屏幕
	- 散热差，同CPU型号性能不如游戏本，难以进行一些高负载的应用
- 评价：
	- 适合那些需要从事文字工作，并且只打一些轻度游戏，需要经常外出，对重量敏感的人。

好了，接下来就是对照上面的需求选定对应型号的电脑了。
主流的轻薄本价位段在3000~5000，主流的游戏本价位段在5000到8000。
在往上的话，同类型提升不大，性价比不高，我是更推荐买多样。

#### 3.2.5 台式机
- 优点：
	- 性能释放强，扩展性强
	- 可以接视频采集卡之类的实现进阶功能
	- 更大的体积也可以在相同散热条件下做到更小的噪音
- 缺点：
	- 基本无法搬运
	- 不能断电
	- 对空间要求高
- 评价：
	- 不推荐将台式机作为唯一一台电脑，更适合搭配轻薄本使用。低端台式机，拓展性可能还比不上笔记本。台式机反而是价格越高，越能体现出他的独特优势。
如果要追求便携性组装ITX主机，那又会损失扩展性和噪音。就算是相对便携的ITX，那也只是适合偶尔移动的人群，因为不自带显示器要和电源，无法做到移动办公。

#### 3.2.6 其他
其他还有平板电脑，虽然总是被嘲讽为泡面盖，大号手机，但是其记笔记看网课还是有其生态位的。
如果你想同时兼顾工作时的静音和高续航，你也可以选择台式电脑加轻薄本，预算足够还可以把轻薄本换成MacBook。
有一种方案，学习前期先买性能过得去的电脑，到了学习后期再升级更高配置，此时硬件也更新迭代了，性价比更高。
还有就是不要因为预算改变电脑类型，如果真的没钱的话，那可以考虑一下二手或者上一代同类型的电脑。

## 6. 到手验机
### 6.1 快递收货，检查包裹完整性，电脑外观
- 有条件的话可以跟快递员一起开箱
- 必须录开箱视频，检查箱体封条是否完好无损，并对每一个面拍摄尽可能清晰的照片
- 开箱视频流程：
	- 最好有朋友帮你拍，或者找个支架，画面中同时露出你和包裹
	- 拍下快递面单，环绕拍摄，展示包裹完整性
	- 一镜到底，打开包裹，取出笔记本包装盒
	- 检查笔记本包装盒封条是否完好，如果有曾经贴过别的封条的痕迹，那么很有可能是已经开封过又再次密封的机器
	- 向镜头展示笔记本包装盒背面的SN码
		- SN码类似于电脑的身份证码，你可以通过SN码在品牌官网查询到电脑的保修，如果保修被日期异常或者已经绑定了其他账号，那么这台机器可以直接退货了
		- 如果SN码有涂抹，推荐也是直接退货
	- 打开笔记本包装盒，检查配件，检查电源线是否扎在一起，电源是否有使用痕迹
	- 查看笔记本本体，笔记本本体一般会有单独的包装，检查包装完整性

### 6.2 开机，初始化设置
- -首先不接电源开机。如果能开机，说明电脑为退货机。
- 然后接电开机，看是否进入系统激活页面，如果直接进入系统，显示电脑桌面的话，就是退货机。
- 进入激活界面后，切勿联网
	- 因为联网会自动激活 Windows，而激活后的笔记本不支持无理由退货。
	- 建议自行百度查看如何不联网开机，或者请看视频：最新的win11系统如何跳过联网激活（https://www.bilibili.com/video/BV1aP41127Qn/）
- 开机过程中，推荐设置英文用户名（因为部分软件安装时会因为中文用户名导致安装失败）

### 6.3 检验功能是否正常
下载图吧工具箱（https://www.tbtool.cn/）

- 检查配置是否正确
- 检查硬盘通电时长
- 检查屏幕是否有明显缺陷
- 检测CPU温度稳定性
- 检测显卡温度稳定性
- 检查各个键盘按键是否有反应
- 其他不怎么重要的项，但还是可以检查一下
	- 检查各个接口能否正常使用
	- 检查摄像头能否正常使用
	- 检查触控板能否正常使用

电脑如果想退货的话，有两个关键时间节点7天和15天，如果你的电脑没有激活，那么0~7天是可以完全无理由退货的。如果你的电脑有轻微瑕疵，那么7~15天是可以退货的，至于15天之后，那估计要走保修了。

## 7. 实用小TIPS：
### 7.1 英文用户名
许多应用中文用户名会报错无法正常使用。
### 7.2 数据备份
- 重要数据记得备份
	- 上云盘或异地备份
- 硬盘分区
	- 对自己的文件进行整理归类
	- 把重要文件移出 C 盘
- 关闭bitlocker
- 定期检查硬盘SMART信息

### 7.3 电池健康
- 尽量插电使用

### 7.4 解压软件

# 重大校园网那些事

## 一、前言

2026 年暑假，信息办调整了校园网，新增免费套餐，并引入三家运营商。本文基于新版校园网政策撰写，整合信息办及各大运营商发布的内容，提供最新、准确的信息。

只要你是重庆大学的学生，无论你有没有办校园网，有没有办校园流量卡，就可以访问学校的资源，比如知网万方维普等数据库，教务系统（选课、查看成绩）。

校园网不同套餐主要影响使用校园网访问校外网络时的速度。

部分服务在校外访问时，需要使用 aTrust 或 CARSI，具体方法见校园网使用技巧。

## 二、信息办新闻

- 重庆大学信息化办公室官网（https://net.cqu.edu.cn/）
- 校园网办理及使用指南（https://net.cqu.edu.cn/info/1015/3078.htm）
- 关于校园网资费调整的通知（https://net.cqu.edu.cn/info/1007/3077.htm）

本文内容主要参考重庆大学信息化办公室发布的资料。如相关政策发生变化，请以信息化办公室的最新通知为准。

## 三、名词解释

- *学生卡*：学校在新生入学报到时发放的一卡通，也称饭卡。除实体卡外，也支持添加到手机 NFC 中，可用于校内消费和部分身份认证场景。

- *校园流量卡*：运营商手机电话卡。它常被售卡人员称为“校园卡”，但与学校发放的学生卡不同。三大运营商均有此类产品，其特点是包含可在全国、重庆或校园范围内使用的大流量包。需要注意的是，校园流量卡套餐一般都有合约期。
- *合约期*：一般为一年，具体期限会在协议中写明。在约定期限内，销户或更改为资费更低的套餐通常会非常麻烦，因此办理前需考虑自己是否会一直使用到合约期结束。

- *校园网*：重庆大学的网络。用户既可以访问校内网站等内部资源，也可以访问 B 站、抖音等外部网站。使用“单宽带免费”套餐时，无需捆绑办理校园流量卡；若有更高需求，需办理融合套餐。

- *融合套餐*：将校园流量卡与校园网绑定销售的套餐，相当于同时购买两者的服务，目前无法单独办理不限量的校园网，只能办融合套餐，但请注意，此类套餐也有合约期。

## 四、基本网络知识

### 1、我们该如何上网

在大学，想要访问互联网，不外乎办理流量卡或者办理宽带，在我们学校这个宽带就是校园网。此外随身 Wi-Fi 也是内置流量卡。

### 2、校园网与流量卡

- 校园网：学校在校内各处铺设的有线网络和无线热点（CQU_WIFI）。用户可以连接 Wi-Fi 或插入网线使用。
- 手机流量：由运营商建设的公共移动网络，通过基站为手机等设备提供无线网络服务。

Q：为什么在校内使用手机流量不算使用校园网？
A：连接 Wi-Fi 或使用网线时，用户的网络访问会先经过校内网络中心；如果访问的是校外资源，则会再转发给运营商处理。使用手机流量时，网络访问会直接进入运营商网络，与学校无关。
简单判断：不会弹出校园网登录页面（login.cqu.edu.cn）的网络，一般不是校园网。

### 3、是什么在影响我们的上网体验

- 主要是带宽、延迟。此外还有很多其他影响因素，我会放到最后的问答环节。

我们可以把网络比作快递
- 带宽就是快递在单位时间内的货运量。
- 延迟就是快递从发货到到达收货的时间。
- 流量就是快递的运输总量。

| 术语     | 单位         | 主要影响                 |
| :----- | :--------- | :------------------- |
| 带宽 | Mbps 或MB/s | 视频播放能开什么分辨率、文件下载是否快速 |
| 延迟 | ms（毫秒）     | 游戏是否延迟、视频会议是否有明显延迟   |
| 流量 | MB 或 GB    | 与部分计费方式有关            |

### 4、数据大小与网速

正如理解速度首先要理解路程，要理解网速，首先需要理解数据大小。

常见数据大小单位：GB 吉字节    MB 兆字节    KB 千字节    B 字节    b 比特。

- G M K 表示数量级，分别表示 十亿 一百万 一千。
- 比特是计算机网络传输中的最小单位，1 字节 = 8 比特。

将数据大小除以时间就是网速。

网速有两种常见单位，MB/s 与 Mbps ，这两个单位有区别：
- Mbps 的全称是兆比特每秒。
- MB/s 的全称是兆字节每秒。

根据前面提到的 1 字节 = 8 比特    可得 8 Mbps = 1 MB/s
例如，200 Mbps = 25 MB/s    50Mbps = 6.25 MB/s    5Mbps = 0.625 MB/s
- 1000 Mbps 可以简写成 1000 M 。
- 带宽即运营商限速下能跑到的网速上限。

介绍完理论，那我们结合一下现实场景，这些数据大小和网速都对应着什么
数据大小
- 一张高清图片 1MB ~ 20MB
- 一首无损音乐 20MB ~ 50MB
- 一本电子书 5 MB ~ 200 MB
- 一部 1080P 高码率电影 2 GB ~10 GB
- 一堂网课（以宋浩30小时的线性代数网课为例） 30 GB
- 电脑版原神 100 GB
网速
- 斗鱼直播原画画质 10 Mbps  蓝光画质 4 Mbps
- B站抖音 1080P 视频 0.5 Mbps ~ 5 Mbps
- 云原神 15 Mbps ~50 Mbps
- 常见竞技游戏 0.5 Mbps ~ 3 Mbps

我们也可以根据网速估算下载时间

- 下载一个100 MB 的电子书/PPT，200 M 需要 4 秒，50 M 需要 16 秒，5 M 需要160秒。
- 下载一个 40 GB 的游戏，200 M 需要 27 分钟，50 M 需要 100 分钟，5 M 需要 18 小时。

### 5、上网计费方式

本文涉及的计费方式主要有三种：

- 按带宽计费：限制最高带宽，不限制流量，用多用少费用一致。
- 按流量计费：限制流量上限，带宽限制相对宽松。套餐一般会包含一定额度，在流量未超过额度时无需额外付费；超过额度后，则可能根据具体资费标准额外收费。
- 达量降速：前两种方式的结合。套餐一般会设置流量额度，在额度内的带宽限制较为宽松；超过额度后，带宽会受到严格限制，但不会额外扣费。这是校园网单宽带免费套餐的计费方式。

## 五、学校套餐介绍

校园网的“单宽带免费”套餐可以在校园网自服务系统（http://user.cqu.edu.cn/）中办理和管理，也可以查看已使用流量和登录设备。

办理方法：手机登录“今日校园”APP，搜索上网账号申请；或者电脑端打开校园网自服务系统（http://user.cqu.edu.cn/）填写相关信息，提交申请后，系统将会自动生成上网账号。
具体办理流程见校园网办理及使用指南（https://net.cqu.edu.cn/info/1015/3078.htm）。

> 注：新版校园网没有“300 元包年 50 Mbps”的套餐了，新用户不能办理，但已办理的用户不受影响。

### 1、单宽带免费

学校提供“单宽带免费”套餐，无需付费。

限制策略：达量限速、不限总量。根据实测，每月使用量在 40 GB 以内时，带宽约为 200 Mbps；超过 40 GB 后，带宽约为 5 Mbps，但仍可继续使用，且不限制总流量，也不影响延迟。实际速度可能因网络环境和设备等因素有所不同。

上述限制仅针对校外服务，访问校内服务不受该带宽限制。

Q：超过 40 GB 后是否无法继续使用？
A：不是。超过后仍然可以使用，但带宽会受到严格限制。当前实测约 5 Mbps 时，可以满足基本的网页浏览、低画质视频观看、微信QQ消息收发，以及少部分对带宽要求较低的网络游戏，但不适合播放高清视频或下载大文件等场景。

### 4、国内、地区、校园及定向流量

这些概念均指手机流量，区别在于适用范围：

- 国内流量：最通用的一类流量，可在全国范围内使用。
- 地区流量：仅限在特定地区使用，例如仅限重庆市内使用。
- 校园流量：适用范围更小，仅在校园内有效。
- 定向流量：运营商会提供一份应用名单，使用名单内的应用时可以消耗定向流量。一般需要绑定与流量卡相同手机号的账号，并手动开启应用内的免流功能。

因此，办理套餐时不能笼统地理解为“总共有 xx GB 流量”，而应具体了解各类流量的构成。
### 5、办理前注意事项

- 建议先了解免费套餐政策。
- 如确有更换运营商的需求，可以了解携号转网；如需保留原号码，可以了解相应的低资费保号套餐。
- 应分别确认国内流量、地区流量、校园流量和定向流量的额度，不要只比较流量总数。
- 应确认套餐价格是否会在优惠期结束后上涨，以及赠送会员等权益的有效期。
- 应确认合约期限，以及提前销户、降档或转网的具体条件。
- 签署各项协议时应仔细阅读，了解各项规定，如有疑问请勿签署，当场提出。

再次提醒：办理融合套餐通常有合约期，一般为一年，具体期限以办理时签署的协议为准。请谨慎决定是否办理，并在签署各项协议时仔细阅读、了解其中的各项规定。

## 六、校园网使用技巧
### 1、在校外访问学校网站及资源

- 关于部分信息系统在校外需通过 VPN 访问的通知（https://net.cqu.edu.cn/info/1007/3056.htm）
- 重庆大学 aTrust VPN 系统用户使用指南（https://net.cqu.edu.cn/info/1015/2899.htm）

部分校园服务无法在非校园网环境中直接访问，需要通过 aTrust 工具打开。

校园网并非必需。即使不使用校园网，仍然可以访问此类服务，只是操作会比在校园网环境中稍麻烦。

### 2、学校购买的学术资源

- 教育网联邦认证与资源共享基础设施（CARSI）（https://www.carsi.edu.cn）

学校购买了部分学术资源。在校园网环境中访问此类资源平台时，平台会自动识别访问者为已获授权的用户。

在非校园网环境中，也可以访问学校已购资源。只需通过资源平台的 CARSI 登录入口选择“重庆大学”即可。例如，访问知网时可以前往 fsso.cnki.net（https://fsso.cnki.net） 登录。

如果平台没有 CARSI 登录选项，可以使用上文所述的 aTrust 工具访问。

常见问题：CARSI 登录使用以 3 开头的统一身份认证号，学号和身份证号无法登录。

### 3、全球漫游服务Eduroam

- eduroam 用户指南（https://net.cqu.edu.cn/info/1015/2900.htm）

重庆大学已加入 eduroam（https://www.eduroam.edu.cn）。本校师生前往其他加入 eduroam 的高校交流或访学时，可以使用重庆大学账号连接当地的 eduroam 无线网络；其他成员高校的师生来校时，也可以使用其所属学校的账号连接重庆大学的 eduroam 网络。

登录账号的格式为“校园网上网账号@cqu.edu.cn”，注意使用时需保证上网套餐处于正常状态（非停机、融合套餐撤机等异常状态）。

## 七、学生卡使用指南

### 1、主要用途

- 校内消费：可在食堂、超市、校车等场景使用。
- 身份认证：参加部分校内考试或办理校内事务时，可作为身份证明之一。具体要求以相关通知为准。

### 2、充值方法

1. 关注“重大财小通”微信公众号，依次选择“缴费充值”-“校园一卡通”-“卡片充值”。
2. 使用学号登录。初始密码一般为身份证号码数字部分的后六位，如无法登录，请根据页面提示重置密码或咨询相关部门。
   例如，身份证尾号为 12345678，则密码为 345678；尾号为 1234567X，则密码为 234567。
3. 登录后选择“标准卡账户”充值，即便开通了校园卡的 NFC 功能，也要充值“标准卡账户”。

通过第三方渠道充值后，资金可能会延迟到账。一般可以等待数分钟后再次查询；如长时间仍未到账，应保留支付记录并联系相关部门处理。

### 3、实体学生卡的替代方式

- 手机NFC校园卡开通及使用指南（https://net.cqu.edu.cn/info/1018/2901.htm）

电子证件：可以使用“今日校园”中的电子证件和电子学生卡二维码完成部分身份认证或支付操作。

NFC：大部分手机（苹果手机除外）支持将学生卡添加到手机 NFC 中，可用于食堂、超市等场景。

## 八、FAQ

### 套餐选择

##### Q：我是原来的 300 元包年套餐用户，能否继续使用？
  A：可以。该套餐已停止新办，但原有用户的套餐仍会长期有效，毕业前不会被取消。需要注意的是，如果改为其他套餐，则无法恢复为 300 元包年套餐，请谨慎决定。

##### Q：不同带宽应该怎么选？
  A：单宽带免费套餐超过 40 GB 后实测带宽约为 5 Mbps，可以满足基本的网页浏览、低画质视频观看、微信QQ消息收发，以及少部分对带宽要求较低的网络游戏。50 Mbps 可以满足除大文件下载外的绝大多数使用场景（大文件仍可下载，但会花费较长时间）。200 Mbps 更适合频繁下载大文件、游戏本体或更新的用户。

##### Q：哪些人适合使用“单宽带免费”套餐？
  A：一是极少使用电脑的用户，绝大部分学习娱乐都在手机上完成；二是已经拥有大流量手机流量卡，在需要下载大文件时，可以使用手机流量。

##### Q：我看很多人都反馈免费校园网限速后的 5 Mbps 刷视频都卡，是这样吗？
  A：首先每个人对于刷视频的需求都是不同的，视频有不同分辨率，视频也可以开倍速，也要考虑拖动进度条之后是否会卡顿，5 Mbps 可以满足对画质要求不高的网课的倍速播放需求，但是如果要观看清晰高画质的视频，并且倍速或者拖动进度条，确实可能会出现卡顿。如果觉得校园网确实很贵，使用免费校园网，要下载文件时切换手机网络共享，虽然麻烦，但确实能省钱。

##### Q：我原来使用电信的 59 元或 69 元融合套餐，需要更换吗？
  A：根据官方信息，原套餐可以继续使用。但新套餐实际上比旧套餐更优惠，因此可以考虑更换为新套餐。请注意，更换套餐后，合约期会重新计算。

##### Q：是否需要在入学后立即办理融合套餐？
  A：不需要。单宽带免费套餐可以随时使用，可以先阅读本文档对于免费套餐的介绍，并且根据一段时间内的实际流量消耗和网络需求，再决定是否办理有合约期的融合套餐。

##### Q：如何判断各运营商的信号表现？
  A：三家运营商在校内基本都实现了全覆盖，各家整体差异不大。但信号会受到校区、建筑物、周边基站、使用人数和手机硬件等因素影响，可以先向同宿舍或同楼栋的同学了解实际情况，再作选择。

##### Q：多少流量够用？
A：因人而异，建议使用几天了解自己的习惯，也可以参考数据大小与网速一节估算。
### 校园网使用与故障

##### Q：网速太慢怎么办？
  A：首先确认是带宽低，还是特定网站访问缓慢。如需测速推荐使用中国信通院推出的全球网测(可以在各大手机应用商店下载)。访问部分境外网站时，也可以切换手机热点或开启加速器进行对比。上述方法无法突破套餐本身的带宽上限。

##### Q：校园网网络延迟怎么样？
  A：影响延迟的主要因素之一是网络接入方式，一般而言：有线网络 < 无线网络（Wi-Fi）< 5G 手机流量 < 4G 手机流量（从左到右，延迟逐渐升高）。此外，发送延迟，传播延迟，处理延迟，排队延迟都会影响延迟表现，解决方法是在打竞技游戏时选择物理距离近的服务器，游玩战地等外服游戏时开启加速器。

##### Q：手机流量的网速怎么没有一个固定的答案？
  A：手机的网速由多个因素决定，首先手机是无线连接到基站，你与基站的远近，是否有建筑物遮挡，都会影响信号；一个基站同时服务于多个人，人多了分到的网速就少了；此外，还受你手机的天线设计、基带性能制约。

##### Q：校园网无法使用怎么办？
A：引起网络故障的原因很多，可以按下面的顺序排查：

1. 查看校园网状态检测，对比不同校区、寝室群和楼栋的探测结果，判断是局部异常还是大范围故障。
2. 查看信息化办公室官网（https://net.cqu.edu.cn/）或者蓝盟服务群是否有维护通知。
3. 检查网线、网口及设备的网络设置。如果手动代理没有使用需求，可以在系统网络设置中将其关闭。

推荐先在蓝盟服务群中咨询。如确认属于上级网络设备或校内网口故障，可在“网上服务大厅”或“今日校园”中搜索“网络故障报修”。

##### Q：登录校园网显示“AC 认证失败”怎么办？
  A：此问题可能是使用了带有临时参数的旧认证网址。可以在地址栏重新输入 login.cqu.edu.cn 后登录。收藏认证页面时，也应只收藏该地址。

##### Q：校园网登录设备类型有何限制？
  A：目前校园网单账号限制同时在三个设备上登录，不区分设备类型。

##### Q：校园网密码忘了怎么办？
A：在手机 App“今日校园”中搜索“密码修改”。

### 学生卡与校园生活

##### Q：宿舍内的智能空调可以远程控制吗？
  A：部分型号可以在连接 Wi-Fi 后使用远程功能，具体方法和支持范围请查看空调说明书。

##### Q：通过微信给学生卡充值后没有到账怎么办？
  A：第三方充值渠道可能存在到账延迟。可以等待数分钟后再次查询；如长时间仍未到账，应保留支付记录并联系相关部门处理。

##### Q：有什么推荐的课表软件吗？
A：不推荐使用第三方课表，因为教务网的课表可能会随着课程安排更新，然而导入第三方课表后，课表数据就不会更新。主编就因此在形势与政策课上走错教室，等到了交论文才发现老师不对。

## 关于校园网

重庆大学校园网包括校内有线网络和无线网络（CQU_WIFI），可以访问校内资源及互联网。2026 年 9 月起，学校实施新的校园网资费政策，新增“单宽带免费”套餐，并引入中国移动、中国联通和中国电信三家运营商的融合套餐。

## 单宽带免费

学生每月可以免费使用 40 GB 校园网高速流量。额度用完后，访问校外网络会降速，但不会停机或产生费用；访问校内网站和资源不受该带宽限制。可以通过“今日校园”中的“上网账号申请”，或校园网自服务系统（http://user.cqu.edu.cn/）办理和管理。

## 运营商融合套餐

有更高带宽或手机流量需求时，可以自愿选择三家运营商提供的融合套餐。融合套餐包含校园网接入、手机流量和通话服务，通常带有固定月租及合约期，具体资费、流量构成和附加条件以办理时签署的协议为准。

详细政策、套餐比较、校外访问方式和常见故障处理，请看重庆大学校园网那些事。

## 校园网状态检测

遇到校园网变慢、丢包或无法访问时，可以先查看校园网状态检测，对比不同校区、寝室群和楼栋的探测结果，判断异常是集中在当前设备或楼栋，还是同时出现在多个区域。

## 校园网状态检测

重庆大学蓝盟校园网分布式探测（https://probe.lanunion.org.cn/）通过部署在不同校区、楼栋和网络环境中的探测节点，持续执行 ICMP 与 HTTP 拨测，用于观察校园网络运行状态

遇到校园网变慢、丢包或无法访问时，可以先查看：

- 网络状态（https://status.tano.asia/status/net）：对比不同校区、寝室群和楼栋的实时连通情况
- 丢包检测（https://grafana.tano.asia/public-dashboards/a1f8f14d4c074a2ebf2c142f639a1981）：查看各探测节点的延迟和丢包数据

多个区域同时异常时，更可能是校园网范围的问题；只有少数节点异常时，可以优先检查当前设备、网线、Wi-Fi、代理设置或所在楼栋的网络。探测结果受节点在线情况和覆盖范围影响，只适合作为排查参考；故障报修方式见重庆大学校园网那些事

## 接入探测节点

如果有长期连接校园网的服务器、软路由、NAS 或其他设备，也可以在项目主页（https://probe.lanunion.org.cn/）了解接入方式，志愿提供一个探测节点
节点 Token 是身份凭据，请勿公开分享

## 1. 问题复现
- 在 Windows 系统下执行 C++ 或 Python 等程序的代码时，若该代码源码使用 UTF-8 编码，而系统语言为中文，则会出现命令行乱码，如下图所示
    图片：CMD 脚本中文乱码与修复后的命令行对比

## 2. 解决方法
1. 打开 设置 或点击 ++win+i++ 快捷键
2. 点击左侧 时间和语言 栏
3. 点击右侧 语言和区域 栏
4. 点击最下方 管理语言设置 按键
5. 在新弹出的 区域 窗口点击下方 非 Unicode 程序的语言 内容下的 更改系统区域设置 按键
    * 该步需要您目前登录的用户是管理员账户，如果您的电脑仅有一个账户，请忽略这句话
6. 在新弹出的 区域设置 窗口打开下方 Beta 版: 使用 Unicode UTF-8 提供全球语言支持(U) 选项，并点击 确定
7. 确保您的工作已经保存的情况下，重启系统
8. 已完成修复

## 关于蓝盟
重庆大学蓝盟（英文名lanunion）是在重庆大学信息化办公室指导下成立的校级学生社团，是一个为全校师生免费提供计算机系统、软件与网络维护服务的志愿者组织。“蓝客”即蓝盟的正式成员，他们利用自己的电脑知识无偿为大家进行计算机系统、软件与网络维护。

## 服务流程
1. 网上报单
    1. 登陆蓝盟官网内网版（http://lanunion.cqu.edu.cn）、公网版（https://lanunion-cqu-edu-cn.atrust.cqu.edu.cn）进行故障申告；
    2. 服务人员和用户预约维修服务时间并在预约的时间内上门服务；
    3. 用户反馈维修结果（跟帖），如果未能完成，蓝盟将持续安排其他人员进行维修。
2. 服务群/软件咨询
    加入QQ群或者打开镜像网站获得技术支持与帮助。

## 1. 判断操作系统
- 大多数人的电脑（除苹果电脑外）是 Windows 系统
    - 包括：Win 7、Win 10、Win 11 等
    - 特征：左下方含有 Windows 按钮（即四个方形组成的图案）
- 如果您的电脑为苹果电脑，即 Macbook、Macmini 或 Mac Studio，您的电脑是 MacOS 系统
    - 包括：Catalina、Big Sur、Monterey 等
    - 特征：左上方含有 Apple 按钮（即苹果公司logo）
- 其余的电脑绝大部分为 Linux 系统
    - 包括 Ubuntu、CentOS、Deepin 等

## 2. 判断系统架构
- Windows
    - 您可以在 设置-系统-系统信息-系统类型 处找到您电脑的系统架构
        - 64 位操作系统, 基于 x64 的处理器 对应的是 64-bit 版本
        - 32 位操作系统, 基于 x86 的处理器 对应的是 32-bit 版本
        - 64 位操作系统, 基于 ARM 的处理器 对应的是 ARM64 版本
- MacOS
    - 请在命令行使用指令 uname -m 来获取您的 系统架构

## 1. 到底能不能买Mac
对于大多数人，有一个很严重的误解：Mac 不能使用很多工程相关的软件。
澄清一下，事实就是这样的……
但是这不代表你不可以仅仅使用一台 Mac 解决大学生活中的所有问题！
而且，在某些领域下，搭配 MacOS 的电脑会有极强的优势。
你完全可以在更加轻松的界面下使用 Mac 来代替一台 Windows 电脑，
只是这需要一些额外的精力来折腾，比如你现在在看这篇文章。
总之，以下是结论：
当你自己不希望折腾，或者你是一个电脑小白，或者有任何打大型游戏的需求，或者财力不足以支撑苹果公司的定价，请不要使用 Mac 电脑。
如果你拥有 iPhone、iPad 等设备，这是选择 Mac 电脑的一个加分项，因为苹果的生态会使联动更加流畅。
当你打算从事视频音频方面工作、软件大数据计算机方面工作、文科方面工作，且有一定的文字阅读能力和独立思考能力，推荐继续往下阅读。

## 2. 如何使用所谓「不支持MacOS」的软件
你有两种选择：寻找平替，以及安装虚拟机
### 2.1 关于平替
可以举一个例子：Solidworks 的平替 Fushion 360
其中，Solidworks 是有名的 3d 工程建模软件，十分老牌，市场占有率很高，但是由于其底层代码的年代确实比较久远，导致其无法支持 MacOS。
而 Fushion 360 是 Autodesk 公司在最近开发的新型 3d 工程建模软件，界面更加人性化，性能更好，目前使用的人也在逐渐变多。最重要的是，Fushion 360 在导出文件上是完全支持 Solidworks 格式的，这使得（交作业等）工作完全可以不依赖 Solidworks 进行。
目前大多数的不支持Mac的工程软件都是这样的，但是大概率你会找到一个支持Mac的，更加现代，更加人性化的工具来替代它。
至于你想要找的软件的平替到底是什么呢，这个问题不妨去百度？
### 2.2 关于虚拟机

## 3. 常用指令
#### 环境管理
- conda create：创建环境
    - -n {envName}：必要指令，创建新的名为 {envName} 的环境，同 --name
    - -p {path}：必要指令，创建路径为 {path} 且名字为 {path} 最子文件夹的环境，同 --prosix ，与 -n 不兼容
    - {package}={ver}：额外指令，指定新环境的 {package} 库版本为 {ver}

- conda activate {envName}：进入名为 {envName} 的环境

- conda install {package}：安装 {package} 库

- conda update {package}：更新 {package} 库
- conda uninstall {package}：卸载 {package} 库

## 0. 简介
FiraCode 是一款专门为广大程序员们提供的一种编程连字等宽字体。
该字体会对编程语言中的特殊符号做出优化，并提高了代码的可读性。
（原项目链接：tonsky/FiraCode（https://github.com/tonsky/FiraCode））

## 1. 下载
【简洁版】
    * FiraCode-VF（https://api.cqu-openlib.cn/file?key=isauK2fzkqih）
【完整版】
    * FiraCode v6.2（https://api.cqu-openlib.cn/file?key=i0sr52fzowwb）

## 2. 安装
【简洁版】
    下载后打开，点击 安装字体 等类似字样即可安装成功
【完整版】
    下载后解压并打开内部某一文件夹（推荐为 ttf 文件夹）的全部文件，逐一点击 安装字体 等类似字样即可安装成功

## 3. 应用
【VSCode】
    1. 点击左下角齿轮状按钮，选择 设置
    2. 在设置页上方搜索 Editor: Font Family，在最前方加入 Fira Code
        * 如原为 Menlo, monospace，则更改为 Fira Code, Menlo, monospace
    3. 在设置页上方搜索 Editor: Font Ligatures，点击下方 在 setting.json 中编辑
    4. 在弹出的 setting.json 页中的 "editor.fontLigatures": false, 行中 false 更改为 true
    5. 保存后即可生效
【Jetbrains IDEs】
    1. 打开 Settings，搜索 Enable Font Ligatures 并勾选
    2. 打开 Settings，选择 Editor，选择 Font
    3. 选择 Fira Code 作为编辑字体
    4. 点击 Apply 即可生效
【Sublime Text】
    1. 点击菜单栏选项 Preferences，选择 Settings
    2. 在右侧添加 "font_face": "fira code",
    3. 保存后即可生效

        test -r ~/.bash_profile && echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.bash_profile
        test -r ~/.zprofile && echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile

    - 如果您的 系统架构 是 x86_64，您可以跳过此步骤
- 如果您是 Linux 用户，请执行如下指令
    bash
    test -d ~/.linuxbrew && eval "$(~/.linuxbrew/bin/brew shellenv)"
    test -d /home/linuxbrew/.linuxbrew && eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"
    test -r ~/.bash_profile && echo "eval \"\$($(brew --prefix)/bin/brew shellenv)\"" >> ~/.bash_profile
    test -r ~/.profile && echo "eval \"\$($(brew --prefix)/bin/brew shellenv)\"" >> ~/.profile
    test -r ~/.zprofile && echo "eval \"\$($(brew --prefix)/bin/brew shellenv)\"" >> ~/.zprofile

## 5. 常用指令
- brew help：查看有哪些指令可以使用
- brew search {app}：查找软件 {app}
- brew install mongodb：安裝软件 {app}
- brew info {app}：查看已安裝软件 {app} 的信息
- brew uninstall mongodb：卸载软件 {app}
- brew list：列出目前已安裝的软件
- brew outdated：查询有哪些软件版本已经过期
- brew cleanup -n：刪除旧版本软件
    - 默认的情況下，Homebrew 不会删除旧版本的软件，但是这样会导致电脑上存在过多的无用历史版本，建议使用cleanup定期清除（-n 是显示删除过程）
- brew upgrade {app}：更新软件 {app}
- brew update && brew upgrade && brew doctor：更新所有软件

## 2. 安装
#### Windows
1. 打开您下载的文件
    - 该文件名称为 VSCodeUserSetup-{!sys}-{!ver}.exe，一般可以在 下载 文件夹中找到
    - 如果您点击打开该文件，将会弹出安装窗口，如未能弹出请请教他人
2. 阅读许可协议（如果您很闲）并点击 我同意此协议-下一步
3. 选择您想要安装的 目标文件夹，并点击 下一步
    - 请牢记您的安装目录，如果可以，建议安装在您指定的目录下，而非默认位置
    - 如果您已经安装，软件的默认安装目录是 C:\Users{用户名}\AppData\Local\Programs\Microsoft VS Code，其中 AppData 文件夹是隐藏的
    - 如果您不知道要安装的目标文件夹是什么，问题不大，但最好请教他人，因为这是计算机的基础操作，但您也可以直接点击 下一步
4. 选择开始菜单文件夹
    - 建议直接点击 下一步
    - 如果您清楚您在干什么，可以勾选 不创建开始菜单文件夹，或者更改此项
5. 选择附加任务
    - 建议全部勾选后点击 下一步
    - 如果您清楚您在做什么，本页可以更改，但是强烈建议勾选 添加到PATH（重启后生效） 选项
6. 点击 安装 后等待一会即可安装成功
7. 安装后 VSCode 将自动打开，如果没有打开请通过 搜索/Windows菜单栏/桌面图标 找到并打开
#### Mac
1. 打开您下载的文件
    - 该文件名称为 VSCode-darwin-universal.zip，一般可以在 下载 文件夹中找到
2. 其中有一个文件，名称为 Visual Studio Code，请将其拖入 访达-应用程序 文件夹中
3. 稍等片刻，在您的 控制台 中应该已经出现 Visual Studio Code 程序，请打开

LaTeX 是一种基于 TeX 的排版系统，由美国计算机科学家莱斯利·兰伯特在 20 世纪 80 年代初期开发，利用这种格式系统的处理，即使用户没有排版和程序设计的知识也可以充分发挥由TEX所提供的强大功能，不必一一亲自去设计或校对，能在几天，甚至几小时内生成很多具有书籍质量的印刷品生成复杂表格和数学公式，这一点表现得尤为突出。因此它非常适用于生成高印刷质量的科技和数学、物理文档。这个系统同样适用于生成从简单的信件到完整书籍的所有其他种类的文档。（摘自 Wikipedia（https://zh.wikipedia.org/zh-cn/LaTeX））
