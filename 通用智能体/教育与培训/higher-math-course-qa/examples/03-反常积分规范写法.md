# 示例三：答案对、过程不成立

## 输入

> ∫₀¹ dx/√x = [2√x]₀¹ = 2，我直接用的牛顿-莱布尼茨公式，这样写对吗？

## 工具调用

```
check_integral(expr="1/sqrt(x)", a="0", b="1")
check_integral(expr="1/x", a="1", b="inf")
```

## 工具返回（节选）

```json
{
  "expr": "1/sqrt(x)",
  "interval": ["0", "1"],
  "verdict": "converged",
  "value": 2.0,
  "error_estimate": 4.44e-16,
  "method": "端点平方代换 + 自适应 Gauss–Legendre（16 点）",
  "confidence": "high",
  "summary": "∫ 在 [0, 1] 上约为 2，误差估计 4.44e-16"
}
```

```json
{
  "expr": "1/x",
  "interval": ["1", "inf"],
  "verdict": "unstable",
  "value": 24.09013832,
  "relative_error": 0.02877310714,
  "confidence": "low",
  "summary": "数值结果不稳定：常见原因是区间内有奇点，或该反常积分本身发散（如 p≤1 的 ∫₁^∞ x^-p）"
}
```

## 助手回复

数值是对的，**过程会被扣分**。

`1/√x` 在 x = 0 处无界，这属于**反常积分（瑕积分）**，不能直接套牛顿-莱布尼茨公式。规范写法是先取极限：

```
∫₀¹ x^(-1/2) dx = lim_{t→0⁺} ∫ₜ¹ x^(-1/2) dx = lim_{t→0⁺} (2 − 2√t) = 2
```

对应讲义条目：HM-05-04（反常积分的敛散性）、HM-05-02-E1（含奇点仍直接用公式）。

顺便记住这个对照，考试常考：

| 积分 | p | 结论 |
| --- | --- | --- |
| ∫₀¹ dx/x^p | p = 1/2 < 1 | 收敛（你这题） |
| ∫₁^∞ dx/x^p | p = 1 | 发散 |
| ∫₁^∞ dx/x² | p = 2 > 1 | 收敛（值为 1） |

第二行就是上面第二个工具调用想说明的事：`∫₁^∞ dx/x` 发散，但数值方法会给出 24.09 这样的数字——**这个数字没有意义**，工具已经把它标成 `unstable`。所以「数值算出来有结果」不等于「积分收敛」，判断敛散必须先看 p。

## 下一步

用定义判断 `∫₀² dx/(x − 1)²` 是否收敛。（提示：x = 1 是区间内部的瑕点，要拆成两段分别取极限。）

## 为什么这样处理

这类提问最容易被敷衍成「对，2 是对的」。但学生问的是「这样写对不对」，考的是过程规范性。工具在这里提供两点价值：

1. 确认数值 2 没错，避免误判为计算错误；
2. 通过第二个对照调用，把「数值有结果 ≠ 收敛」这个更深的观念带出来。

对发散积分给数值是数值方法固有的陷阱，工具用 `unstable` 和 `confidence: low` 明确标注，答疑时必须转述这个不确定性，不能只报 24.09。
