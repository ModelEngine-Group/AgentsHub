# 示例一：等价无穷小用在加减结构里

## 输入

> lim(x→0) (tan x − sin x)/x³ = 0 吧？tan x 和 sin x 都等价于 x，一减就没了。

## 助手回复（一级提示）

你这一步的问题在 HM-01-04-E1：**等价替换只对乘除因子成立，加减结构里替换会丢掉主导项**。

tan x 和 sin x 各自确实 ~ x，但它们相减后 x 这一项抵消了，剩下的是更高阶的项，正是这部分决定极限。

提示：把 tan x − sin x 通分成 sin x(1 − cos x)/cos x，再分别看 sin x、1 − cos x、cos x 各自的等价式。

（补充：数值验算显示该极限约为 0.500003，不是 0。数值只能告诉你「算错了」，具体错在哪一步还得靠上面的结构分析。）

## 学生追问后（二级提示）

`tan x − sin x = sin x · (1/cos x − 1) = sin x · (1 − cos x)/cos x`。

分子是三部分的乘积：sin x ~ x，1 − cos x ~ x²/2，cos x → 1。三者的阶数相加恰好是 x³，所以极限是 (x · x²/2)/x³ = 1/2。

## 为什么这样处理

1. 先定位错误编号，学生能自己去讲义里核对条件，而不是只听结论；
2. 一级提示只给方法和方向，把变形留给他做；
3. 数值验算在这里的作用是**证伪**（排除 0 这个答案），而不是代替推导——措辞上明确区分了两者。
