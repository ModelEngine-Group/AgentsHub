# 第六章 多元函数微分法及其应用（HM-06）

> 多元与一元最大的差别是「可导」被拆成了两个概念：偏导数存在、可微。
> 本章九成的概念题都在考这个区分。

## HM-06-01 偏导数与全微分

**偏导数**：z = f(x, y) 对 x 的偏导数，是把 y 视为常数后对 x 求导：

```
f_x(x₀, y₀) = lim_{Δx→0} [f(x₀ + Δx, y₀) − f(x₀, y₀)] / Δx
```

**全微分**：若 Δz = AΔx + BΔy + o(ρ)，其中 ρ = √(Δx² + Δy²)，则称 f 在該点可微，dz = A dx + B dy，且此时 A = f_x，B = f_y。

**三者的强弱关系（必须记清）**

```
偏导数连续 ⇒ 可微 ⇒ 连续
                    ⇒ 偏导数存在
```

反向都不成立。经典反例：

- f(x, y) = √(x² + y²) 在原点连续但偏导数不存在；
- f(x, y) = xy/(x² + y²)（原点补 0）偏导数存在但不连续；
- 偏导存在且连续之外的情形不能用「偏导存在」推出可微。

**判定可微的标准流程**：先算 f_x、f_y（分界点用定义），再验证

```
lim_{(Δx,Δy)→(0,0)} [Δz − f_x Δx − f_y Δy] / ρ = 0
```

**易错点**

- HM-06-01-E1 由「偏导数存在」推出「连续」。这是本章最高频的概念错误。
- HM-06-01-E2 由「偏导数存在」推出「可微」。
- HM-06-01-E3 求分界点处的偏导数时直接用求导公式，而没有回到定义。
- HM-06-01-E4 认为 f_xy = f_yx 恒成立。相等需要二阶混合偏导数连续这一条件。

## HM-06-02 多元复合函数与隐函数求导

**链式法则**：z = f(u, v)，u = u(x, y)，v = v(x, y)，则

```
∂z/∂x = f_u·u_x + f_v·v_x
∂z/∂y = f_u·u_y + f_v·v_y
```

画清变量树是避免漏项的唯一可靠办法：从 z 出发有几条路径通向 x，就有几项相加。

**隐函数求导**：F(x, y, z) = 0 确定 z = z(x, y)，且 F_z ≠ 0，则

```
∂z/∂x = −F_x / F_z        ∂z/∂y = −F_y / F_z
```

注意负号，且分母是「对隐函数本身那个变量」的偏导。

**易错点**

- HM-06-02-E1 链式法则漏项，只写了一条路径。
- HM-06-02-E2 隐函数求导漏掉负号。
- HM-06-02-E3 求 ∂z/∂x 时把 y 也当成 x 的函数（在没有额外约束时 y 与 x 独立）。
- HM-06-02-E4 二阶偏导的链式法则再做一次时，忘记 f_u 本身仍是 u、v 的函数，需要继续展开。

## HM-06-03 方向导数与梯度

**方向导数**：f 在点 P 沿单位向量 l = (cos α, cos β) 的方向导数

```
∂f/∂l = f_x cos α + f_y cos β = grad f · l
```

**梯度**：grad f = (f_x, f_y)。梯度的方向是函数值增长最快的方向，梯度的模是最大方向导数的值；负梯度方向是下降最快的方向。

**前提**：方向导数的计算公式要求 f 在该点可微。仅偏导存在时公式可能不成立。

**易错点**

- HM-06-03-E1 用非单位向量代入方向导数公式，忘记先归一化。
- HM-06-03-E2 把梯度当成方向导数。梯度是向量，方向导数是数。
- HM-06-03-E3 在不可微点套用 grad f · l 的公式。

## HM-06-04 多元函数的极值与条件极值

**无条件极值**

必要条件：可微点取极值则 f_x = f_y = 0（驻点）。

充分条件：设 A = f_xx，B = f_xy，C = f_yy，判别式 Δ = AC − B²。

| 判别式 | 结论 |
| --- | --- |
| Δ > 0，A > 0 | 极小值 |
| Δ > 0，A < 0 | 极大值 |
| Δ < 0 | 不是极值（鞍点） |
| Δ = 0 | 判据失效，需用定义或其他方法 |

**条件极值（拉格朗日乘数法）**：求 f(x, y) 在约束 g(x, y) = 0 下的极值，构造

```
L(x, y, λ) = f(x, y) + λ g(x, y)
```

解方程组 L_x = 0，L_y = 0，L_z（即 g = 0），得到候选点，再比较函数值。

**闭区域上的最值**：内部驻点 + 边界上的最值（边界通常化为一元问题或用乘数法），逐一比较。

**易错点**

- HM-06-04-E1 求出驻点就宣布是极值，没有用判别式。
- HM-06-04-E2 在 Δ = 0 时仍下结论。
- HM-06-04-E3 条件极值忘记把约束方程一起解，只解了 L_x = L_y = 0。
- HM-06-04-E4 求闭区域最值时只算内部驻点，漏掉边界。
- HM-06-04-E5 应用题中设了目标函数却漏设约束条件（如体积固定、表面积最小）。
