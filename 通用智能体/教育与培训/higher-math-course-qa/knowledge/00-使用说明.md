# 使用说明与知识库索引

## 这份知识库是什么

面向大学「高等数学」课程的答疑语料，按同济《高等数学》第七版大纲组织，覆盖上册（函数极限、导数、中值定理、不定积分、定积分）与下册核心章节（多元微分、重积分、级数）。

**内容为原创整理**，用于讲解概念、归纳方法、记录易错点，不摘录任何教材原文、例题或习题编号。若学生需要对照教材页码，应自行查阅纸质教材。

## 引用编号规则

- `HM-01` ~ `HM-07`：章
- `HM-01-04`：章-知识点序号（与 `agent.json` 中的知识点索引一致）
- `HM-01-04-E2`：该知识点下的第 2 条易错点

答疑时引用编号，学生可以直接定位到具体条目，避免「老师说的那条我找不到」。

## 检索建议

检索效果最好的是「知识点名词 + 题目关键特征」，例如：

- 「等价无穷小 加减替换」
- 「洛必达 条件 不适用」
- 「反常积分 p 积分 收敛」
- 「极坐标 漏 r」

只输入题号或「这道题怎么做」通常检索不到合适条目。若检索为空，改用知识点名称重试。

## 与工具的分工

| 内容 | 由谁负责 |
| --- | --- |
| 概念、定理条件、方法步骤、易错点 | 本知识库 |
| 具体数值的极限、导数、积分、表达式等价性 | MCP 工具（check_limit / check_derivative / check_integral / compare_expressions） |
| 答疑的流程、提示分级、话术 | Skill（calculus-tutoring-playbook） |

三者各司其职：知识库管「讲什么」，工具管「算得对不对」，Skill 管「怎么讲」。
