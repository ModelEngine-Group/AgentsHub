# 第五章 定积分及其应用（HM-05）

> 定积分是「数」，不定积分是「函数族」，这个区别决定了本章一半的错误来源。
> 另一个高频坑是：对含奇点的被积函数直接用牛顿-莱布尼茨公式。

## HM-05-01 定积分的定义与性质

**定义**：分割、取点、求和、取极限。若黎曼和的极限存在且与分割方式、取点方式无关，称 f 在 [a, b] 上可积，该极限记为 ∫ₐᵇ f(x)dx。

**可积的充分条件**：闭区间上连续；或有界且只有有限个间断点；或单调有界。

**基本性质**

1. 线性：∫(αf + βg) = α∫f + β∫g；
2. 区间可加：∫ₐᵇ = ∫ₐᶜ + ∫꜀ᵇ（c 可在区间内外，只要各段有意义）；
3. 保号性：f ≥ 0 则 ∫ₐᵇ f ≥ 0（a < b）；
4. 估值：m(b − a) ≤ ∫ₐᵇ f ≤ M(b − a)；
5. 积分中值定理：f 在 [a, b] 上连续，则存在 ξ ∈ [a, b] 使 ∫ₐᵇ f = f(ξ)(b − a)。

**易错点**

- HM-05-01-E1 把定积分当成函数。定积分的结果是一个确定的数（在上下限固定时）。
- HM-05-01-E2 认为无界函数一定不可积。无界函数可以定义反常积分，只是不再是黎曼意义下的可积。
- HM-05-01-E3 交换上下限时忘记变号：∫ₐᵇ = −∫ᵦᵃ。

## HM-05-02 牛顿-莱布尼茨公式与变限积分

**公式**：若 f 在 [a, b] 上连续，F 是 f 的一个原函数，则

```
∫ₐᵇ f(x)dx = F(b) − F(a)
```

**使用前提**：f 在 [a, b] 上连续（至少要在区间上存在原函数）。若区间内部有第二类间断点（如 1/x² 在 [−1, 1] 上跨过 0），必须先分区间判断是否为反常积分，不能直接代公式。

**变限积分**：Φ(x) = ∫ₐˣ f(t)dt。若 f 连续，则 Φ′(x) = f(x)。

**复合上下限的求导**

```
d/dx ∫_{φ(x)}^{ψ(x)} f(t)dt = f(ψ(x))ψ′(x) − f(φ(x))φ′(x)
```

**易错点**

- HM-05-02-E1 被积函数在区间内有奇点仍直接套牛顿-莱布尼茨公式。典型错误：∫₋₁¹ dx/x² = [−1/x]₋₁¹ = −2，实际该积分发散。
- HM-05-02-E2 变限积分求导时漏掉链式因子 ψ′(x) 或 φ′(x)。
- HM-05-02-E3 把 ∫ₐˣ f(t)dt 写成 ∫ₐˣ f(x)dx，混淆积分变量与上限。
- HM-05-02-E4 求导时把被积函数里的 x 当常数（被积函数含 x 时需先提出或换元）。

## HM-05-03 对称性与奇偶性简化

**对称区间**：∫₋ₐᵃ f(x)dx —— f 为奇函数时为 0；f 为偶函数时为 2∫₀ᵃ f(x)dx。

**周期性**：f 以 T 为周期，则任意长度为 T 的区间上积分相等：∫ₐ^{a+T} f = ∫₀^T f。

**区间再现公式**：∫₀ᵃ f(x)dx = ∫₀ᵃ f(a − x)dx。常用于被积函数含 sin x 与 cos x 对称结构的情形。

**易错点**

- HM-05-03-E1 区间不对称却使用奇偶性结论。
- HM-05-03-E2 周期函数在非整周期区间上套用「一个周期积分相等」。
- HM-05-03-E3 用了区间再现公式但没有把积分限一起换。

## HM-05-04 反常积分的敛散性

**两类反常积分**：无穷区间（∫ₐ^∞）；无界函数的瑕积分（被积函数在端点或内部趋于无穷）。

**定义**：取极限，极限存在则收敛，否则发散。

**p 积分的结论（必须记住）**

```
∫₁^∞ dx/x^p ：p > 1 收敛，p ≤ 1 发散
∫₀¹ dx/x^p ：p < 1 收敛，p ≥ 1 发散
```

两组条件方向相反，这是最容易记混的地方：无穷区间要求「衰减够快」（p 大），瑕点要求「增长够慢」（p 小）。

**判别法**：比较判别法（与已知敛散的积分比较）、极限比较法（lim f/g = c，0 < c < ∞ 时同敛散）。

**易错点**

- HM-05-04-E1 对发散的反常积分算出一个有限数。例如把 ∫₁^∞ dx/x 算成 ln(∞) − 0 后随手写成 0 或某个数。
- HM-05-04-E2 混淆两类 p 积分的条件方向。
- HM-05-04-E3 只检查端点，漏掉区间内部的无界点（如 ∫₀² dx/(x−1)² 在 x = 1 处有瑕点，必须拆成两段）。

## HM-05-05 定积分的应用

**面积**：由 y = f(x)、y = g(x) 与 x = a、x = b 围成的区域，面积为 ∫ₐᵇ |f(x) − g(x)|dx。求交点定上下限，分段时逐段积分再相加。

**旋转体体积**

| 情形 | 公式 |
| --- | --- |
| 绕 x 轴旋转（圆盘法） | V = π∫ₐᵇ f²(x)dx |
| 绕 y 轴旋转（柱壳法） | V = 2π∫ₐᵇ x·f(x)dx |
| 两曲线之间绕 x 轴 | V = π∫ₐᵇ [f² − g²]dx |

**弧长**：y = f(x) 时 s = ∫ₐᵇ √(1 + f′²(x))dx；参数方程 x = φ(t)、y = ψ(t) 时 s = ∫ √(φ′² + ψ′²)dt。

**物理应用**：变力做功 W = ∫F(x)dx；水压力、形心坐标、函数平均值 f̄ = (1/(b−a))∫ₐᵇ f。

**易错点**

- HM-05-05-E1 求面积不加绝对值，导致 x 轴下方的部分抵消掉。
- HM-05-05-E2 两曲线围成的面积不先求交点，上下限凭感觉取。
- HM-05-05-E3 弧长公式漏掉根号里的 1，写成 ∫√(f′²)dx。
- HM-05-05-E4 绕 y 轴旋转用圆盘法公式，混淆了旋转轴。
