# 第四章 不定积分（HM-04）

> 不定积分的失分点高度集中：漏积分常数、换元忘记回代、部分分式设错形式。
> 本章尽量把「怎么选方法」做成可执行的判据，而不是罗列公式。

## HM-04-01 原函数与不定积分概念

**原函数**：若 F′(x) = f(x)，称 F 为 f 的一个原函数。f 的全体原函数为 F(x) + C，记作 ∫f(x)dx。

**存在性**：区间上连续的函数一定有原函数；含第一类间断点的函数在含该点的区间上不存在原函数（因为导数具有介值性）。但「有原函数」不等于「原函数是初等函数」——e^{−x²}、sin x / x、1/ln x 都没有初等原函数，遇到它们只能表示为特殊函数或定积分形式。

**基本积分表（与导数表互为逆运算）**

```
∫x^a dx = x^{a+1}/(a+1) + C  (a ≠ −1)      ∫dx/x = ln|x| + C
∫e^x dx = e^x + C            ∫a^x dx = a^x/ln a + C
∫sin x dx = −cos x + C       ∫cos x dx = sin x + C
∫sec²x dx = tan x + C        ∫dx/(1+x²) = arctan x + C
∫dx/√(1−x²) = arcsin x + C   ∫tan x dx = −ln|cos x| + C
```

**易错点**

- HM-04-01-E1 漏写积分常数 C。不定积分的结果是一个函数族，不是单个函数。
- HM-04-01-E2 认为所有连续函数都能积出初等表达式。
- HM-04-01-E3 ∫dx/x 写成 ln x + C，漏绝对值。正确是 ln|x| + C。

## HM-04-02 换元积分法

**第一类换元（凑微分）**：若被积式能写成 ∫f(φ(x))·φ′(x)dx，令 u = φ(x)，则化为 ∫f(u)du。特征是被积函数里「藏着一个导数」。

常见凑法：x dx = d(x²)/2；dx/x = d(ln|x|)；e^x dx = d(e^x)；dx/√x = 2d(√x)。

**第二类换元**：令 x = ψ(t)，dx = ψ′(t)dt，积分后再把 t 回代为 x 的函数。必须回代，除非题目要求定积分（定积分换元要同步换上下限）。

**三角代换的选择**

| 被积式含 | 代换 | 依据 |
| --- | --- | --- |
| √(a² − x²) | x = a sin t | 1 − sin²t = cos²t |
| √(a² + x²) | x = a tan t | 1 + tan²t = sec²t |
| √(x² − a²) | x = a sec t | sec²t − 1 = tan²t |

代换后要写清 t 的取值范围（一般取主值区间），否则回代时反三角函数会出分支问题。

**根式代换**：含 ⁿ√(ax + b) 时令 t = ⁿ√(ax + b)，可一次性去掉根号。

**易错点**

- HM-04-02-E1 第二类换元后忘记把 t 回代为 x，答案里留着 t。
- HM-04-02-E2 换元时忘记替换 dx（漏乘 ψ′(t)）。
- HM-04-02-E3 三角代换后回代出错，特别是 sin t = x/a 时 cos t 的符号取错（要根据 t 的范围定）。
- HM-04-02-E4 定积分换元后仍用原来的上下限。

## HM-04-03 分部积分法

**公式**：∫u dv = uv − ∫v du，即 ∫u v′ dx = uv − ∫u′ v dx。

**u 的选取顺序**：反三角 → 对数 → 幂函数 → 三角 → 指数（口诀「反对幂指三」，排在前面的优先作 u）。选 u 的原则是「求导后变简单」，选 dv 的原则是「容易积出来」。

**循环积分**：∫e^x sin x dx 这类会回到自身，移项求解，注意移项时的符号与系数。

**递推**：∫sin^n x dx、∫(ln x)^n dx 等通过分部积分建立递推关系 I_n = f(I_{n−1})，再用 I_0 或 I_1 逐步回推。

**易错点**

- HM-04-03-E1 u 与 dv 选反，导致 ∫v du 比原积分更难。
- HM-04-03-E2 循环积分移项时符号出错（移过去应变为 I = (…)/2 而不是 I = …×2）。
- HM-04-03-E3 建立递推式后忘记给出初始值 I_0，导致递推无法落地。

## HM-04-04 有理函数积分

**标准流程**

1. 判断真假分式：分子次数 ≥ 分母次数时先做多项式除法，分离出多项式部分；
2. 分母分解为一次因式与不可约二次因式的乘积；
3. 按因式类型设部分分式：
   - (x − a)^k → A₁/(x − a) + A₂/(x − a)² + … + A_k/(x − a)^k
   - (x² + px + q)^k（p² − 4q < 0）→ (B₁x + C₁)/(x² + px + q) + … 
4. 通分比较系数或用赋值法求待定系数；
5. 逐项积分：一次因式给对数，二次因式配方后给对数 + 反正切。

**易错点**

- HM-04-04-E1 假分式不做除法直接设部分分式。
- HM-04-04-E2 二次不可约因式对应的分子写成常数而不是一次式 Bx + C。
- HM-04-04-E3 重根情形只设一项，漏掉低次幂项。
- HM-04-04-E4 待定系数求出后忘记乘回分解时的常数因子。

## HM-04-05 三角有理式与简单根式

**万能代换**：令 t = tan(x/2)，则

```
sin x = 2t/(1 + t²)      cos x = (1 − t²)/(1 + t²)      dx = 2dt/(1 + t²)
```

万能代换一定能把三角有理式化为有理函数，但计算量通常很大，属于「保底手段」而非首选。

**优先尝试的对称技巧**

| 被积式的对称性 | 代换 |
| --- | --- |
| R(−sin x, cos x) = −R(sin x, cos x) | t = cos x |
| R(sin x, −cos x) = −R(sin x, cos x) | t = sin x |
| R(−sin x, −cos x) = R(sin x, cos x) | t = tan x |

**其他常见处理**：∫sin mx cos nx dx 用积化和差；∫dx/(a sin x + b cos x) 用辅助角公式；含 √(a² − x²) 用三角代换。

**易错点**

- HM-04-05-E1 一上来就用万能代换，把一个能用 t = cos x 两步解决的积分做成十几项的有理分式。
- HM-04-05-E2 万能代换后忘记替换 dx。
- HM-04-05-E3 用积化和差时系数漏乘 1/2。
