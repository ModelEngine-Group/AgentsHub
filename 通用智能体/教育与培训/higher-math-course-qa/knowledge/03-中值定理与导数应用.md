# 第三章 微分中值定理与导数的应用（HM-03）

> 本章是证明题的主战场。中值定理类题目失分八成不是不会定理，而是没验证条件、或辅助函数构造错位。

## HM-03-01 三大中值定理

**罗尔定理**：f 在 [a, b] 上连续，在 (a, b) 内可导，且 f(a) = f(b)，则存在 ξ ∈ (a, b) 使 f′(ξ) = 0。

**拉格朗日中值定理**：f 在 [a, b] 上连续，在 (a, b) 内可导，则存在 ξ ∈ (a, b) 使

```
f(b) − f(a) = f′(ξ)(b − a)
```

**柯西中值定理**：f、g 在 [a, b] 上连续，在 (a, b) 内可导，且 g′(x) ≠ 0，则存在 ξ ∈ (a, b) 使

```
[f(b) − f(a)] / [g(b) − g(a)] = f′(ξ) / g′(ξ)
```

**条件必须逐条核对**：闭区间连续、开区间可导、罗尔额外要求端点值相等、柯西额外要求 g′ ≠ 0。少一条结论就不成立（例如 f(x) = |x| 在 [−1, 1] 上不满足开区间可导，罗尔定理结论仍成立但这属于巧合，不能作为通用推理）。

**辅助函数构造（证明题的胜负手）**

| 要证的式子 | 构造的辅助函数 |
| --- | --- |
| ξf′(ξ) + f(ξ) = 0 | F(x) = x f(x) |
| f′(ξ) − λ f(ξ) = 0 | F(x) = e^{−λx} f(x) |
| f′(ξ) + g′(ξ) f(ξ) = 0 | F(x) = e^{g(x)} f(x) |
| f(b) − f(a) = ξ f′(ξ) ln(b/a) | 对 f 与 ln x 用柯西定理 |

**易错点**

- HM-03-01-E1 直接用定理却未验证「闭区间连续、开区间可导」。
- HM-03-01-E2 用罗尔定理时忘记验证 f(a) = f(b)，或自己造了一个端点相等的函数却没说明。
- HM-03-01-E3 把 ξ 写在闭区间 [a, b] 上。定理只保证 ξ 在开区间 (a, b) 内。
- HM-03-01-E4 辅助函数构造对了但求导算错，导致 F′(ξ) = 0 推不出目标式。

## HM-03-02 洛必达法则

**适用类型**：仅限 0/0 与 ∞/∞ 两种未定式。

**三个条件**：分子分母在去心邻域内可导且分母导数不为零；求导后的比值的极限存在或为无穷（含 ±∞）。第三条常被忽略。

**其他未定式的转化**

| 类型 | 转化方式 |
| --- | --- |
| 0·∞ | 化为 0/(1/∞) 或 ∞/(1/0)，选求导更简单的那个 |
| ∞ − ∞ | 通分，或提取主部 |
| 1^∞、0⁰、∞⁰ | 取对数化为 0·∞，或用 e^{lim v(u−1)} |

**易错点**

- HM-03-02-E1 对非未定式使用洛必达。例如 lim (x + sin x)/x 在 x → 0 时是 0/0 可以用；但 lim (2 + sin x)/x 在 x → ∞ 时不是未定式，直接得 0。
- HM-03-02-E2 用了洛必达后发现 lim f′/g′ 不存在，就断言原极限不存在。反例：lim_{x→∞} (x + sin x)/x = 1，但求导后的 (1 + cos x)/1 极限不存在。此时应改用夹逼或其他方法。
- HM-03-02-E3 连续多次使用洛必达却不检查每一次是否仍是未定式。

## HM-03-03 泰勒公式

**带佩亚诺余项**（用于求极限）：

```
f(x) = Σ_{k=0}^{n} f^(k)(x₀)/k! · (x − x₀)^k + o((x − x₀)^n)
```

**带拉格朗日余项**（用于估计误差、证明不等式）：

```
f(x) = Σ_{k=0}^{n} f^(k)(x₀)/k! · (x − x₀)^k + f^(n+1)(ξ)/(n+1)! · (x − x₀)^{n+1}
```

**常用麦克劳林展开（x → 0）**

```
e^x = 1 + x + x²/2! + x³/3! + o(x³)
sin x = x − x³/3! + x⁵/5! + o(x⁵)
cos x = 1 − x²/2! + x⁴/4! + o(x⁴)
ln(1 + x) = x − x²/2 + x³/3 + o(x³)
(1 + x)^a = 1 + ax + a(a−1)x²/2! + o(x²)
1/(1 − x) = 1 + x + x² + … + x^n + o(x^n)
```

**展开阶数的确定方法**：先看分母的阶数，分子至少展开到同阶；若最高阶项抵消，继续展开一阶，直到出现非零主部。

**易错点**

- HM-03-03-E1 展开阶数不足，分子各项抵消后得到 0，误判极限为 0。典型：(sin x − x)/x³，若只展开到 x 就出错。
- HM-03-03-E2 分子分母展开到不同阶，导致比较失真。
- HM-03-03-E3 求极限用拉格朗日余项（不知道 ξ 的具体位置无法处理），或证明不等式用佩亚诺余项（只知道是 o 无法给出定量界）。

## HM-03-04 单调性与极值

**单调性判据**：在区间 I 上 f′(x) > 0 则严格递增；f′(x) < 0 则严格递减。个别点导数为 0 不影响单调性（如 x³ 在 0 处）。

**极值的必要条件**：可导点取极值则 f′(x₀) = 0（费马引理）。

**极值可疑点**：驻点（f′ = 0）与不可导点（如 |x| 的 0 点）都要检查。

**第一充分条件**：f′ 在 x₀ 左右变号——由正变负为极大，由负变正为极小，不变号则不是极值。

**第二充分条件**：f′(x₀) = 0 且 f″(x₀) < 0 为极大；f″(x₀) > 0 为极小；f″(x₀) = 0 时此判据失效，须退回第一充分条件。

**易错点**

- HM-03-04-E1 认为 f′(x₀) = 0 就是极值点。反例：x³ 在 0 处导数为 0 但单调。
- HM-03-04-E2 只检查驻点，漏掉不可导点。反例：|x| 在 0 处取极小但不可导。
- HM-03-04-E3 在 f″(x₀) = 0 时仍用第二充分条件下结论。

## HM-03-05 凹凸性、拐点与渐近线

**凹凸判据**：f″(x) > 0 时曲线为凹（开口向上，位于切线上方）；f″(x) < 0 时为凸（开口向下）。

**拐点**：连续曲线凹凸性发生改变的点。判定需要两个条件同时满足：该点为 f″ = 0 或 f″ 不存在的点，且 f″ 在该点两侧变号。

**渐近线**

| 类型 | 判据 |
| --- | --- |
| 垂直 | lim_{x→a} f(x) = ∞（a 通常是使分母为 0 的点） |
| 水平 | lim_{x→±∞} f(x) = b |
| 斜 | k = lim_{x→∞} f(x)/x ≠ 0 且有限，b = lim_{x→∞} [f(x) − kx]，直线 y = kx + b |

**易错点**

- HM-03-05-E1 由 f″(x₀) = 0 直接断定是拐点。反例：y = x⁴ 在 0 处 f″ = 0 但两侧均为凹，不是拐点。
- HM-03-05-E2 求斜渐近线只算出 k 没算 b，或反过来。
- HM-03-05-E3 画图时只找水平渐近线，漏掉垂直渐近线（如 1/(x − 1) 在 x = 1 处）。

## HM-03-06 最值与不等式证明

**闭区间最值的完整步骤**：求 f′ → 找出所有驻点与不可导点 → 计算这些点以及两个端点的函数值 → 比较取最大最小。端点最易被漏。

**不等式证明的四条路径**

1. 单调性法：移项构造 F(x)，证 F′ 的符号，再由端点值得出结论；
2. 最值法：证 F 的最小值 ≥ 0（或最大值 ≤ 0）；
3. 拉格朗日中值定理：把 f(b) − f(a) 写成 f′(ξ)(b − a)，再对 f′(ξ) 放缩；
4. 泰勒公式：在合适点展开，用余项符号判断。

**易错点**

- HM-03-06-E1 求闭区间最值只比较驻点，漏掉端点。
- HM-03-06-E2 构造了 F(x) 但没说明单调区间，直接由 F′ > 0 推出全局结论。
- HM-03-06-E3 用中值定理证不等式时，对 f′(ξ) 的放缩方向弄反（ξ 的范围决定放缩方向）。
