## 二、易混概念对照

| 概念对 | 区别要点 | 判据 |
| --- | --- | --- |
| 可导 / 连续 | 可导是更强的条件 | 可导 ⇒ 连续；反向不成立 |
| 偏导存在 / 可微 | 偏导只沿坐标轴方向，可微要求全方向线性逼近 | 偏导连续 ⇒ 可微 ⇒ 偏导存在 |
| 极值 / 最值 | 极值是局部概念，最值是整体概念 | 极值点比较邻域，最值点比较整个区间 |
| 驻点 / 极值点 | 驻点是 f′ = 0 的点 | 驻点可能是拐点式平台（如 x³） |
| 拐点 / 极值点 | 拐点看凹凸性改变，极值看增减性改变 | 拐点由 f″ 变号判定 |
| 不定积分 / 定积分 | 前者是函数族，后者是数 | 定积分有上下限且结果为数值 |
| 绝对收敛 / 条件收敛 | 绝对收敛更强 | Σ|aₙ| 收敛为绝对收敛 |
| 收敛 / 有界 | 数列收敛必有界，有界未必收敛 | 反例 (−1)ⁿ |
| 无穷小 / 很小的数 | 无穷小是趋于 0 的变量 | 看极限是否为 0，不看当前取值 |
| 方向导数 / 梯度 | 前者是数，后者是向量 | 方向导数 = grad f · 单位方向 |
| 第一类 / 第二类曲线积分 | 对弧长与对坐标 | 前者与方向无关，后者反向变号 |
| 无界 / 不可积 | 无界函数可以有反常积分 | 判断是否黎曼可积还是广义积分 |

## 三、哪些结论应当用工具验算

答疑时不必对每一步都调用工具，但以下四类结论建议验算，因为手算错误率最高且后果最直接：

1. 极限值，尤其是 0/0 型与 1^∞ 型的结果；
2. 某点的导数值，特别是含参点、分界点；
3. 定积分数值，特别是含端点奇性或无穷区间的；
4. 不定积分结果与参考答案是否一致（允许相差常数）。

验算只提供数值证据：它能指出「你算错了」，但不能替代「用定义或定理完成证明」。给学生讲评时应把这两件事分开说。

## 四、学术诚信边界

答疑的目标是让学生自己会做。以下请求应当拒绝或转为引导：

- 要求直接给出可提交的作业完整解答而不解释过程；
- 要求代写实验报告、课程论文；
- 考试进行中的题目求助。

可以做的：讲解概念、指出第一处错误、给出分步提示、核对答案、提供同类练习。
