# 第一章 函数、极限与连续（HM-01）

> 本章覆盖答疑中出现频率最高的三类问题：定义域与函数性质、极限是否存在与如何求、连续与间断点判定。
> 章节顺序按同济《高等数学》第七版上册大纲编排，讲义内容为原创整理，不摘录教材原文。

## HM-01-01 函数性质与定义域

**定义域的四条硬约束**

| 形式 | 约束 |
| --- | --- |
| 分式 1/g(x) | g(x) ≠ 0 |
| 偶次根式 √g(x) | g(x) ≥ 0 |
| 对数 ln g(x) | g(x) > 0 |
| 反三角 arcsin g(x)、arccos g(x) | −1 ≤ g(x) ≤ 1 |

补充：tan x 要求 x ≠ π/2 + kπ；cot x 要求 x ≠ kπ。

**复合函数的定义域**：u = g(x) 的值域必须落进 f(u) 的定义域，两个条件同时成立才算数。求 f(g(x)) 的定义域时，先把 g 的允许范围解出来，再把 g(x) 代入 f 的约束里解不等式，最后取交集。

**奇偶性**：先检查定义域是否关于原点对称，再看 f(−x) 与 f(x) 的关系。即使 f(−x) = f(x) 恒成立，只要定义域不对称（如 [−1, 2]），也不能称偶函数。

**有界性**：存在 M > 0 使 |f(x)| ≤ M 对所有 x ∈ D 成立。注意「有界」是整体性质，单点附近有界不代表在整个定义域有界。

**易错点**

- HM-01-01-E1 求复合函数定义域时只看外层，漏掉内层自身的约束（典型：ln(1/x) 既要 1/x > 0 又要 x ≠ 0）。
- HM-01-01-E2 判断奇偶性不先看定义域对称性。
- HM-01-01-E3 认为 y = x² 存在反函数。反函数存在要求函数在区间上严格单调，y = x² 在 R 上不单调，只在 x ≥ 0 或 x ≤ 0 上分别可逆。

**自检**：y = arcsin(x − 1) + ln(4 − x) 的定义域为？（答：[0, 3]）

## HM-01-02 数列极限与收敛准则

**定义（ε-N）**：对任意 ε > 0，存在正整数 N，当 n > N 时恒有 |aₙ − A| < ε，则称 {aₙ} 收敛于 A。写证明时必须体现「对任意 ε」与「存在 N」这两个量词的先后顺序。

**常用结论**

1. 收敛数列必有界，但有界数列未必收敛（如 (−1)ⁿ）。
2. 收敛数列的任一子列收敛于同一极限；若两个子列极限不同，则原数列发散。
3. 单调有界准则：单调递增且有上界（或单调递减且有下界）的数列必收敛。
4. 夹逼准则：若 bₙ ≤ aₙ ≤ cₙ 且 bₙ、cₙ 同趋于 A，则 aₙ 也趋于 A。
5. 重要极限的数列形式：lim (1 + 1/n)ⁿ = e。

**易错点**

- HM-01-02-E1 用「n 越来越大，1/n 越来越小，所以极限是 0」代替 ε-N 证明。这在计算题里可以，证明题里不算完成。
- HM-01-02-E2 把「有界」当作「收敛」的充分条件。
- HM-01-02-E3 用夹逼准则时只验证了一侧不等式。

## HM-01-03 函数极限与左右极限

**定义要点**：x → x₀ 的极限只与 x₀ 的去心邻域有关，与 f(x₀) 是否有定义、取什么值无关。这一点是理解「可去间断点」的关键。

**极限存在的充要条件**：lim_{x→x₀} f(x) 存在 ⟺ 左极限 f(x₀⁻) 与右极限 f(x₀⁺) 都存在且相等。

**x → ∞ 的极限**：指的是 |x| 无限增大，同样要求 x → +∞ 与 x → −∞ 两个方向的极限都存在且相等。

**求极限的基本顺序**

1. 先代入：能直接代入且不出现未定式，就是答案。
2. 出现 0/0 或 ∞/∞：先化简（约分、有理化、通分），再考虑等价无穷小、洛必达或泰勒。
3. 出现 ∞ − ∞：通分或提取主部。
4. 出现 1^∞、0⁰、∞⁰：取对数或用 e^{lim (f−1)g}。

**易错点**

- HM-01-03-E1 在分段点只算了一侧的极限就下结论。
- HM-01-03-E2 把「代入后分母为 0」直接判为「极限不存在」。0/0 型可能极限存在，需要化简。
- HM-01-03-E3 求 x → ∞ 的极限时只用 x → +∞ 的样本。

## HM-01-04 无穷小与等价无穷小替换

**无穷小**：若 lim α(x) = 0，称 α 为无穷小。无穷小是变量，不是「很小的数」。

**阶的比较**：设 α、β 均为无穷小且 β ≠ 0，若 lim α/β = 0，称 α 是 β 的高阶无穷小，记 α = o(β)；若极限为非零常数 c，称同阶；若 c = 1，称等价，记 α ~ β。

**x → 0 时的常用等价**

```
sin x ~ x        tan x ~ x        arcsin x ~ x      arctan x ~ x
1 − cos x ~ x²/2      ln(1 + x) ~ x      e^x − 1 ~ x
(1 + x)^a − 1 ~ ax    a^x − 1 ~ x ln a
```

**使用边界（本章最容易出错的地方）**

- 等价替换成立的前提是「被替换的对象整体是一个乘除因子」。
- 在加减法中直接替换会丢失低阶项，除非先把同阶项合并抵消，再对剩余部分替换。
- 判定阶数不够时，用泰勒展开到足够阶，而不是硬套等价式。

**易错点**

- HM-01-04-E1 计算 lim (sin x − x)/x³ 时把 sin x 替换成 x 得 0，正确答案是 −1/6。原因是分子是加减结构，替换丢掉了 −x³/6 这一项。
- HM-01-04-E2 认为「等价」就是「相等」，在等式推导中把 ~ 当 = 用。
- HM-01-04-E3 在 x → ∞ 时套用 x → 0 的等价式（如把 sin(1/x) 直接写成 1/x 而不说明 1/x → 0）。

## HM-01-05 两个重要极限

**第一重要极限**：lim_{x→0} sin x / x = 1。推论：lim_{x→0} tan x / x = 1，lim_{x→0} arcsin x / x = 1，lim_{x→0} (1 − cos x)/x² = 1/2。

**第二重要极限**：lim_{x→∞} (1 + 1/x)^x = e；等价形式 lim_{x→0} (1 + x)^{1/x} = e。

**1^∞ 型的标准处理**：若 lim u(x) = 1，lim v(x) = ∞，则

```
lim u^v = e^{lim v·(u − 1)}
```

其中 u − 1 通常可以用等价无穷小替换（因为此时 u − 1 → 0，且为乘除结构）。

**易错点**

- HM-01-05-E1 在 x → ∞ 时使用 lim sin x / x = 1（此时极限实际为 0）。
- HM-01-05-E2 遇到 1^∞ 直接写 1，没有意识到这是未定式。
- HM-01-05-E3 用 e^{lim v(u−1)} 时，v(u−1) 的极限不存在却仍套公式。

## HM-01-06 连续性与间断点分类

**连续的三个条件**（缺一不可）：f(x₀) 有定义；lim_{x→x₀} f(x) 存在；二者相等。

**间断点分类**

| 类型 | 判据 | 例子 |
| --- | --- | --- |
| 第一类·可去 | 左右极限存在且相等，但不等于函数值或无定义 | sin x / x 在 0 处 |
| 第一类·跳跃 | 左右极限都存在但不相等 | 符号函数在 0 处 |
| 第二类·无穷 | 至少一侧极限为无穷 | 1/x 在 0 处 |
| 第二类·振荡 | 至少一侧极限不存在且不趋于无穷 | sin(1/x) 在 0 处 |

**分段函数在分界点连续性的判定步骤**：算左极限 → 算右极限 → 取函数值 → 三者比较。

**易错点**

- HM-01-06-E1 只算左右极限相等就判连续，忘了还要等于函数值。
- HM-01-06-E2 把「无定义」一律当成可去间断点。可去间断还要求极限存在，如 1/x 在 0 处是无穷间断。
- HM-01-06-E3 求分段函数中的待定参数时，只在一个分界点列方程。

## HM-01-07 闭区间上连续函数的性质

**四个定理（条件都是「闭区间 + 连续」）**

1. 有界性与最值定理：f 在 [a, b] 上连续，则 f 有界且能取到最大值与最小值。
2. 介值定理：f 在 [a, b] 上连续，μ 介于 f(a) 与 f(b) 之间，则存在 ξ ∈ [a, b] 使 f(ξ) = μ。
3. 零点定理：f(a)·f(b) < 0 且 f 连续，则 (a, b) 内至少存在一个零点。
4. 一致连续性（康托尔定理）：闭区间上连续函数一致连续。

**用法**：证明方程有根常用零点定理，先构造函数、再验证端点异号；证明存在 ξ 使 f(ξ) = 某值常用介值定理。

**易错点**

- HM-01-07-E1 用零点定理却不验证 f(a)·f(b) < 0。
- HM-01-07-E2 把结论套到开区间上（如 (0, 1) 上的 1/x 无界）。
- HM-01-07-E3 只证「存在」却写成「唯一」；唯一性需要再证单调。

**自检**：证明 x = cos x 在 (0, π/2) 内有唯一根。（提示：令 f(x) = x − cos x，f(0) < 0，f(π/2) > 0，再用 f′(x) = 1 + sin x > 0 说明唯一。）
