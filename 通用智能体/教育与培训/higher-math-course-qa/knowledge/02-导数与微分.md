# 第二章 导数与微分（HM-02）

> 本章的核心不是背公式，而是分清「定义」与「公式」各自适用的场合。
> 分段点、绝对值点、含参点一律回到定义，这是本章最重要的操作纪律。

## HM-02-01 导数定义与可导性判定

**定义**

```
f′(x₀) = lim_{Δx→0} [f(x₀ + Δx) − f(x₀)] / Δx
```

等价写法：f′(x₀) = lim_{x→x₀} [f(x) − f(x₀)] / (x − x₀)。几何意义是曲线在该点切线的斜率。

**可导与连续的关系**：可导必连续，连续不一定可导。典型反例：y = |x| 在 x = 0 处连续但不可导；y = x^{1/3} 在 0 处连续但导数为无穷（切线垂直）。

**分段函数在分界点求导的正确流程**

1. 用定义算左导数：lim_{x→x₀⁻} [f(x) − f(x₀)]/(x − x₀)；
2. 用定义算右导数；
3. 两者存在且相等才可导，导数值即为公共值；
4. 分界点以外可以直接用求导公式。

**易错点**

- HM-02-01-E1 在分界点直接套求导公式，导致该点导数凭空出现。公式只保证在区间内部成立。
- HM-02-01-E2 由「连续」推出「可导」。判断可导必须验证左右导数，或验证差商的极限存在。
- HM-02-01-E3 混淆 f′(x₀) 与 [f(x₀)]′。后者是常数的导数，恒为 0。
- HM-02-01-E4 求 f′(x₀) 时把 x₀ 当作变量继续求导，得到 f″。

## HM-02-02 求导法则与复合函数求导

**四则法则**：(u ± v)′ = u′ ± v′；(uv)′ = u′v + uv′；(u/v)′ = (u′v − uv′)/v²，要求 v ≠ 0。

**链式法则**：若 y = f(u)，u = g(x)，则 dy/dx = f′(u)·g′(x)。多层复合逐层乘到底。

**基本导数表（必须熟记）**

```
(x^a)′ = a x^{a−1}      (a^x)′ = a^x ln a      (e^x)′ = e^x
(ln x)′ = 1/x           (sin x)′ = cos x       (cos x)′ = −sin x
(tan x)′ = sec²x        (arctan x)′ = 1/(1+x²) (arcsin x)′ = 1/√(1−x²)
```

**易错点**

- HM-02-02-E1 复合函数漏乘内层导数，如把 (sin 2x)′ 写成 cos 2x，正确是 2cos 2x。
- HM-02-02-E2 混淆 sin²x 与 sin(x²)：前者是 (sin x)²，导数为 2 sin x cos x；后者导数为 2x cos(x²)。
- HM-02-02-E3 商法则分子符号写反，写成 (uv′ − u′v)/v²。
- HM-02-02-E4 对 ln|x| 求导时纠结绝对值，实际 (ln|x|)′ = 1/x（x ≠ 0）。

## HM-02-03 隐函数与参数方程求导

**隐函数求导**：方程 F(x, y) = 0 确定 y = y(x)。两边对 x 求导，遇到 y 时按复合函数处理（乘 y′），再从所得方程中解出 y′。结果中允许保留 y。

**参数方程求导**：x = φ(t)，y = ψ(t)，则

```
dy/dx = ψ′(t) / φ′(t)     （φ′(t) ≠ 0）
```

二阶导数：

```
d²y/dx² = [d/dt (dy/dx)] / φ′(t)
```

**对数求导法**：适用于幂指函数 u(x)^{v(x)} 及多个因子连乘除的情形。先取对数化为加法，再两边求导。幂指函数的另一条路是写成 e^{v ln u} 后直接求导，两者结果一致。

**易错点**

- HM-02-03-E1 隐函数求导时把 y 当常数，漏掉 y′。
- HM-02-03-E2 参数方程求二阶导时，直接对 ψ′/φ′ 关于 t 求导就当作答案，忘了再除以 φ′(t)。
- HM-02-03-E3 幂指函数直接套幂函数公式，把 u^v 的导数写成 v u^{v−1}。

## HM-02-04 高阶导数

**常用 n 阶导数**

```
(sin x)^(n) = sin(x + nπ/2)        (cos x)^(n) = cos(x + nπ/2)
(e^{ax})^(n) = a^n e^{ax}          (x^m)^(n) = m(m−1)…(m−n+1) x^{m−n}
(1/x)^(n) = (−1)^n n! / x^{n+1}    (ln x)^(n) = (−1)^{n−1}(n−1)! / x^n
```

**莱布尼茨公式**：(uv)^(n) = Σ_{k=0}^{n} C(n, k) u^(k) v^(n−k)。当一个因子是低次多项式时，只有前几项非零。

**有理分式求 n 阶导**：先做部分分式分解，化成若干个 1/(x − a)^k 之和，再套公式。

**易错点**

- HM-02-04-E1 把 (uv)^(n) 当成 u^(n) v^(n)。
- HM-02-04-E2 用归纳法求 n 阶导数时，只归纳出形式而不验证 n = 1 的初值。
- HM-02-04-E3 部分分式分解后忘记系数，直接对原分式套 1/(x−a) 的公式。

## HM-02-05 微分与近似计算

**微分定义**：若 Δy = A·Δx + o(Δx)，则称 f 在 x 处可微，dy = A·Δx = f′(x)dx。一元函数可微与可导等价。

**一阶微分形式不变性**：无论 u 是自变量还是中间变量，dy = f′(u)du 都成立。这是凑微分法的基础。

**近似计算**：f(x₀ + Δx) ≈ f(x₀) + f′(x₀)Δx，误差是 o(Δx)。例如 √(1.02) ≈ 1 + 0.02/2 = 1.01。

**易错点**

- HM-02-05-E1 认为 Δy = dy。两者相差高阶无穷小，只有 |Δx| 很小时才近似相等。
- HM-02-05-E2 把 dx 理解成「某个很小的固定数」。dx 是自变量增量，可任意取值。
- HM-02-05-E3 用一次近似算误差时，把相对误差和绝对误差混为一谈。
