# 第七章 重积分与无穷级数（HM-07）

> 重积分的错误几乎全是「面积元/体积元少乘一个因子」，级数的错误几乎全是「判别法用超范围」。
> 本章按「先画区域、再定坐标、最后核对因子」的顺序组织。

## HM-07-01 二重积分与极坐标

**化累次积分**：画出积分区域 D，判断是 X 型（上下由曲线夹住）还是 Y 型（左右由曲线夹住）。

```
X 型：∫ₐᵇ dx ∫_{φ₁(x)}^{φ₂(x)} f(x, y) dy
Y 型：∫꜀ᵈ dy ∫_{ψ₁(y)}^{ψ₂(y)} f(x, y) dx
```

**极坐标**：x = r cos θ，y = r sin θ，面积元

```
dx dy = r dr dθ
```

**那个 r 是雅可比行列式的值，不是可有可无的符号**，漏掉它是最常见的错误。

适用极坐标的三类信号：区域是圆、圆环或扇形；被积函数含 x² + y²；被积函数含 y/x 或 arctan(y/x)。

**对称性**：D 关于 x 轴对称时，若 f(x, −y) = −f(x, y)（对 y 为奇函数），则积分为 0；若为偶函数则等于上半部分的两倍。

**交换积分次序**：当内层积分积不出来时（如 ∫₀¹dx∫ₓ¹ e^{y²}dy），重画区域并交换次序往往能解。

**易错点**

- HM-07-01-E1 极坐标下漏乘 r。
- HM-07-01-E2 内外层上下限写反，或把变量混用（内层上限含外层变量，不能含内层变量）。
- HM-07-01-E3 θ 的范围取错：圆心在原点的整圆是 0 到 2π，上半圆是 0 到 π，第一象限是 0 到 π/2。
- HM-07-01-E4 交换次序时区域没有重画，导致新上下限仍按原区域写。

## HM-07-02 三重积分

**直角坐标·投影法**：把 Ω 投影到 xOy 面得 D，则

```
∭Ω f dV = ∬D dxdy ∫_{z₁(x,y)}^{z₂(x,y)} f dz
```

**柱面坐标**：x = r cos θ，y = r sin θ，z = z，体积元 dV = r dr dθ dz。适用于旋转体、柱面、锥面围成的区域。

**球面坐标**：x = ρ sin φ cos θ，y = ρ sin φ sin θ，z = ρ cos φ，体积元

```
dV = ρ² sin φ dρ dφ dθ
```

其中 ρ ≥ 0，0 ≤ φ ≤ π（与 z 轴正向夹角），0 ≤ θ ≤ 2π。

**易错点**

- HM-07-02-E1 球面坐标漏乘 ρ² sin φ（只写 dρ dφ dθ）。
- HM-07-02-E2 柱面坐标漏乘 r。
- HM-07-02-E3 φ 与 θ 的含义搞反：φ 是极角（与 z 轴夹角），θ 是方位角（在 xOy 面内的角）。
- HM-07-02-E4 用投影法时上下曲面判断反了（里层 z₁ 是「下曲面」）。

## HM-07-03 曲线积分与格林公式

**第一类曲线积分（对弧长）**

```
∫_L f(x, y) ds，ds = √(x′²(t) + y′²(t)) dt
```

与方向无关：∫_{L⁻} f ds = ∫_L f ds。

**第二类曲线积分（对坐标）**

```
∫_L P dx + Q dy
```

与方向有关：反向时变号。

**格林公式**

```
∮_L P dx + Q dy = ∬_D (∂Q/∂x − ∂P/∂y) dxdy
```

三个条件：L 是分段光滑的**闭**曲线；L 取**正方向**（沿 L 前进时区域在左侧，即逆时针）；P、Q 在 D 上有连续一阶偏导。

**非闭曲线的处理**：补一条辅助线使之闭合，用格林公式算出闭合曲线的积分，再减去辅助线上的积分。

**与路径无关的条件**：在单连通区域内 ∂P/∂y = ∂Q/∂x 时，积分只与起点终点有关。若区域有洞（如含原点），即使偏导相等也不能断定路径无关。

**易错点**

- HM-07-03-E1 对非闭曲线直接用格林公式，没有补线。
- HM-07-03-E2 方向取反（把顺时针当成正向），结果差一个负号。
- HM-07-03-E3 区域含奇点（如 P = −y/(x²+y²)，Q = x/(x²+y²) 在原点）仍直接用格林公式。
- HM-07-03-E4 混淆两类曲线积分，把 ds 与 dx、dy 直接互换。

## HM-07-04 常数项级数的敛散判别

**收敛的定义**：部分和数列 Sₙ 有极限。收敛级数满足 aₙ → 0，但 aₙ → 0 不能推出收敛（调和级数 Σ1/n 发散）。

**正项级数判别法**

| 方法 | 内容 | 适用 |
| --- | --- | --- |
| 比较判别 | 与已知敛散的级数逐项比较 | 有显然的放缩对象 |
| 极限比较 | lim aₙ/bₙ = c（0 < c < ∞）则同敛散 | 与 p 级数比较 |
| 比值判别（达朗贝尔） | lim a_{n+1}/aₙ = ρ，ρ < 1 收敛，ρ > 1 发散，ρ = 1 失效 | 含阶乘、指数 |
| 根值判别（柯西） | lim ⁿ√aₙ = ρ，判据同上 | 含 n 次方 |

**p 级数**：Σ 1/n^p 在 p > 1 时收敛，p ≤ 1 时发散。几何级数 Σ qⁿ 在 |q| < 1 时收敛。

**交错级数（莱布尼茨判别）**：aₙ 单调递减且 aₙ → 0，则 Σ(−1)^{n−1}aₙ 收敛，且余项满足 |Rₙ| ≤ a_{n+1}。

**绝对收敛与条件收敛**：Σ|aₙ| 收敛称绝对收敛（必收敛）；Σaₙ 收敛但 Σ|aₙ| 发散称条件收敛。

**易错点**

- HM-07-04-E1 由 aₙ → 0 推出级数收敛。
- HM-07-04-E2 比值判别得到 ρ = 1 就下结论（应改用其他方法）。
- HM-07-04-E3 交错级数不验证 aₙ 单调递减，直接用莱布尼茨判别。
- HM-07-04-E4 把条件收敛当成绝对收敛，进而在逐项重排、逐项相乘时出错。

## HM-07-05 幂级数与泰勒级数

**阿贝尔定理**：幂级数 Σaₙ(x − x₀)ⁿ 存在收敛半径 R，|x − x₀| < R 时绝对收敛，|x − x₀| > R 时发散，端点需单独判断。

**收敛半径**

```
R = lim |aₙ / a_{n+1}|   或   R = 1 / lim ⁿ√|aₙ|
```

**收敛域 = 收敛区间 + 端点讨论**。端点必须代回原级数单独判断，不能直接写开区间。

**逐项求导与逐项积分**：在收敛区间内可以逐项求导、逐项积分，收敛半径不变，但**端点的敛散性可能改变**。

**常用和函数**

```
Σ_{n=0}^∞ xⁿ = 1/(1 − x)        (|x| < 1)
Σ_{n=1}^∞ xⁿ/n = −ln(1 − x)     (−1 ≤ x < 1)
Σ_{n=0}^∞ xⁿ/n! = e^x           (全体实数)
Σ_{n=0}^∞ (−1)ⁿ x^{2n+1}/(2n+1)! = sin x
```

**易错点**

- HM-07-05-E1 只写收敛区间不讨论端点，把收敛域写成开区间。
- HM-07-05-E2 逐项求导后沿用原来的端点敛散性。
- HM-07-05-E3 求和函数时不写成立范围。和函数离开收敛域没有意义。
- HM-07-05-E4 用比值法求 R 时，把缺项级数（如只含 x^{2n}）直接套公式。缺项级数应换元后求，或直接用根值法。
