# 高中数学课程答疑助手

按人教 A 版五册章序回答高中数学问题。支持概念解释、只给一步提示、完整解答和作业订正，可引用“必修第二册 第7章 复数（A-B2-07）”这样的定位。在适用题型中调用 MCP 核对二次式和分数计算。

## 文件和依赖

| 文件 | 用途 |
| --- | --- |
| `agent.json` | Nexent 导出配置，进入目标租户后重新选择适用的对话模型和知识库 |
| `knowledge/*.md` | 5 册共 18 章自编讲义及总目录，每章包含要点、例题和易错点 |
| `skills/pep-a-math-tutoring/SKILL.md` | 基于册次的检索和答疑流程 |
| `mcps/` | MCP 和可选本地嵌入服务的代码、安装步骤与连通测试 |
| `evaluation/` | 五册及总目录检索结果，以及公开示例题的章节定位评估 |

参考人教社公开章序编排。讲义内容为自编，A 版章号只适用于 A 版。

## 导入和配置

1. 在 Nexent 模型管理中配置可用的对话模型及文本向量模型。验证环境为 Nexent v2.7.0，使用 `deepseek-flash` 对话、`deepseek-v4-pro` 评审和本地 `bge-small-zh-v1.5` 做向量化。
2. 在「知识库」创建知识库，选定向量模型，上传 `knowledge/` 下六份 Markdown，等待入库。检查册名、章名和编号可检索。需要逐章分片时，可在 Chunk 详情手动放入各章内容，并保留文首定位行。验证环境采用逐章分片，共 18 个正文分片和 1 个目录分片。
3. 在「资源仓库 → Skill → 我的 Skill」上传随附的 `SKILL.md`。已有同名 Skill 时核对内容后复用。
4. 根据 [MCP 服务说明](mcps/README.md) 启动服务，在「MCP 工具」添加远程连接，使用服务名 `high_school_math`，验证后启用两项工具。
5. 在「智能体开发 → 导入」导入 `agent.json`。核对目标环境的对话模型，在「知识库」选择新建知识库，在「工具与技能」启用 `pep-a-math-tutoring`、`quadratic_check` 和 `fraction_check`。保存草稿并调试，确认无误后发布。

配置移除了源租户标识、源环境模型和向量索引 ID。示例的 Docker 内网 MCP 地址可按部署环境修改。若模型长时间只输出思考过程，请按供应商说明关闭或调整思考模式。验证版本的规划模型温度为 0.15，输出预算 12288，DeepSeek 连接接受 `thinking: {"type":"disabled"}`。

## 验收

- 用必修第二册第7章复数题验证册次、章名和条目编号引用。
- 请求区分两个第3章，确认分别指向函数与圆锥曲线。
- 指明使用 B 版且只给章号，确认不套用 A 版章号。

五册和总目录检索抽查 6 项的目标条目均排第一。原部署 1.1 版的章次评估 3/3 通过，得分 1.0，阈值 0.8。复数题中附加的分数加法不构成复数除法验算，手工复核建议用商乘回分母。
