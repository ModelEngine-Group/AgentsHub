# python课程答疑小助手

> 基于 Nexent 平台构建的 Python 课程答疑智能体，严格依据课程知识库回答课程内容、知识点、作业疑问与考试范围相关问题，不臆造资料外的结论。

## 功能特点

- **知识库约束答疑**：通过 `knowledge_base_search` 检索课程资料，仅依据命中内容作答，并标注所依据的章节或条目。
- **不臆造**：知识库无相关内容时明确告知并建议补充资料或联系教师，不编造知识点、公式、考试范围或来源。
- **作业辅导有边界**：对代码作业只给思路、关键知识点与必要示例，不代替学生完成全部作业。
- **文件分析**：用户通过 S3 / HTTP(S) 链接提供讲义、作业题等文本时，可用 `analyze_text_file` 提取内容再结合问题作答。
- **配套 Skill**：`course-qa-assistant` 定义了「接收定位 → 检索 → 基于知识库回答 → 标注出处」的工作流与约束原则。

## 依赖与前置配置

导入前请先在目标 Nexent 实例中准备以下资源：

| 类型 | 配置要求 |
|---|---|
| 模型 | 原导出环境使用 `大肥鱼V4`、`大肥鱼F1`（model_ids `[1, 2]`）。目标环境需先在「模型配置」中添加并验证可用模型，导入时重新选择；名称不必一致。 |
| Skill | 必填。进入「智能体开发 → 选择技能 → 构建技能」，上传 `skills/course-qa-assistant.zip` 后再导入智能体。 |
| 知识库 | 必填。`agent.json` 中 `knowledge_base_search` 的 `index_names` 为导出环境的知识库索引（`1-f31311e070c04a1da8afec1896042cf2`）。导入后需将其替换为目标环境中自己的课程知识库索引，否则检索不可用。 |
| MCP | 无（`mcp_info` 为空数组），无需配置 MCP 服务。 |
| 工具 | 内置 `knowledge_base_search`、`analyze_text_file`、`create_directory`，无需额外安装。 |

## 导入步骤

1. 登录目标 Nexent 平台，在「模型配置」中添加并验证可用的大语言模型。
2. 进入「智能体开发 → 选择技能 → 构建技能」，上传 `skills/course-qa-assistant.zip`。
3. 进入「智能体开发 → 导入」，上传本目录下的 `agent.json`。
4. 在导入界面选择目标环境可用的模型，并把 `index_names` 指向已创建的课程知识库。
5. 确认技能 `course-qa-assistant` 已勾选，完成导入并发布。

## 回归用例

导入后建议逐条验证（示例问题取自 `example_questions`）：

| 场景 | 输入 | 预期 |
|---|---|---|
| 知识点讲解 | 「请根据课程资料解释一下列表和元组的区别」 | 命中知识库后作答，并标注章节/条目出处 |
| 考试范围 | 「这门课期末考试的重点范围是什么」 | 仅依据资料回答；资料未覆盖时明确说明，不推测 |
| 作业辅导 | 「我有一道 Python 作业题不会做，可以帮我分析吗」 | 给出思路与关键知识点，不直接给出完整答案 |
| 概念答疑 | 「课程里讲到的递归函数我不太理解，能再讲讲吗」 | 结合资料用教学语气解释 |
| 检索能力 | 「请帮我查找课程资料中关于面向对象编程的内容」 | 返回资料中的对应内容并注明来源 |
| 越界提问 | 与课程完全无关的问题 | 礼貌引导回课程话题，不编造答案 |

## 局限说明

- 回答质量完全依赖课程知识库覆盖度；知识库为空或索引未正确配置时，智能体应如实说明无法回答。
- `analyze_text_file` 仅在用户提供可访问的文件 URL 时可用，不支持直接读取本地磁盘文件。
- 原环境的模型名称与知识库索引不随包迁移，需由导入者自行配置。
- 不包含真实课程资料，知识库内容需自行准备。

## 脱敏说明

- `tenant_id` 已置空。
- `author` 已由个人邮箱替换为 `Community Contributor`。
- 配置中不含任何 API Key、Token、租户密钥或外部服务地址；`mcp_info` 为空。
- 保留导出时的知识库索引字符串，与本仓库其他条目做法一致；该值仅为知识库标识，导入后需重配为目标环境索引。
