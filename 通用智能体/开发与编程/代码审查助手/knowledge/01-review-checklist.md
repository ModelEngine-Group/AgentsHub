# 通用代码审查清单

> 用法：按变更内容检索对应条目。每条都是可判定的，不写「注意质量」这类空话。

## R-GEN-01 空值与边界

**级别**：P1　**适用**：所有语言

**判定**：外部输入（HTTP 参数、消息、文件、环境变量）未校验就参与索引、运算、`split`、类型转换；可能为 `None` 的值直接解引用。
**反例**：`name = request.args["name"]; return name.strip()`
**修复**：入口处校验并给默认值；类型转换捕获异常；契约层用 schema 收敛。

## R-GEN-02 错误处理

**级别**：P1　**适用**：所有语言

**判定**：异常被吞掉、只打印不处理、捕获范围过大、错误路径没有回滚或补偿。
**反例**：`try: pay() except: pass`
**修复**：捕获具体异常；记录上下文；失败时回滚事务并返回明确错误码。

## R-GEN-03 资源释放

**级别**：P2　**适用**：所有语言

**判定**：文件、连接、锁、临时目录在异常路径未释放；`open` 未用 `with`。
**反例**：`f = open(p); data = f.read()`（异常时泄漏）
**修复**：`with` / `try-finally` / 连接池上下文管理器。

## R-GEN-04 事务与一致性

**级别**：P1　**适用**：涉及写库的变更

**判定**：一次业务操作写多张表但无事务；异常路径不回滚；先查后写在并发下不成立。
**反例**：扣库存与写订单分开提交，第二步失败后库存已扣。
**修复**：显式事务；唯一约束/乐观锁兜底；补偿任务。

## R-GEN-05 幂等与重试

**级别**：P1　**适用**：接口、消息消费、支付、回调

**判定**：重复请求会重复扣款/重复发货；重试没有退避；没有幂等键。
**反例**：`POST /pay` 无 `Idempotency-Key`，超时重试两次扣款。
**修复**：幂等键 + 唯一索引；重试指数退避；区分可重试与不可重试错误。

## R-GEN-06 权限与数据边界

**级别**：P0/P1　**适用**：所有对外接口

**判定**：只校验登录不校验归属；按 id 查询未带租户/用户条件；批量接口可越权。
**反例**：`GET /orders/{id}` 直接返回，任何登录用户可读他人订单。
**修复**：查询条件带 `owner_id/tenant_id`；集中式鉴权；越权返回 404 而非 403。

## R-GEN-07 输入输出契约

**级别**：P2　**适用**：API、RPC、消息

**判定**：修改字段名/类型/可空性未同步调用方；返回结构随实现变化；错误码不统一。
**反例**：把 `int` 的 `id` 改成 `string`，调用方解析失败。
**修复**：版本化契约；兼容期双写/双读；契约测试。

## R-GEN-08 并发与共享状态

**级别**：P1　**适用**：服务端、后台任务

**判定**：模块级可变对象做缓存无锁；check-then-act；线程池共享 session；异步中调用阻塞 IO。
**反例**：`if key not in cache: cache[key] = load(key)` 并发重复加载。
**修复**：锁/原子操作/单飞（singleflight）；每线程独立连接。

## R-GEN-09 超时与隔离

**级别**：P1　**适用**：所有外部调用

**判定**：HTTP/DB/缓存无超时；失败无降级；一个下游拖垮整个请求链路。
**反例**：`requests.get(url)` 无 timeout。
**修复**：连接与读取超时；有限重试；熔断/舱壁；异步化非关键路径。

## R-GEN-10 日志与脱敏

**级别**：P2　**适用**：所有语言

**判定**：日志打印口令、Token、身份证、手机号；异常只 `print`；关键分支无日志。
**反例**：`print("login", username, password)`
**修复**：结构化日志；敏感字段脱敏；`logger.exception` 保留堆栈。

## R-GEN-11 测试覆盖

**级别**：P2　**适用**：所有变更

**判定**：新增分支、异常路径、边界值没有用例；测试依赖真实外部服务；只测 happy path。
**反例**：新增 `if not items: raise` 但没有空列表用例。
**修复**：为本次变更的关键分支补最小用例；外部依赖用 fake。

## R-GEN-12 可回滚与可观测

**级别**：P1　**适用**：数据库、配置、发布

**判定**：加非空列无默认值；删除字段/枚举；配置变更无法回退；没有指标暴露失败。
**反例**：`ALTER TABLE ADD COLUMN status NOT NULL` 无默认值，历史行迁移失败。
**修复**：分步迁移（可空→回填→非空）；保留回滚脚本；加成功率/延迟指标。
