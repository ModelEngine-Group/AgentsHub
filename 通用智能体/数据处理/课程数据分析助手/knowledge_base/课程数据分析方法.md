# 课程数据分析方法

## 数据契约

`data/course_records.csv` 为 UTF-8 CSV，字段约定如下：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `student_id` | string | 学生编号 |
| `gender` | string | 性别 |
| `grade` | string | 年级 |
| `attendance_rate` | number | 出勤率，0 到 1 之间 |
| `homework_score` | integer | 平时作业得分 |
| `midterm_score` | integer | 期中成绩 |
| `final_score` | integer | 期末成绩 |
| `learning_hours` | number | 课外学习时长（小时） |
| `experiment_score` | integer | 实验得分 |

## 分析要求

1. 先执行 `inspect_dataset` 获取行数、列数、缺失值和数值字段范围，不得在未检查前直接下结论。
2. 使用 `analyze_course_data` 计算 `final_score` 的均值、标准差、分位数和相关系数。
3. 使用 `query_course_data` 查询指定条件的学生记录；查询返回空集时如实说明。
4. 输出必须包含数据质量、关键统计量、相关性发现、异常或缺失值提示和下一步建议。
5. 相关系数仅表示线性关联，不得解释为因果关系。
6. 成绩数据仅用于教学分析，不得用于个人评价、公开披露或自动化决策。

## 指标口径

- `attendance_rate` 直接读取 0 到 1 的比例，不重复除以 100。
- `at_risk_threshold` 默认为 60；`final_score` 低于该阈值时视为课程预警。
- 相关性解释使用统一区间：`|r| >= 0.7` 为强线性关联，`0.4 <= |r| < 0.7` 为中等，`0.2 <= |r| < 0.4` 为弱，其余基本无线性关联。
- 分析报告中的数值保留两位小数；样本量小于 5 时提示统计结论不稳定。

## 输出模板

```markdown
## 数据质量
- 样本量、字段数、缺失值、异常值

## 关键统计
- 期末成绩均值、标准差、最低分、最高分、分位数
- 高风险人数与比例

## 相关性发现
- 出勤率、作业、期中、学习时长与期末成绩的相关系数
- 明确说明不能因果推断

## 下一步建议
- 数据补充、教学干预或验证分析建议
```

## 边界与治理

- 不读取 `data/` 以外的文件，不执行写文件、删除文件或访问网络的操作。
- 不根据姓名、学号等敏感信息生成个人画像；输出以群体统计和阈值预警为主。
- 如果用户要求医疗、金融等非课程数据分析，应说明当前工具仅支持课程成绩与学习行为数据。
