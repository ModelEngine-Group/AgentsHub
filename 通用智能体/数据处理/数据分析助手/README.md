# 数据分析助手

## 简介

数据分析助手是一个面向业务场景的数据分析智能体。用户上传 Excel / CSV 表格或直接粘贴数据后，它会先在沙箱中做真实计算，再输出结构化的分析结论与可执行建议——包括数据概览、关键指标、异常与趋势、归因假设和行动建议。

它不做"看着像"的估算：每一个数字都来自实际执行的 pandas / openpyxl 代码，避免大模型口算导致的数字错误。

## 功能特性

### 1. 真实计算，而非"猜数"
- 在沙箱中执行 pandas / openpyxl 代码完成聚合、分组、同比环比、占比与分布计算
- 所有数字均来自执行结果，可复现、可核对

### 2. 结构化分析框架
固定按以下顺序推进，避免"给一堆数字但没有结论"：

| 环节 | 产出 |
|------|------|
| 数据概览 | 字段含义、时间范围、样本量、缺失情况 |
| 关键指标 | 总量、均值、极值、同比/环比、占比、分布 |
| 异常与趋势 | 突增突降、离群点、结构性变化 |
| 归因假设 | 可能原因及其可验证方式 |
| 行动建议 | 谁来做、做什么、看哪个指标验证 |

### 3. 交付物生成
- 需要图表时用 matplotlib 生成 PNG 并给出文件路径
- 需要交付表格时使用 `xlsx` 技能产出 Excel 文件

### 4. 结论有边界
- 标注样本局限、口径假设
- 明确哪些结论还需要补充数据才能验证
- 口径不明确时先提问，不自行假设

## 技术架构

### 模型信息
- **主模型**：需在导入后选择（本模板导出自 `Qwen2.5-7B-Instruct` 本地部署实例）
- **模型要求**：支持 OpenAI 兼容接口与工具调用（function calling）

### 技能依赖

| 技能 | 用途 | 来源 |
|------|------|------|
| `xlsx` | Excel / CSV 读写与统计（沙箱内预装 pandas、openpyxl、markitdown） | 平台内置技能，随本目录 `skills/xlsx.zip` 一并提供 |

> 若目标平台的沙箱未预装该技能，请先在「智能体开发 → 选择技能 → 构建技能」中上传 `skills/xlsx.zip`，再导入 `agent.json`。

### 外部集成
无。不依赖任何自定义 MCP 服务。

## 工作流程

```
用户上传表格 / 粘贴数据
  ↓
确认字段含义、口径、样本量（不清楚则提问）
  ↓
在沙箱执行 pandas/openpyxl 计算
  ↓
数据概览 → 关键指标 → 异常趋势 → 归因假设
  ↓
输出结论 + 可执行建议（+ 图表/Excel 文件）
```

## 使用示例

**示例 1：周度销售趋势**

用户输入：
```
这是本周每天的销售额（万元）：周一 12.3，周二 15.1，周三 9.8，周四 18.2，
周五 22.6，周六 25.1，周日 19.4。请分析趋势，找出最值得关注的一天，并给出下周建议。
```

助手执行：
- 计算总销售额 122.50 万元、日均 17.50 万元、峰值周六 25.10 万元
- 算出逐日环比：+2.80、−5.30、+3.40、+4.50、−5.70
- 指出周三为低谷、周末为峰值，并给出对应运营建议

**示例 2：上传 Excel 做多维度分析**

用户输入：
```
（上传 sales_2024.xlsx）帮我按区域和品类两个维度拆解销售额，
找出增长放缓和库存积压风险最高的组合。
```

助手执行：
- 读取表格并确认字段（区域、品类、销售额、库存周转天数、月份）
- 按区域 × 品类做透视，计算同比增速与库存周转
- 输出"高库存 + 低增速"的风险组合清单与处理建议

**示例 3：数据质量检查**

用户输入：
```
检查这份订单数据的异常值、缺失和重复记录，说明对后续结论的影响。
```

助手执行：
- 统计缺失率、重复率、数值字段的分布与离群点
- 说明每类问题建议的处理方式（删除 / 填充 / 保留）及对结论的影响

## 导入与配置

1. 在 Nexent 平台进入「智能体开发」→「导入」，选择本目录的 `agent.json`
2. 按提示选择要使用的大模型（需支持工具调用）
3. 如平台未内置 `xlsx` 技能，先上传 `skills/xlsx.zip`
4. 导入后建议用上方的示例 1 做一次连通性验证，再发布上线

### 关键参数

| 参数 | 值 | 说明 |
|------|----|------|
| 最大步数 | 12 | 复杂分析需要多轮工具调用 |
| 协议修复重试 | 开启 | 小模型偶发格式错误时自动修复 |
| 温度 | 0.3 | 偏低温度，保证数字与结论稳定 |
| 运行摘要 | 开启 | 便于回溯每一步的推理与工具调用 |

## 提示词设计要点

- **禁止编造数字**：所有数值必须来自工具执行结果
- **最终回答不贴代码**：只给结论、表格与建议，避免暴露中间过程
- **结论必须自洽**：先判断"是否存在值得关注的点"，再给建议，禁止先说"无异常"又建议重点关注某一天
- **服务业务落地**：每条建议都要求说明谁来做、做什么、看哪个指标验证

## 适用场景与边界

**适用**：销售/运营数据分析、财务指标拆解、用户行为统计、数据质量检查、周报月报数据整理

**不适用**：
- 需要实时流式数据接入的场景（当前为文件/粘贴数据驱动）
- 需要连接企业数据库直连查询的场景（需额外配置 MCP 数据源）
- 对图表美观度要求极高的汇报级可视化（建议配合专业 BI 工具）
